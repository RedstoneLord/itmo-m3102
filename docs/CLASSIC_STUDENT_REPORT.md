# Улучшения классической версии по отчёту пользователя

Изменения применяются при `npm run classic` и `npm run site` из `app/`. Исходные файлы классического сайта в корне не изменены. Готовая версия находится в `app/site/`, копия для разработки — в `app/public/classic/`.

| № | Запрос | Реализация и где искать |
|---|---|---|
| 1 | Всё приложение без интернета | «Настройки → Работа без интернета»: оболочка, все игры и их зависимости, конспекты, PDF, аудио и другие файлы. Готовность объявляется только после успешной загрузки. Живые очереди и публикация требуют подключения. |
| 2 | Материалы при лимите GitHub | Готовое дерево `data/tree.json` создаётся при сборке. Просмотр папок не обращается к Contents API. Списки и данные сохраняются, при ошибке доступна повторная попытка. |
| 3 | Свежесть данных | Внизу сайта — последнее успешное обновление расписания, ДЗ и очередей; при возврате к кешу — явная надпись «сохранённые данные». Неудачная попытка не обновляет дату успеха. |
| 4 | Будущие сроки и старые долги | «Скоро сдавать», «Остались долги» и свёрнутый архив разделены на главной и в дедлайнах. Общие признаки `archived`, `completed` или `status: done/completed/closed/archived` отправляют работу в архив; личная отметка не меняет общие данные. |
| 5 | Мои очереди | Выбор студента на главной, в дедлайнах или настройках. На главной — «вы №N», в очереди — выделение и «это вы». Учитывается человек из названия заявки, включая запись другим студентом; очереди читаются со всех страниц API. |
| 6 | Копия всего личного прогресса | Отдельный раздел настроек: задачи, отметки, план, черновики, закладки, тесты, чтение, аудио, игры и оформление. Формат проверяется до восстановления; есть предложение скачать текущую копию. Токены и кеши исключены. |
| 7 | Личные и общие изменения | Форма ДЗ сообщает, что сохраняется локально, и указывает следующий шаг для публикации. Кнопка «Сохранить только для меня», подсказки у выполнения и удаления; публикация группы остаётся явным действием GitHub. |
| 8 | Одна страница предмета | «Все предметы» на главной и в материалах: конспекты с темами, ближайшая пара, лабораторные, записи, сроки, преподаватели из расписания и ссылки. |
| 9 | Темы до открытия папки | Карточки лекций и практик дополнены заголовками из `data/lectures.json`; те же темы видны на странице предмета. |
| 10 | Закладки и вопросы | «Закладка / вопрос» в читалке; можно выделить фрагмент и добавить личную пометку. Общий список доступен с главной и из настроек; переход возвращает к заголовку/фрагменту или странице PDF. |
| 11 | Долгое чтение PDF | Тёмные страницы в тёмной теме с отдельным переключателем, номер страницы и восстановление позиции. Позиции сохраняются отдельно для каждого файла. |
| 12 | Подготовка к контрольной | На странице предмета собираются вопросы из файлов-тестов и блоков `quiz`. Перемешивание, сохранение ошибок между посещениями, повтор только ошибок и ссылка на исходный конспект. Недоступные файлы перечисляются счётчиком и повторной загрузкой. |
| 13 | «Для ИИ» | На странице предмета — скачивание общего Markdown и копирование постоянной ссылки. Файлы собираются заранее в `ai/`; запросов к GitHub во время выгрузки нет. |
| 14 | Неделя и месяц | Переключатели в расписании; обзор занятий, свободных дней и окон; переход к любому дню и к следующему/предыдущему периоду. |
| 15 | Подписка на календарь | В расписании отдельное окно: `webcal:`-подписка, копирование HTTPS-адреса и отдельно подписанный разовый `.ics`. Используется существующая обновляемая выгрузка `m3102.ics`. |
| 16 | Настройка главной | Два отдельных блока — следующая пара с обратным отсчётом и мои очереди. «Настроить главную» меняет порядок блоков и сохраняет выбор. |
| 17 | Соседние вкладки заданий | Пункт «ДЗ и Дедлайны» возвращает последний открытый список. В обоих разделах доступны соседние кнопки переключения. |
| 18 | «Добавить ДЗ» у пары | Действие переименовано; существующие задания по-прежнему показываются отдельным списком внутри карточки занятия. |
| 19 | Тип пары на телефоне | «Лекция / Практика / Лабораторная» остаётся видимой и в закрытой карточке. |
| 20 | Служебная папка `output` | Скрыта в навигации; исключена из создаваемого учебного дерева. |
| 21 | Логотип в светлой теме | Сохраняется и проверяется существующий светлый каскад: инверсия белого логотипа при явной и системной светлой теме. |
| 22 | Управление загрузками | Выбор предметной папки и отдельного файла, объём до загрузки, состояния «сохранён / есть обновление / не скачан», список ошибок и повтор. Частичная загрузка не выдаётся за полный сайт. |
| 23 | Прослушивание записей | Аудиофайлы открываются внутри сайта: скорость, ±15 секунд, сохранённая позиция, личные отметки тем с временем и конспекты того же предмета. |
| 24 | Крупные мемы и прямые ссылки | Доступное с клавиатуры окно просмотра, подпись/изображение открываются нажатием, копирование ссылки с ID и открытие конкретного мема по этой ссылке. |
| 25 | Недостаточно ягод | Рядом с заблокированной раздачей указаны ставка и баланс, ссылки на ёжика и ежедневные награды. |

Код дополнений — `app/classic/`. Подключение к оригинальным функциям — `app/src/lib/classicPatch.ts`; сборка дерева, оболочки и выгрузок — `app/scripts/assemble-classic.ts`. Изменившиеся точки подключения останавливают сборку с ошибкой вместо тихого пропуска правок.

Проверки: `npm run test:classic` — разделение сроков, целостность дерева, резервные копии и откат при ошибке записи; `e2e/classic-student.spec.ts` — пользовательские сценарии, включая настоящий сервис-воркер и первое открытие игр без сети. Существующие проверки светлой темы — `e2e/classic-theme.spec.ts`.
