# М3102 — приложение (`/app/`)

Вторая версия сайта группы М3102: React-приложение, которое открывается по адресу
[redstonelord.github.io/itmo-m3102/app/](https://redstonelord.github.io/itmo-m3102/app/). Основной сайт группы —
[классическая версия](https://redstonelord.github.io/itmo-m3102/) в корне репозитория; данные у обеих общие, переключаются
кнопкой в шапке. Эта папка — только приложение, классический сайт здесь не правится.

Сервера нет: данные приходят из репозитория группы на GitHub, личное хранится в браузере. Правила разработки и
принятые решения подробно — в [AGENTS.md](../AGENTS.md); здесь — что есть и как запустить.

## Разделы

| Раздел | Что там |
|---|---|
| **Главная** | ближайшая пара с обратным отсчётом и полоской дня, кнопки «Конспект» (конспект именно этой пары, а если его ещё нет — «Последний конспект») и «Материалы»; ближайшие дедлайны, пары на сегодня, ДЗ, «Мои очереди» (где вы стоите на сдачу и под каким номером), недавние конспекты, материалы, личный план, предметы. Порядок и видимость блоков настраиваются кнопкой «Настроить главную» рядом с датой |
| **Расписание** | день, неделя (сеткой по часам) и месяц; на телефоне открывается день, на компьютере неделя; чётные и нечётные недели, переносы и отмены, ДЗ к паре; подписка на календарь `m3102.ics` (Google, Apple), которая обновляется сама |
| **Дедлайны** | сроки группы списком или карточками: «Впереди», «Просрочено» (открыто сразу) и «Выполнено»; фильтр по предмету, отметка «выполнено для меня», очередь на сдачу (GitHub Issues, метка `queue-signup`) с номерами; «Найти себя» подсвечивает ваши записи («Вы №3 из 7»; не из группы — «Я гость»); вкладка «Домашние задания» |
| **Материалы** | конспекты по предметам и занятиям (Markdown с формулами и схемами, PDF по страницам), файлы репозитория группы, записи лекций, ссылки; закладки и пометки в тексте, «Скачать PDF», печать |
| **Предметы** | на странице предмета — следующая пара, ближайший срок (или «Просрочено: N»), прогресс тестов, вкладки «Обзор», «Задачи», «Конспекты», «Заметки», «Ссылки»; описание курса и контакты; «Для ИИ» — все конспекты предмета одним Markdown-файлом или ссылкой; ссылка «по частям» ведёт на короткое оглавление с отдельным файлом на каждый конспект (весь предмет ИИ по ссылке целиком не читает — он слишком большой) |
| **Тесты и повторение** | тесты к конспектам, режим «Перед контрольной», повторение ошибок через 1, 3, 7 и 14 дней |
| **Личное** | учебный план, заметки, отметки «сделано» — только в этом браузере |
| **Группа** | студенты с фото и контактами (себя на карточке отмечает плашка «Это вы»), мемы, диаграммы (редактор схем), игры «Ёжик-кувырок» и «Колючий куш» |
| **Настройки** | оформление, данные (резервная копия личных данных одним файлом, синхронизация, сброс), работа без интернета, «Что нового» — выпуски простыми словами (у «Настроек» горит точка, пока их не открыли) |

Поиск — `Ctrl+K` (на Mac `⌘K`): предметы, текст конспектов и PDF, дедлайны, быстрые действия; в результатах подсвечены совпадения, их можно отфильтровать по типу и предмету. Все сочетания клавиш — по `?`.

Пока данные группы ещё не загрузились, вместо нулей и «пусто» — прочерки и заглушки, а со старыми данными сверху видно, когда они обновлялись. При первом открытии появляется окно «Настройте сайт под себя»: стиль, тема, палитра и «Кто вы?»; его можно вызвать снова в «Настройки → Оформление». Радио — в верхней панели.

## Оформление

Три независимых выбора — в «Настройки → Оформление» и в меню «Оформление» (кнопка с палитрой внизу бокового меню,
на телефоне — на странице «Ещё»):

- **Стиль**: Minimalism (без фона и свечения), Aurora (мягкое сияние за страницей, по умолчанию), Liquid Glass
  (полупрозрачные поверхности поверх цветного фона).
- **Тема**: светлая, тёмная или как в системе. Тема, палитра и скругления общие с классической версией.
- **Палитра**: акцент и второй акцент (по умолчанию лаванда и пыльная роза), свой цвет, палитры классической версии,
  «Динамическая тема», которая сама меняет цвета.

На телефоне внизу панель вкладок. Сайт ставится как приложение (Android и ПК — «Установить приложение» в браузере,
iPhone — «Поделиться» → «На экран „Домой“») и после первого открытия работает без сети; PDF и картинки можно заранее
скачать на устройство в «Настройки → Данные».

## Данные

- **Общие** — из репозитория группы [RedstoneLord/itmo-m3102](https://github.com/RedstoneLord/itmo-m3102): список
  файлов, конспекты, `data/*.json` (расписание, ДЗ, ссылки, мемы), сроки из папки `Дедлайны/`, очередь на сдачу из
  Issues. Сами файлы (PDF, картинки) берутся с `raw.githubusercontent.com`. Синхронизация идёт при открытии сайта и по
  кнопке «Синхронизировать» в шапке; последняя копия хранится в браузере, поэтому сайт открывается и без сети.
- **Личные** (план, заметки, отметки, результаты тестов, настройки) — в `localStorage` этого браузера и никуда не
  отправляются. Отметки «сделано» классической версии приложение читает само. Чтобы не потерять их при смене устройства
  или очистке данных сайта, скачайте резервную копию («Настройки → Данные → Скачать копию»); восстановление спрашивает
  подтверждение и при ошибке оставляет текущие данные как были.
- **Запись в репозиторий группы** (ДЗ, мемы) — через токен GitHub с правом на один репозиторий; токен
  хранится только в браузере.

У проекта нет собственного backend: аккаунты, синхронизация личных данных между устройствами и уведомления сейчас не
реализованы (план — в [docs/BACKEND_PLAN.md](../docs/BACKEND_PLAN.md)).

## Запуск

Нужен Node.js 22.12 или новее (так требует Vite; CI работает на 22). Для `npm run test:e2e` локально нужен установленный
Microsoft Edge (`channel: 'msedge'` в `playwright.config.ts`), в CI браузер ставится отдельным шагом.

```bash
cd app
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`, классическая версия для переключателя — на `/classic/`.

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер Vite |
| `npm test` | юнит-тесты (Vitest) |
| `npm run test:e2e` | тесты в браузере (Playwright) по собранному сайту целиком |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run size` | бюджет размера сборки (после `build`) |
| `npm run ics` | календарь-подписка `m3102.ics` из данных группы |
| `npm run site` | готовый сайт в `app/site`: классическая версия в корне, приложение в `/app/`, файлы «Для ИИ» в `/app/ai/` |
| `npm run format` · `format:check` | Prettier по `src/` |

Перед выкладкой — все проверки по порядку: `format:check`, `test`, `build`, `size`, `ics`, `site`, `test:e2e`.
Бюджеты (gzip): JS первой загрузки — до 215 КБ, CSS — до 25 КБ, одна страница — до 220 КБ.

## Устройство кода

```text
app/
├── src/
│   ├── app/           маршруты (HashRouter), меню и разделы
│   ├── components/    каркас (меню, шапка, нижняя панель) и общие компоненты интерфейса
│   ├── features/      разделы: today, schedule, deadlines, materials, subjects, settings, …
│   ├── services/      синхронизация с GitHub и публикация в репозиторий
│   ├── lib/           общие утилиты: даты, хранилище, движение
│   ├── styles/        токены дизайна, общие стили, слои Aurora и Liquid Glass
│   └── data/          то, чего нет у группы: предметы, студенты, описания курсов
├── e2e/               сценарии Playwright (GitHub подменён заглушками)
├── scripts/           сборка сайта, календаря, файлов «Для ИИ», проверка размера
└── public/            сервис-воркер, манифест, иконки, переключатель версий
```

Страница `#/design` показывает все компоненты интерфейса. Новый компонент сначала ищите там.

## Публикация

GitHub Actions (`.github/workflows/deploy-pages.yml`) при пуше в `master` и раз в сутки: Prettier → юнит-тесты →
сборка → календарь → бюджет размера → готовый сайт → тесты в браузере → Lighthouse → GitHub Pages. Если упал любой
шаг, сайт не обновляется.
