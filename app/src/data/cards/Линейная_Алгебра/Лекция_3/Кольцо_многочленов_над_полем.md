@@ id=warmup-idea type=concept src="0. Разминка (продолжение темы «Комплексные числа»)"
Q: Как свести сумму $S_n(x) = \sum_{k=0}^{n}\cos kx$ к геометрической прогрессии и какие три инструмента при этом нужны?
A:
Инструменты:
- формула Эйлера: $z = e^{ix} = \cos x + i\sin x$, причём $|z| = 1$ (из $\cos^2 x + \sin^2 x = 1$);
- $\operatorname{Re} z = \frac{z + \bar z}{2}$;
- $z\bar z = |z|^2$ — избавление от комплексного числа в знаменателе.

Идея: $\cos kx = \operatorname{Re}(e^{ikx}) = \operatorname{Re}(z^k)$. Так как $\operatorname{Re}$ линейна (действительная часть суммы — сумма действительных частей),
$$S_n(x) = \operatorname{Re}\Big(\sum_{k=0}^{n} z^k\Big) = \operatorname{Re}\frac{z^{n+1} - 1}{z - 1},$$
где сумма прогрессии берётся при $z \ne 1$, то есть $x \ne 2\pi m$.

@@ id=warmup-derivation type=proof src="0. Разминка (продолжение темы «Комплексные числа»)"
Q: Доведи вычисление $\operatorname{Re}\dfrac{z^{n+1} - 1}{z - 1}$ при $|z| = 1$ до формулы для $S_n(x)$: чему равен знаменатель и числитель после домножения на $\bar z - 1$?
A:
Домножаем на $\bar z - 1$, сопряжённое к $z - 1$.

**Знаменатель** (вещественный):
$$(z - 1)(\bar z - 1) = z\bar z - z - \bar z + 1 = |z|^2 - 2\operatorname{Re} z + 1 = 2 - 2\cos x = 2(1 - \cos x) = 4\sin^2\frac x2.$$

**Числитель**, с учётом $z\bar z = 1$:
$$(z^{n+1} - 1)(\bar z - 1) = z^{n+1}\bar z - z^{n+1} - \bar z + 1 = z^n - z^{n+1} - \bar z + 1.$$
Его действительная часть: $\cos nx - \cos(n+1)x - \cos x + 1$.

Так как знаменатель вещественный, действительная часть дроби — это действительная часть числителя, делённая на знаменатель:
$$\sum_{k=0}^{n}\cos kx = \frac{1 - \cos x + \cos nx - \cos(n+1)x}{2(1 - \cos x)},\qquad x \ne 2\pi m.$$

@@ id=warmup-check type=calc src="0. Разминка (продолжение темы «Комплексные числа»)"
Q: Проверь формулу для $S_n(x)$ в трёх случаях: $n = 1$ (для любого $x$), $n = 4$ при $x = \frac\pi2$, и выясни, чему равна сумма при $x = 2\pi m$.
A:
Формула: $S_n(x) = \dfrac{1 - \cos x + \cos nx - \cos(n+1)x}{2(1 - \cos x)}$.

- $n = 1$: $\dfrac{1 - \cos x + \cos x - \cos 2x}{2(1 - \cos x)} = \dfrac{1 - \cos 2x}{2(1 - \cos x)} = \dfrac{2\sin^2 x}{4\sin^2\frac x2} = 2\cos^2\frac x2 = 1 + \cos x$ — совпадает с прямой суммой $\cos 0 + \cos x$.
- $n = 4$, $x = \frac\pi2$: прямо $1 + 0 - 1 + 0 + 1 = 1$. По формуле $\cos x = 0$, $\cos 4x = \cos 2\pi = 1$, $\cos 5x = \cos\frac{5\pi}{2} = 0$: $\dfrac{1 - 0 + 1 - 0}{2\cdot 1} = 1$. ✓
- $x = 2\pi m$: тогда $z = 1$, знаменатель формулы равен нулю — формула неприменима, но все косинусы равны $1$, поэтому $S_n = n + 1$.

@@ id=poly-def type=term src="1.1 Определение многочлена"
Q: Что такое многочлен над полем $K$ и его степень? Откуда берутся коэффициенты?
A:
Многочлен над полем $K$ — выражение
$$P(x) = a_n x^n + a_{n-1}x^{n-1} + \dots + a_0 = \sum_{k=0}^{n} a_k x^k,\qquad a_k \in K.$$

Коэффициенты $a_k$ берутся из поля $K$ (в $\mathbb{R}[x]$ — вещественные, в $\mathbb{C}[x]$ — комплексные). **Степень** $\deg P$ — номер старшего **ненулевого** коэффициента: если $a_n \ne 0$, то $\deg P = n$. Число $n$ в записи — лишь верхняя граница суммирования.

@@ id=poly-degree-pitfall type=pitfall src="1.1 Определение многочлена"
Q: Чему равна степень $P(x) = 0\cdot x^5 + 3x^2 + 1$ и почему условие $a_n \ne 0$ в определении степени существенно?
A:
$\deg P = 2$, а не $5$. Одно и то же выражение можно записать с лишними нулевыми старшими членами, поэтому степень определяют по реальному **старшему ненулевому** коэффициенту, а не по выписанному верхнему индексу. Без условия $a_n \ne 0$ у многочлена не было бы определённой степени.

@@ id=kx-ring type=concept src="1.2 Множество $K[x]$"
Q: Какие свойства имеет $K[x]$ относительно сложения и умножения многочленов и на какую известную структуру он похож?
A:
$K[x]$ — **коммутативное кольцо с единицей** (единица — константа $1$): сложение образует абелеву группу, умножение ассоциативно и коммутативно, выполнена дистрибутивность.

Похоже на $\mathbb{Z}$: складывать и умножать можно всегда, а деление без остатка, вообще говоря, невозможно. Вместо него вводится деление с остатком (раздел 2). Как и в $\mathbb{Z}$, поля из $K[x]$ не получается.

@@ id=kx-units type=proof src="1.2 Множество $K[x]$"
Q: Какие многочлены обратимы в $K[x]$? Докажи, что $K[x]$ не поле, и покажи, что $x$ необратим.
A:
Пусть $PQ = 1$. По свойству степеней $\deg P + \deg Q = \deg 1 = 0$, а обе степени неотрицательны (оба многочлена ненулевые), значит $\deg P = \deg Q = 0$. Итак, обратимы **только ненулевые константы**.

Поэтому $K[x]$ — не поле. Например, $x$ не имеет обратного: $\deg(x\cdot Q) = 1 + \deg Q \ge 1 \ne 0$ ни при каком $Q$. (Дробь $\tfrac1x$ — уже не многочлен.)

@@ id=deg-properties type=theorem src="1.3 Степени многочленов: свойства"
Q: Сформулируй свойства степени: для произведения, суммы, ненулевой константы и нулевого многочлена. Зачем $\deg 0 = -\infty$?
A:
1. $\deg(PQ) = \deg P + \deg Q$;
2. $\deg(P + Q) \le \max(\deg P, \deg Q)$;
3. $\deg C = 0$ для константы $C \ne 0$;
4. $\deg 0 = -\infty$.

Соглашение $\deg 0 = -\infty$ нужно, чтобы свойства 1 и 2 работали без исключений: например, $\deg(0\cdot Q) = -\infty = -\infty + \deg Q$, а неравенство в свойстве 2 остаётся верным, если один из многочленов нулевой.

@@ id=deg-field-condition type=concept src="1.3 Степени многочленов: свойства"
Q: Где в свойстве $\deg(PQ) = \deg P + \deg Q$ используется, что $K$ — поле? Что может сломаться над кольцом с делителями нуля?
A:
Старшие члены $a_n x^n$ и $b_m x^m$ перемножаются в $a_n b_m x^{n+m}$. Чтобы степень произведения была ровно $n + m$, нужно $a_n b_m \ne 0$. В поле делителей нуля нет: из $a_n \ne 0$ и $b_m \ne 0$ следует $a_n b_m \ne 0$.

Над кольцом $\mathbb{Z}_4$, где $2\cdot 2 = 0$: для $P = Q = 2x$ имеем $\deg P + \deg Q = 2$, но $PQ = 4x^2 = 0$ и $\deg(PQ) = -\infty$. Формула нарушена.

@@ id=deg-sum-strict type=calc src="1.3 Степени многочленов: свойства"
Q: Приведи пример, где $\deg(P + Q) < \max(\deg P, \deg Q)$, и скажи, когда равенство $\deg(P+Q) = \max(\deg P,\deg Q)$ гарантировано.
A:
Пусть $P = x^2 + 1$, $Q = -x^2 + x$. Тогда $\deg P = \deg Q = 2$, а
$$P + Q = x + 1,\qquad \deg(P + Q) = 1 < 2.$$
Старшие члены $x^2$ и $-x^2$ сократились.

Равенство гарантировано, если $\deg P \ne \deg Q$ (старший член большего никто не сокращает) или если старшие члены не сокращаются.

@@ id=deg-zero-pitfall type=pitfall src="1.3 Степени многочленов: свойства"
Q: Чем «многочлен нулевой степени» отличается от «нулевого многочлена» и какие степени у них?
A:
- **Многочлен нулевой степени** — ненулевая константа $C = a_0 \ne 0$; $\deg C = 0$.
- **Нулевой многочлен** $P(x) \equiv 0$; для него $\deg = -\infty$, а не $0$.

Путать их нельзя: $\deg 0 = 0$ дало бы $\deg(0\cdot Q) = \deg Q$, что противоречит свойству 1. Ненулевая константа обратима в $K[x]$, а нулевой многочлен нет; делить на нулевой многочлен нельзя.

@@ id=division-theorem type=theorem src="2.1 Формулировка теоремы"
Q: Сформулируй теорему о делении многочленов с остатком: условия, что именно утверждается и как называются $Q$ и $R$.
A:
Пусть $A(x), B(x) \in K[x]$ и $B(x) \ne 0$. Тогда существуют **единственные** $Q(x), R(x) \in K[x]$ такие, что
$$A(x) = B(x)\,Q(x) + R(x),\qquad \deg R(x) < \deg B(x).$$

$Q$ — неполное частное, $R$ — остаток. Это аналог деления целых чисел с остатком, где вместо «остаток меньше делителя» стоит «**степень** остатка меньше степени делителя». Остаток может быть нулевым многочленом ($\deg = -\infty < \deg B$).

@@ id=division-calc type=calc src="2.1 Формулировка теоремы"
Q: Раздели с остатком $A = x^4 - 3x^3 + 2x - 5$ на $B = x^2 - x + 1$ уголком и проверь результат.
A:
Записываем $A = x^4 - 3x^3 + 0x^2 + 2x - 5$ и по шагам уничтожаем старший член:

1. $x^2\cdot B = x^4 - x^3 + x^2$. Вычитаем: $-2x^3 - x^2 + 2x - 5$.
2. $-2x\cdot B = -2x^3 + 2x^2 - 2x$. Вычитаем: $-3x^2 + 4x - 5$.
3. $-3\cdot B = -3x^2 + 3x - 3$. Вычитаем: $x - 2$.

Степень $x - 2$ равна $1 < 2 = \deg B$, останавливаемся:
$$Q = x^2 - 2x - 3,\qquad R = x - 2.$$

Проверка: $(x^2 - x + 1)(x^2 - 2x - 3) = x^4 - 3x^3 + x - 3$, плюс $R = x - 2$ даёт $x^4 - 3x^3 + 2x - 5$. ✓

@@ id=division-existence type=proof src="2.2 Доказательство существования (метод математической индукции)"
Q: Докажи существование деления с остатком индукцией по $n = \deg A$ (при фиксированном $m = \deg B$). Какой одночлен нужен на шаге индукции и где здесь используется, что $K$ — поле?
A:
**База** $n < m$ (включая $A = 0$): $Q = 0$, $R = A$; $\deg R = \deg A < m$.

**Переход.** Пусть утверждение верно для степеней $\le n$, а $\deg A = n + 1 \ge m$, $A = a_{n+1}x^{n+1} + \dots$, $B = b_m x^m + \dots$, $b_m \ne 0$. Возьмём
$$\widetilde A = A - \frac{a_{n+1}}{b_m}\,x^{n+1-m}B.$$
Старший член вычитаемого равен $a_{n+1}x^{n+1}$, он сокращается, поэтому $\deg\widetilde A \le n$. По предположению индукции $\widetilde A = B\widetilde Q + \widetilde R$, $\deg\widetilde R < m$. Тогда
$$A = B\Big(\widetilde Q + \frac{a_{n+1}}{b_m}x^{n+1-m}\Big) + \widetilde R,$$
то есть $Q = \widetilde Q + \frac{a_{n+1}}{b_m}x^{n+1-m}$, $R = \widetilde R$. $\blacksquare$

Поле нужно ради деления на $b_m$: в $\mathbb{Z}[x]$ нельзя поделить $x^2$ на $2x + 1$ (потребовался бы коэффициент $\tfrac12$). Это формализация деления уголком.

@@ id=division-uniqueness type=proof src="2.3 Доказательство единственности"
Q: Докажи единственность $Q$ и $R$ в теореме о делении с остатком. Какие свойства степени использованы?
A:
Пусть $A = BQ + R = BQ^* + R^*$, $\deg R, \deg R^* < m = \deg B$. Вычитая, получаем
$$B\,(Q - Q^*) = R^* - R.$$

Допустим, $Q \ne Q^*$. По свойству 1: $\deg\big(B(Q - Q^*)\big) = m + \deg(Q - Q^*) \ge m$ (второй множитель ненулевой, его степень $\ge 0$). По свойству 2: $\deg(R^* - R) \le \max(\deg R^*, \deg R) < m$.

Один и тот же многочлен не может иметь степень и $\ge m$, и $< m$ — противоречие. Значит $Q = Q^*$, тогда $R^* - R = B\cdot 0 = 0$, и $R = R^*$. $\blacksquare$

@@ id=bezout-theorem type=theorem src="2.4 Теорема Безу"
Q: Сформулируй теорему Безу и докажи её, исходя из теоремы о делении с остатком.
A:
**Теорема.** Остаток от деления $P(x)$ на $(x - c)$ равен $P(c)$:
$$P(x) = (x - c)\,Q(x) + P(c).$$

**Доказательство.** Делим $P$ на $B = x - c$ (степень $1$): остаток $R$ имеет степень $< 1$, то есть это константа (ненулевая или нулевой многочлен): $P(x) = (x - c)Q(x) + R$. Подставим $x = c$:
$$P(c) = (c - c)Q(c) + R = 0\cdot Q(c) + R = R.$$
Значит $R = P(c)$. $\blacksquare$

Ключевая идея: остаток — константа, а подстановка $x = c$ обнуляет слагаемое $(x - c)Q(x)$.

@@ id=bezout-calc type=calc src="2.4 Теорема Безу"
Q: Найди остатки: (а) от деления $x^{10} - 3x + 5$ на $x + 1$; (б) от деления $x^3 - 2x + 7$ на $2x - 1$.
A:
**(а)** $x + 1 = x - (-1)$, поэтому $c = -1$ и остаток равен
$$P(-1) = (-1)^{10} - 3(-1) + 5 = 1 + 3 + 5 = 9.$$

**(б)** $2x - 1 = 2\big(x - \tfrac12\big)$: деление на $2\big(x - \tfrac12\big)$ даёт тот же остаток, что на $x - \tfrac12$ (остаток — константа, а множитель $2$ уходит в частное). Поэтому
$$R = P\big(\tfrac12\big) = \tfrac18 - 1 + 7 = \tfrac{49}{8}.$$

Типичная ошибка — взять $c = 1$ в (а) или $c = 2$ в (б): надо подставлять **корень делителя**.

@@ id=root-def type=term src="2.5 Корень многочлена"
Q: Что такое корень многочлена и чем он связан с делимостью на $x - c$? Докажи оба направления.
A:
$c \in K$ — **корень** $P(x) \in K[x]$, если $P(c) = 0$.

**Следствие из теоремы Безу:** $c$ — корень $\iff P(x) = (x - c)Q(x)$ (остаток от деления на $x - c$ равен нулю).

- ($\Rightarrow$) По Безу остаток равен $P(c) = 0$, поэтому деление нацело.
- ($\Leftarrow$) Если $P = (x - c)Q$, то $P(c) = 0\cdot Q(c) = 0$.

Корень ищется в поле $K$: у $x^2 + 1$ в $\mathbb{R}$ корней нет, а в $\mathbb{C}$ есть $\pm i$.

@@ id=horner-calc type=calc src="2.6 Разбор примера"
Q: Покажи, что $c = 1$ — корень $P(x) = x^3 - 3x^2 + 4x - 2$, и разложи $P$ на множители схемой Горнера. Что даст та же схема при $c = 2$?
A:
$P(1) = 1 - 3 + 4 - 2 = 0$, значит по Безу $P(x) = (x - 1)Q(x)$, $\deg Q = 2$.

Схема Горнера: сносим старший коэффициент, дальше «предыдущий $\cdot\,c$ + следующий коэффициент».

| | $1$ | $-3$ | $4$ | $-2$ |
| --- | --- | --- | --- | --- |
| $c = 1$ | $1$ | $-3 + 1 = -2$ | $4 + (-2) = 2$ | $-2 + 2 = 0$ (остаток) |

Последнее число — остаток $0$, остальные — коэффициенты частного: $Q = x^2 - 2x + 2$.
$$P(x) = (x - 1)(x^2 - 2x + 2).$$
Проверка: $(x - 1)(x^2 - 2x + 2) = x^3 - 2x^2 + 2x - x^2 + 2x - 2 = x^3 - 3x^2 + 4x - 2$. ✓

При $c = 2$ получаем строку $1,\ -1,\ 2,\ 2$: остаток $2 = P(2) = 8 - 12 + 8 - 2$. ✓ — не корень, но схема всё равно считает значение $P(c)$.

Q: Подбери корень $P(x) = 2x^3 - 5x^2 + 4$ среди $\pm1, \pm2, \pm4, \pm\tfrac12$, разложи по Горнеру и найди остальные корни.
A:
$P(1) = 1 \ne 0$, $P(-1) = -3 \ne 0$, $P(2) = 16 - 20 + 4 = 0$ — корень $c = 2$.

Коэффициенты $2, -5, 0, 4$ (нулевой при $x$ обязателен!):

| | $2$ | $-5$ | $0$ | $4$ |
| --- | --- | --- | --- | --- |
| $c = 2$ | $2$ | $-5 + 4 = -1$ | $0 - 2 = -2$ | $4 - 4 = 0$ |

$$P(x) = (x - 2)(2x^2 - x - 2).$$
Проверка: $(x - 2)(2x^2 - x - 2) = 2x^3 - x^2 - 2x - 4x^2 + 2x + 4 = 2x^3 - 5x^2 + 4$. ✓

Остальные корни: $2x^2 - x - 2 = 0$, $D = 1 + 16 = 17$, $x = \dfrac{1 \pm \sqrt{17}}{4}$. Вывод: три корня $2,\ \frac{1 + \sqrt{17}}{4},\ \frac{1 - \sqrt{17}}{4}$.

@@ id=gauss-theorem type=theorem src="3.1 Теорема Гаусса"
Q: Сформулируй теорему Гаусса (основную теорему алгебры). Чем $\mathbb{C}$ отличается от $\mathbb{R}$ в этом смысле?
A:
**Теорема.** Любой многочлен $P(x) \in \mathbb{C}[x]$ степени $\deg P \ge 1$ имеет хотя бы один корень в $\mathbb{C}$.

Условие $\deg P \ge 1$ существенно: ненулевая константа корней не имеет. Над $\mathbb{R}$ аналога нет: $x^2 + 1$ — непостоянный многочлен без вещественных корней. Поле $\mathbb{C}$ «достаточно велико»: любое уравнение $P(x) = 0$ с непостоянным $P$ в нём разрешимо (поле алгебраически замкнуто).

@@ id=full-factorization type=theorem src="3.2 Следствие: полное разложение на множители над $\mathbb{C}$"
Q: Сформулируй следствие теоремы Гаусса о полном разложении на линейные множители и объясни, как оно выводится. Зачем в записи $a_n$?
A:
Любой $P(x) \in \mathbb{C}[x]$ степени $n \ge 1$ раскладывается:
$$P(x) = a_n(x - c_1)(x - c_2)\cdots(x - c_n),$$
$a_n$ — старший коэффициент, $c_i$ — корни.

Вывод: по Гауссу есть корень $c_1$; по следствию из Безу $P = (x - c_1)Q_1$, $\deg Q_1 = n - 1$. Если $n - 1 \ge 1$, применяем то же к $Q_1$ и т. д. После $n$ шагов остаётся константа — старший коэффициент $a_n$.

Константа обязательна: без $a_n$ (при $a_n \ne 1$) равенство неверно — сравните коэффициенты при $x^n$.

@@ id=factorization-calc type=calc src="3.2 Следствие: полное разложение на множители над $\mathbb{C}$"
Q: Разложи $z^4 - 1$ на линейные множители над $\mathbb{C}$ и $2z^2 + 8$ — как $a_n(\dots)(\dots)$. Сколько всего корней у многочлена степени $n$ и почему?
A:
- $z^4 - 1 = 0 \iff z^4 = 1$: корни четвёртой степени из $1$ — $1,\ i,\ -1,\ -i$. Поэтому $z^4 - 1 = (z - 1)(z + 1)(z - i)(z + i)$. Проверка: $(z - 1)(z + 1) = z^2 - 1$, $(z - i)(z + i) = z^2 + 1$, произведение $z^4 - 1$. ✓
- $2z^2 + 8 = 2(z^2 + 4) = 2(z - 2i)(z + 2i)$, корни $\pm 2i$, старший коэффициент $a_2 = 2$.

Всего у многочлена степени $n$ над $\mathbb{C}$ ровно $n$ корней, если считать кратность; различных корней не больше $n$ (число линейных множителей равно степени).

@@ id=multiplicity-def type=term src="3.3 Кратность корня"
Q: Что такое кратность корня? Определи кратности корней у $P(x) = (x - 2)^3(x - 5)$ и скажи, как кратности связаны со степенью.
A:
Если в полном разложении множитель $(x - c)$ встречается $k$ раз, то $c$ — корень **кратности $k$**; при $k = 1$ корень **простой**.

У $P = (x - 2)^3(x - 5)$: корень $2$ имеет кратность $3$, корень $5$ — простой (кратность $1$). Сумма кратностей равна степени: $3 + 1 = 4 = \deg P$. Поэтому «ровно $n$ корней» верно только с учётом кратности.

@@ id=multiplicity-horner type=algo src="3.3 Кратность корня"
Q: Как найти кратность корня $c$ повторным делением по Горнеру? Найди кратность корня $1$ у $P(x) = x^4 - 3x^3 + 3x^2 - x$.
A:
Кратность $c$ — наибольшее $k$, при котором $(x - c)^k$ делит $P$. Делим по Горнеру на $(x - c)$, пока остаток нулевой; число успешных делений и есть кратность.

Коэффициенты $P$: $1, -3, 3, -1, 0$.
1. $c = 1$: $1,\ -2,\ 1,\ 0,\ 0$ — остаток $0$, частное $x^3 - 2x^2 + x$.
2. Для $1, -2, 1, 0$: $1,\ -1,\ 0,\ 0$ — остаток $0$, частное $x^2 - x$.
3. Для $1, -1, 0$: $1,\ 0,\ 0$ — остаток $0$, частное $x$.
4. Для $1, 0$: $1,\ 1$ — остаток $1 \ne 0$, стоп.

Три успешных деления — кратность $3$. Действительно, $P = x(x - 1)^3$.

@@ id=conj-roots-theorem type=theorem src="4.1 Теорема о сопряжённых корнях"
Q: Сформулируй теорему о сопряжённых корнях. Почему нужна вещественность коэффициентов?
A:
**Теорема.** Если $P(x) = \sum a_k x^k$ имеет **вещественные** коэффициенты и $c \in \mathbb{C}$ — корень, то $\bar c$ — тоже корень. Невещественные корни идут парами $c, \bar c$.

Содержательна для $c = a + ib$, $b \ne 0$ (для вещественного $c$ равенство $c = \bar c$ тривиально).

Условие вещественности коэффициентов существенно: у $P(x) = x - i \in \mathbb{C}[x]$ корень $i$, но $\bar i = -i$ — не корень ($-i - i = -2i \ne 0$).

@@ id=conj-roots-proof type=proof src="4.2 Доказательство"
Q: Докажи теорему о сопряжённых корнях: где используется вещественность коэффициентов и свойства сопряжения?
A:
Подставим $\bar c$ и используем $(\bar c)^k = \overline{c^k}$ (сопряжение произведения):
$$P(\bar c) = \sum_{k=0}^{n} a_k\,\overline{c^k}.$$

Коэффициенты вещественны, поэтому $a_k = \overline{a_k}$. Далее сопряжение суммы и произведения — сумма и произведение сопряжённых:
$$\sum a_k\,\overline{c^k} = \sum \overline{a_k}\,\overline{c^k} = \overline{\sum a_k c^k} = \overline{P(c)}.$$

Так как $P(c) = 0$, то $\overline{P(c)} = \bar 0 = 0$, то есть $P(\bar c) = 0$. $\blacksquare$

Единственное место, где нужна вещественность коэффициентов, — переход $a_k = \overline{a_k}$.

@@ id=real-factorization type=theorem src="4.3 Разложение многочлена над $\mathbb{R}$ на множители"
Q: Сформулируй теорему о разложении многочлена с вещественными коэффициентами и объясни, как из неё и из теоремы о сопряжённых корнях получается вывод. Почему квадратичные множители неприводимы?
A:
**Теорема.** Любой $P(x) \in \mathbb{R}[x]$ раскладывается в произведение линейных и неприводимых квадратичных многочленов с вещественными коэффициентами.

Почему: берём полное разложение над $\mathbb{C}$. Вещественные корни дают множители $(x - c)$. Невещественные корни разбиваются на сопряжённые пары, и каждая пара склеивается в вещественный множитель
$$(x - c)(x - \bar c) = x^2 - 2\operatorname{Re}(c)\,x + |c|^2.$$

Его корни $c, \bar c$ невещественны, то есть дискриминант $D < 0$, и вещественных линейных множителей у него нет — он **неприводим над $\mathbb{R}$**.

Следствие: многочлен нечётной степени над $\mathbb{R}$ имеет хотя бы один вещественный корень (нечётную степень нельзя набрать из одних квадратичных множителей).

@@ id=real-factorization-calc type=calc src="4.3 Разложение многочлена над $\mathbb{R}$ на множители"
Q: Разложи над $\mathbb{R}$ на неприводимые множители: (а) $x^4 + 4$; (б) $x^6 - 1$. Найди предварительно комплексные корни.
A:
**(а)** $x^4 = -4 = 4(\cos\pi + i\sin\pi)$; корни $\sqrt2\left(\cos\frac{\pi + 2\pi k}{4} + i\sin\frac{\pi + 2\pi k}{4}\right)$, то есть $1 + i,\ -1 + i,\ -1 - i,\ 1 - i$. Сопряжённые пары: $\{1 \pm i\}$ и $\{-1 \pm i\}$:
- $(x - 1 - i)(x - 1 + i) = x^2 - 2x + 2$;
- $(x + 1 - i)(x + 1 + i) = x^2 + 2x + 2$.
$$x^4 + 4 = (x^2 - 2x + 2)(x^2 + 2x + 2).$$
Проверка: $(x^2 + 2)^2 - (2x)^2 = x^4 + 4x^2 + 4 - 4x^2 = x^4 + 4$. ✓

**(б)** Корни — шестые корни из $1$: $\pm1$ и $\frac{\pm1 \pm i\sqrt3}{2}$. Вещественные дают $(x - 1)(x + 1)$; пары $\frac{1 \pm i\sqrt3}{2}$ и $\frac{-1 \pm i\sqrt3}{2}$ дают $x^2 - x + 1$ и $x^2 + x + 1$ (дискриминанты $-3 < 0$):
$$x^6 - 1 = (x - 1)(x + 1)(x^2 + x + 1)(x^2 - x + 1).$$

@@ id=real-factorization-example type=calc src="4.3 Разложение многочлена над $\mathbb{R}$ на множители"
Q: Для $P(x) = (x - 1)(x^2 - 2x + 2)$ найди комплексные корни квадратного множителя и покажи, что он — это $x^2 - 2\operatorname{Re}(c)\,x + |c|^2$ для корня $c$.
A:
Для $x^2 - 2x + 2$: $D = 4 - 8 = -4 < 0$, вещественных корней нет; комплексные корни
$$x = \frac{2 \pm 2i}{2} = 1 \pm i.$$

Для $c = 1 + i$: $2\operatorname{Re}(c) = 2$, $|c|^2 = 1 + 1 = 2$, то есть $x^2 - 2x + 2$ — ровно тот множитель, что предсказывает формула. Значит над $\mathbb{R}$ разложение $(x - 1)(x^2 - 2x + 2)$ уже полное, а над $\mathbb{C}$ оно продолжается:
$$P(x) = (x - 1)(x - 1 - i)(x - 1 + i).$$

@@ id=fields-compare type=compare src="4.3 Разложение многочлена над $\mathbb{R}$ на множители"
Q: Сравни многочлены над $\mathbb{C}$ и над $\mathbb{R}$: гарантия существования корня, какие многочлены неприводимы, как выглядит разложение.
A:
| | $\mathbb{C}[x]$ | $\mathbb{R}[x]$ |
| --- | --- | --- |
| Есть ли корень у непостоянного $P$ | да (теорема Гаусса) | не обязательно ($x^2 + 1$) |
| Неприводимые многочлены | только линейные | линейные и квадратичные с $D < 0$ |
| Разложение | $a_n\prod (x - c_i)$, $n$ множителей | линейные $\times$ квадратичные |
| Невещественные корни | любые | парами $c, \bar c$ |

Над $\mathbb{R}$ степень неприводимого многочлена не превосходит $2$, и всё определяется тем, что вещественные коэффициенты «замыкают» комплексные корни парами.

@@ id=vieta-notation type=term src="5. Формулы Виета (обобщение на степень $n$)"
Q: Что обозначает $\sum_{i<j<k} c_i c_j c_k$ и как выглядят формулы Виета в общем виде для $P(x) = a_n x^n + \dots + a_0$ с корнями $c_1, \dots, c_n$?
A:
$\sum_{i<j<k}c_ic_jc_k$ — сумма произведений корней по тройкам **различных** индексов $i < j < k$ ($c_1c_2c_3,\ c_1c_2c_4,\ c_1c_3c_4,\dots$).

В общем виде для $r = 1, \dots, n$:
$$e_r = \sum_{i_1 < \dots < i_r} c_{i_1}\cdots c_{i_r} = (-1)^r\,\frac{a_{n-r}}{a_n}.$$

Частные случаи: $r = 3$ — $\sum_{i<j<k}c_ic_jc_k = -\dfrac{a_{n-3}}{a_n}$; $r = n$ (в сумме одно слагаемое) — $c_1c_2\cdots c_n = (-1)^n\dfrac{a_0}{a_n}$; $r = 1$ — $\sum c_i = -\dfrac{a_{n-1}}{a_n}$.

@@ id=vieta-sign type=proof src="5. Формулы Виета (обобщение на степень $n$)"
Q: Откуда берутся формулы Виета и знак $(-1)^r$? Выведи для $n = 3$.
A:
Формулы получаются сравнением двух записей: $P(x) = a_n x^n + \dots + a_0$ и $P(x) = a_n(x - c_1)\cdots(x - c_n)$. Раскроем скобки для $n = 3$:
$$(x - c_1)(x - c_2)(x - c_3) = x^3 - (c_1 + c_2 + c_3)\,x^2 + (c_1c_2 + c_1c_3 + c_2c_3)\,x - c_1c_2c_3.$$

Приравняем коэффициенты при $x^3, x^2, x, 1$ в $a_3(\dots)$ и в $a_3x^3 + a_2x^2 + a_1x + a_0$:
$$e_1 = -\frac{a_2}{a_3},\qquad e_2 = \frac{a_1}{a_3},\qquad e_3 = -\frac{a_0}{a_3}.$$

В общем случае сумма $e_r$ входит в коэффициент при $x^{n-r}$ со знаком $(-1)^r$ — каждый из $r$ выбранных множителей даёт $-c_i$ вместо $x$.

@@ id=vieta-calc type=calc src="5. Формулы Виета (обобщение на степень $n$)"
Q: Проверь формулы Виета для $P(x) = x^3 - 3x^2 + 4x - 2$ с корнями $1,\ 1 + i,\ 1 - i$ и составь многочлен $2x^3 + \dots$ с корнями $1, -1, 3$.
A:
**Проверка.** $a_3 = 1,\ a_2 = -3,\ a_1 = 4,\ a_0 = -2$.

- $e_1 = 1 + (1 + i) + (1 - i) = 3 = -\frac{-3}{1}$ ✓;
- $e_2 = 1(1 + i) + 1(1 - i) + (1 + i)(1 - i) = 2 + 2 = 4 = \frac{4}{1}$ ✓;
- $e_3 = 1\cdot(1 + i)(1 - i) = 2 = -\frac{-2}{1}$ ✓.

**Построение.** $2(x - 1)(x + 1)(x - 3) = 2(x^2 - 1)(x - 3) = 2x^3 - 6x^2 - 2x + 6$. Проверка по формулам Виета: $e_1 = 1 - 1 + 3 = 3 = -\frac{-6}{2}$; $e_2 = -1 + 3 - 3 = -1 = \frac{-2}{2}$; $e_3 = -3 = -\frac{6}{2}$. ✓

Заметим: произведение корней и знак $(-1)^n$ — частая ловушка; для нечётного $n$ произведение корней равно $-\frac{a_0}{a_n}$.
