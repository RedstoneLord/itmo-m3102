# itmo-m3102

Репозиторий с учебными материалами группы **М3102** (ИТМО): конспекты лекций и практик, аудиозаписи лекций, лабораторные работы и вспомогательные материалы (учебники) по дисциплинам первого курса.

## Структура репозитория

| Папка | Что внутри |
|---|---|
| [`Конспекты/`](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%D1%8B/) | Конспекты лекций и практик по предметам (`.md`, `.pdf`, `.docx`, `.html`) |
| [`Записи лекций/`](%D0%97%D0%B0%D0%BF%D0%B8%D1%81%D0%B8%20%D0%BB%D0%B5%D0%BA%D1%86%D0%B8%D0%B9/) | Аудиозаписи лекций |
| [`Лабораторные/`](%D0%9B%D0%B0%D0%B1%D0%BE%D1%80%D0%B0%D1%82%D0%BE%D1%80%D0%BD%D1%8B%D0%B5/) | Лабораторные работы и отчёты по ним |
| [`Материалы/`](%D0%9C%D0%B0%D1%82%D0%B5%D1%80%D0%B8%D0%B0%D0%BB%D1%8B/) | Учебники и вспомогательные материалы (`.djvu`, `.pdf`) |

> Некоторые конспекты продублированы в нескольких форматах (`.md` + `.pdf`, иногда ещё `.docx`/`.html`) — это один и тот же материал, просто выбирайте удобный вам формат.

## Расшифровка сокращений

| Сокращение | Дисциплина |
|---|---|
| ОП | Основы программирования |
| ДМ | Дискретная математика |
| ИСРПО | Индивидуальные средства разработки ПО |
| Линал | Линейная алгебра |
| Матан | Математический анализ |
| АиСД | Алгоритмы и структуры данных |

## Конспекты по предметам

Внутри `Конспекты/` — папка на каждый предмет, внутри предмета — папка на каждую лекцию/практику.

- **АиСД** → [`Конспекты/АиСД/`](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%D1%8B/%D0%90%D0%B8%D0%A1%D0%94/)
  — 1 лекция, 2 лекция, 2 прак
- **ДМ** → [`Конспекты/ДМ/`](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%D1%8B/%D0%94%D0%9C/)
  — 1 лек, 1 прак, 2 лек, 3 лек
- **ИСРПО** → [`Конспекты/ИСРПО/`](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%D1%8B/%D0%98%D0%A1%D0%A0%D0%9F%D0%9E/)
  — 1 лек
- **Линал** → [`Конспекты/Линал/`](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%D1%8B/%D0%9B%D0%B8%D0%BD%D0%B0%D0%BB/)
  — 1 лек, 1 прак, 2 лек, 3 лек
- **Матан** → [`Конспекты/Матан/`](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%D1%8B/%D0%9C%D0%B0%D1%82%D0%B0%D0%BD/)
  — 1 лек, 2-3 лек, 4 лекция
- **ОП** → [`Конспекты/ОП/`](%D0%9A%D0%BE%D0%BD%D1%81%D0%BF%D0%B5%D0%BA%D1%82%D1%8B/%D0%9E%D0%9F/)
