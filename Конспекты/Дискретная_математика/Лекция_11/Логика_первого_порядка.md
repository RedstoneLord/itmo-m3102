## Язык и модели

### Сигнатура, переменные и выражения

В логике высказываний атом представляет утверждение целиком. Чтобы отдельно говорить об объектах, их свойствах и отношениях, нужен язык первого порядка. Например, утверждение «каждое число либо чётно, либо нечётно» записывается одной конечной формулой даже для бесконечного домена:

$$
\forall x.\,(\mathrm{Even}(x)\lor\mathrm{Odd}(x)).
$$

:::meaning
**Сигнатура** $\Sigma=(C,F,R)$ состоит из трёх попарно непересекающихся множеств. $C$ содержит символы констант, $F$ — функциональные символы, $R$ — предикатные. Арность — число аргументов. У символов из $F$ и $R$ она положительна, у констант равна нулю.

Переменные образуют отдельное счётное множество $\mathrm{Var}=\{x_0,x_1,x_2,\ldots\}$, не пересекающееся с сигнатурой.
:::

У арифметики можно взять $\Sigma_{\mathrm{arith}}=(\{0,1\},\{+\},\{\le\})$, где $+$ и $\le$ бинарны. Для графов подходит $\Sigma_{\mathrm{graph}}=(\varnothing,\varnothing,\{E\})$ с бинарным $E$. Константу включают в сигнатуру, когда понадобится имя конкретного объекта.

:::meaning
**Терм** — переменная, константа или $f(t_1,\ldots,t_n)$, где $f$ имеет арность $n$, а все $t_i$ — термы. Терм обозначает объект.

**Атом** — $P(t_1,\ldots,t_n)$ с предикатным символом подходящей арности или равенство термов $t_1=t_2$.

**Формула** — атом либо результат применения связок $\neg,\land,\lor,\to,\leftrightarrow$ к формулам подходящего числа или квантора $\forall x$, $\exists x$ к одной формуле. Других способов построения нет.
:::

У арифметического терма $+(x,1)$ два аргумента-терма. Выражение $\le(x,1)$ — атом, а $\le(x,1)\land\exists y.\,(y=+(x,1))$ — составная формула. Выражение $+(\le(x,1),1)$ не является термом, поскольку первый аргумент — атом. В арифметических примерах можно писать функции и отношения в привычном виде, например $x+1$ и $x<y$.

### Дерево разбора и область действия

Для $\forall x.\,(P(x)\to\exists y.\,Q(x,f(y)))$ в корне стоит последняя операция построения — $\forall x$. В её области действия вся импликация. Внутренний $\exists y$ охватывает только $Q(x,f(y))$.

```tree
title: Дерево разбора формулы
∀x
  →
    P(x)
      x
    ∃y
      Q(x, f(y))
        x
        f(y)
          y
```

Вхождение переменной связано, если над ним действует квантор по этой переменной. Остальные вхождения свободны. В $P(x)\land\forall x.\,Q(x)$ подстановка $x:=c$ заменяет только первое вхождение и даёт $P(c)\land\forall x.\,Q(x)$. Если свободная переменная вставляемого терма оказывается в области действия одноимённого квантора, происходит **захват**. Например, подстановка $x:=y+1$ в $\forall y.\,(x<y)$ требует предварительного переименования связанного $y$.

### Интерпретация и оценка

:::meaning
**Интерпретация** $\mathcal I=(D,\cdot^{\mathcal I})$ задаёт непустой домен $D$ и сопоставляет символам сигнатуры значения $c^{\mathcal I}\in D$, $f^{\mathcal I}:D^n\to D$, $P^{\mathcal I}\subseteq D^n$. Символ равенства логический и обозначает совпадение элементов домена.

**Оценка** $\nu:\mathrm{Var}\to D$ задаёт значения переменных. С одной интерпретацией можно использовать разные оценки.
:::

На $\mathbb N$ символы $0,1,+,\le$ можно интерпретировать как числа $0$ и $1$, сложение и обычный порядок. Тогда $\forall x.\,(x\le +(x,1))$ истинна, поскольку для всякого натурального $x$ выполнено $x\le x+1$. При оценке $\nu(x)=1,\nu(y)=2$ формула $x<y$ истинна, при $\nu(x)=2,\nu(y)=1$ — ложна. Значение $\nu(z)$ здесь безразлично.

Термы вычисляют изнутри наружу. Переменная даёт $\llbracket x\rrbracket_{\mathcal I,\nu}=\nu(x)$, константа — $\llbracket c\rrbracket_{\mathcal I,\nu}=c^{\mathcal I}$. Для функции:

$$
\llbracket f(t_1,\ldots,t_n)\rrbracket_{\mathcal I,\nu}
=f^{\mathcal I}\bigl(\llbracket t_1\rrbracket_{\mathcal I,\nu},\ldots,\llbracket t_n\rrbracket_{\mathcal I,\nu}\bigr).
$$

При $\nu(x)=5,\nu(y)=2$ сначала находим значение $+(x,1)$, равное $6$, затем значение $+(+(x,1),y)$, равное $6+2=8$.

### Истинность, свидетели и порядок кванторов

Запись $\mathcal I,\nu\models\varphi$ означает истинность $\varphi$ в интерпретации $\mathcal I$ при оценке $\nu$. У атома $P(t_1,\ldots,t_n)$ проверяют, принадлежит ли кортеж значений термов отношению $P^{\mathcal I}$. У $t_1=t_2$ сравнивают значения термов. Связки работают как в логике высказываний.

:::formula
Оценка $\nu[x:=d]$ совпадает с $\nu$ вне переменной $x$ и присваивает ей $d$.

$$
\begin{aligned}
\mathcal I,\nu\models\forall x.\,\varphi
&\iff \text{для каждого }d\in D\quad\mathcal I,\nu[x:=d]\models\varphi,\\
\mathcal I,\nu\models\exists x.\,\varphi
&\iff \text{для некоторого }d\in D\quad\mathcal I,\nu[x:=d]\models\varphi.
\end{aligned}
$$
:::

На конечном домене $\forall$ работает как конъюнкция проверок по всем элементам, а $\exists$ — как дизъюнкция. На $D=\{0,1\}$ предложение $\forall x.\,(x=0\lor x=1)$ даёт $(0=0\lor 0=1)\land(1=0\lor 1=1)$, то есть истину.

:::meaning
**Свидетель** для $\exists x.\,\varphi$ — элемент $d$, при котором $\varphi$ истинна для $x=d$. Элемент, на котором $\varphi$ ложна, служит **контрпримером** к $\forall x.\,\varphi$.
:::

На $\mathbb N$ у $\exists x.\,(x+2=5)$ свидетель $3$, а у $\exists x.\,(x+x=3)$ свидетеля нет из-за чётности суммы $x+x$. Формула $\forall x.\,(x+0=x)$ проверяется для всех элементов.

:::example
При $D=\{0,1\}$ и $E^{\mathcal I}=\{(0,1),(1,0)\}$ формула $\forall x\exists y.\,E(x,y)$ истинна, поскольку ответом на $x=0$ служит $y=1$, а на $x=1$ — $y=0$. Формула $\exists y\forall x.\,E(x,y)$ ложна, поскольку после любого выбора $y$ можно взять $x=y$, а петель нет.

В игровой трактовке кванторы делают ходы слева направо. Истинность означает, что у игрока $\exists$ есть способ выполнить матрицу при любом ходе $\forall$. Свидетель может зависеть от уже сделанных ходов.
:::

### Общезначимость и выполнимость

:::meaning
Формула **выполнима**, если $\mathcal I,\nu\models\varphi$ хотя бы для одной пары интерпретации и оценки. Она **общезначима**, если это выполнено для всех пар. Общезначимость записывают $\models\varphi$.
:::

| Формула | Статус | Проверка |
|---|---|---|
| $(\forall x.\,P(x))\to\exists x.\,P(x)$ | Общезначима | Если посылка истинна, подойдёт любой элемент непустого домена |
| $\forall x.\,P(x)$ | Выполнима, но не общезначима | На $D=\{0\}$ подходит $P^{\mathcal I}=D$, а $P^{\mathcal I}=\varnothing$ даёт контрмодель |
| $(\forall x.\,P(x))\land(\exists x.\,\neg P(x))$ | Невыполнима | Свидетель правой части нарушил бы левую |

Формула $\varphi$ общезначима тогда и только тогда, когда $\neg\varphi$ невыполнима.

### Законы кванторов

:::formula
В законах отрицания квантор меняется на двойственный:

$$
\neg\forall x.\,\varphi(x)\equiv\exists x.\,\neg\varphi(x),
\qquad
\neg\exists x.\,\varphi(x)\equiv\forall x.\,\neg\varphi(x).
$$
:::

«Сдал не каждый» означает существование провалившегося, «не сдал никто» — что каждый не сдал.

Распределение работает для двух пар связок и кванторов:

$$
\begin{aligned}
\forall x.\,(\varphi(x)\land\psi(x))
 &\equiv(\forall x.\,\varphi(x))\land(\forall x.\,\psi(x)),\\
\exists x.\,(\varphi(x)\lor\psi(x))
 &\equiv(\exists x.\,\varphi(x))\lor(\exists x.\,\psi(x)).
\end{aligned}
$$

При $D=\{0,1\}$, $P^{\mathcal I}=\{0\}$ и $Q^{\mathcal I}=\{1\}$ каждый элемент удовлетворяет $P$ или $Q$, хотя ни один из предикатов не истинен на всём домене. Оба предиката имеют свидетелей, но общего свидетеля для $P\land Q$ нет.

:::remember
Если $x$ не свободна в $\psi$, то действуют переносы:

$$
\begin{aligned}
\forall x.\,(\varphi(x)\lor\psi)&\equiv(\forall x.\,\varphi(x))\lor\psi,\\
\exists x.\,(\varphi(x)\land\psi)&\equiv(\exists x.\,\varphi(x))\land\psi,\\
\forall x.\,(\varphi(x)\land\psi)&\equiv(\forall x.\,\varphi(x))\land\psi,\\
\exists x.\,(\varphi(x)\lor\psi)&\equiv(\exists x.\,\varphi(x))\lor\psi.
\end{aligned}
$$

При том же условии вынос квантора в посылку импликации меняет его вид:

$$
\begin{aligned}
\forall x.\,(\varphi(x)\to\psi)&\equiv(\exists x.\,\varphi(x))\to\psi,\\
\exists x.\,(\varphi(x)\to\psi)&\equiv(\forall x.\,\varphi(x))\to\psi.
\end{aligned}
$$
:::

:::warning
При $D=\{0,1\}$, $P^{\mathcal I}=D$, $Q^{\mathcal I}=\{1\}$ и $\nu(x)=1$ формула $\forall x.\,(P(x)\land Q(x))$ ложна из-за $x=0$. Запись $(\forall x.\,P(x))\land Q(x)$ истинна, поскольку свободное $x$ в $Q(x)$ получает значение $1$.
:::

Если $S(x)$ означает «$x$ сдал», а замкнутая формула $H$ означает «преподаватель доволен», то $\forall x.\,(S(x)\to H)$ читается как «если кто-то сдал, преподаватель доволен». На $D=\{a,b\}$ при $S^{\mathcal I}=\{a\}$ и ложном $H$ исходная формула нарушается на $a$. В форме $(\exists x.\,S(x))\to H$ посылка истинна благодаря тому же $a$, а заключение ложно.

### Правила натуральной дедукции

Терм $t$ может быть переменной, константой или выражением с функциями. В $\forall E$ и $\exists I$ подстановка $x:=t$ должна быть свободной. Параметр $a$ в $\forall I$ и $\exists E$ — свежее имя, отсутствующее в исходной формуле и остальных открытых гипотезах. В $\exists E$ оно также не должно входить в итоговое заключение.

$$
\frac{\varphi(a)}{\forall x.\,\varphi(x)}\ \forall I
\qquad
\frac{\forall x.\,\varphi(x)}{\varphi(t)}\ \forall E
$$

$$
\frac{\varphi(t)}{\exists x.\,\varphi(x)}\ \exists I
\qquad
\frac{\exists x.\,\varphi(x)\qquad [\varphi(a)]\vdash C}{C}\ \exists E
$$

:::example
**Введение $\forall$.** Временно допускаем $P(a)$, повторяем его правилом $R$ и снимаем допущение правилом $\to I$. Получаем $P(a)\to P(a)$. Теперь $a$ не входит в открытые гипотезы и можно вывести $\forall x.\,(P(x)\to P(x))$.

**Удаление $\forall$.** Из $\forall x.\,(P(x)\to Q(x))$ по $\forall E$ с $t=3$ получаем $P(3)\to Q(3)$. Вторая посылка $P(3)$ даёт $Q(3)$ по $\to E$.

**Введение $\exists$.** Из $P(3)$ по $\lor I$ получаем $P(3)\lor Q(3)$. Терм $3$ даёт экземпляр нужной формулы, поэтому по $\exists I$ выводим $\exists x.\,(P(x)\lor Q(x))$.

**Удаление $\exists$.** Посылки — $\exists x.\,P(x)$ и $\forall x.\,(P(x)\to D)$, где $D$ не зависит от $x$. Открываем подвывод с $P(a)$ для свежего $a$. Из второй посылки по $\forall E$ получаем $P(a)\to D$, затем по $\to E$ — $D$. По $\exists E$ закрываем подвывод и получаем $D$ вне его.
:::

### Силлогистика и пустой субъект

Количеством суждения называется выбор между «все» и «некоторые», качеством — утверждение или отрицание признака. Традиционные обозначения — $A,E,I,O$. Общие формы ограничивают субъект $S$ импликацией, частные требуют свидетеля, на котором выполнена конъюнкция. При пустом $S$ «Все единороги магические» истинно, а «Некоторые единороги магические» ложно. Модус Barbara остаётся корректным при пустом субъекте, поскольку прямой вывод объединяет две импликации и обходится без предположения о существовании элемента класса.

```quiz
title: Проверка: язык, модели и правила кванторов

- [ ] $P(c)\land\forall x.\,Q(c)$
- [x] $P(c)\land\forall x.\,Q(x)$
- [ ] $P(x)\land\forall x.\,Q(c)$

## Метатеория

### Теории, модели, корректность и полнота

:::meaning
**Теория** $\Gamma$ — множество замкнутых формул. Интерпретация $\mathcal I$ — её **модель**, если $\mathcal I\models\Gamma$, то есть в ней истинна каждая формула $\Gamma$.

$\Gamma\models\varphi$ означает истинность $\varphi$ во всех моделях $\Gamma$. $\Gamma\vdash\varphi$ означает существование формального вывода из $\Gamma$.
:::

Транзитивность, асимметричность и сравнимость образуют теорию строгого линейного порядка. Обычные порядки на $\mathbb N,\mathbb Z,\mathbb Q$ удовлетворяют этим требованиям. Предложение $\exists x\forall y.\,(x=y\lor x<y)$ истинно на $\mathbb N$ благодаря наименьшему элементу, ложно на $\mathbb Z$ и $\mathbb Q$. Порядок $\mathbb Q$ вдобавок плотный.

:::remember
По **корректности** $\Gamma\vdash\varphi$ влечёт $\Gamma\models\varphi$. Каждое правило сохраняет истинность при выполнении его условий. Например, истинные $\varphi$ и $\varphi\to\psi$ дают истинную $\psi$. Индукция по выводу переносит эту проверку на всё доказательство.

По **полноте** $\Gamma\models\varphi$ влечёт $\Gamma\vdash\varphi$. Вместе эти направления дают теорему Гёделя о полноте исчисления первого порядка (1930). Построение Хенкина, используемое в её доказательстве, добавляет имена свидетелям и строит модель из термов.
:::

### Полуразрешимость и неразрешимость

Алгоритм полуразрешает множество, если для каждого его элемента останавливается с ответом «да», а вне множества может работать бесконечно либо остановиться с ответом «нет». Для **общезначимости** перебирают конечные формальные выводы без посылок и проверяют каждый по правилам. Корректность исключает ложный ответ «да», полнота гарантирует, что доказательство общезначимой формулы рано или поздно встретится. Такой же поиск применим к выводимости из эффективно перечислимой теории, если перечислять её аксиомы параллельно с поиском конечных выводов.

:::example
Контрмодель к $\forall x.\,P(x)$ имеет $D=\{0\}$ и $P^{\mathcal I}=\varnothing$. Перебор доказательств без посылок никогда её не докажет. По теореме Чёрча (1936) общезначимость в логике первого порядка в общем случае неразрешима: алгоритма, останавливающегося с верным ответом на каждом входе, нет.
:::

### Компактность и нестандартные числа

:::remember
**Теорема о компактности.** Множество предложений $\Gamma$ имеет модель тогда и только тогда, когда модель имеет каждое конечное $\Gamma_0\subseteq\Gamma$.
:::

Модель всего множества удовлетворяет любой его части. Обратное направление доказываем контрапозицией. Если у $\Gamma$ нет модели, то $\Gamma\models\bot$. Полнота даёт $\Gamma\vdash\bot$. Доказательство конечно, поэтому использует только конечное $\Gamma_0$. Корректность даёт $\Gamma_0\models\bot$, то есть даже у $\Gamma_0$ модели нет.

:::example
К $\mathrm{Th}(\mathbb N)$ — всем предложениям, истинным на натуральных числах, — добавим свежую константу $c$ и аксиомы $c>S^n(0)$ для всех натуральных $n$. Для модели конечной части на $\mathbb N$ достаточно поставить $c$ выше самого большого из упомянутых числительных. Компактность даёт модель всего набора. В ней $c$ больше каждого стандартного числительного $S^n(0)$, значит, не совпадает ни с одним из них.
:::

### Лёвенгейм — Сколем и каноническая терм-модель

Если теория в счётном языке имеет бесконечную модель, то по **нисходящей** части теоремы Лёвенгейма — Сколема она имеет счётно бесконечную модель. По **восходящей** части — модель каждой бесконечной мощности $\kappa$. В первом случае носитель можно построить из счётного запаса термов, во втором — потребовать $\kappa$ попарно различных имён и применить компактность.

Для теории $T$ и замкнутых термов $t,t'$ положим $t\equiv_T t'$ тогда и только тогда, когда $T\vdash t=t'$. Аксиомы равенства дают рефлексивность, симметричность и транзитивность. Подстановка равных сохраняет значения функций и истинность предикатов, поэтому доказуемое равенство — **конгруэнтность**. Например, в $\mathrm{Th}(\mathbb N)$ из $0+0=0$ следует $S(0+0)=S(0)$, так что соответствующие классы совпадают.

:::meaning
Для непротиворечивой $T$ с хотя бы одной константой каноническая терм-структура $\mathcal M_T$ имеет домен $\mathrm{CTerm}(\Sigma)/{\equiv_T}$. Она интерпретирует константу $c$ классом $[c]$, а остальные символы — по правилам:

$$
\begin{aligned}
f^{\mathcal M_T}([t_1],\ldots,[t_n])&=[f(t_1,\ldots,t_n)],\\
([t_1],\ldots,[t_n])\in P^{\mathcal M_T}
&\iff T\vdash P(t_1,\ldots,t_n).
\end{aligned}
$$

Конгруэнтность гарантирует, что результат не зависит от выбора представителей классов.
:::

В терм-модели $\mathrm{Th}(\mathbb N)$ класс $[S(S(0))]$ представляет $2$, а пара $([0],[S(S(0))])$ входит в отношение $\le^{\mathcal M_T}$, потому что $T$ доказывает $0\le S(S(0))$.

### Свидетели и лемма об истинности

:::meaning
Теория имеет **свидетелей**, если для каждого предложения $\exists x.\,\varphi(x)$ есть константа $c$ такая, что $T\vdash(\exists x.\,\varphi(x))\to\varphi(c)$. **Полная непротиворечивая теория** доказывает для каждого предложения либо его само, либо его отрицание. Полнота исчисления связывает семантическое следование с выводимостью, а полнота теории описывает, какие предложения эта теория решает.
:::

**Лемма об истинности.** Для полной непротиворечивой теории со свидетелями $\mathcal M_T\models\varphi\iff T\vdash\varphi$ для каждого предложения $\varphi$. Следовательно, структура $\mathcal M_T$ является моделью $T$. В счётной сигнатуре термов не более чем счётно, поэтому и классов не более чем счётно.

Доказательство идёт индукцией по строению формулы:

1. Для атомов утверждение задаётся определением предиката в терм-модели. Для равенства совпадение классов равносильно доказуемому равенству.
2. Для отрицания полнота и непротиворечивость превращают недоказуемость предложения в доказуемость его отрицания. Для конъюнкции и дизъюнкции применяем правила связок к уже проверенным подформулам. Например, если ни один дизъюнкт не доказуем, теория доказывает оба отрицания и тем самым отрицание дизъюнкции.
3. Если $T\vdash\forall x.\,\varphi(x)$, то по $\forall E$ доказуем каждый экземпляр $\varphi(t)$ с замкнутым $t$. Индукция даёт истинность на каждом классе $[t]$.
4. Если $\forall x.\,\varphi(x)$ не доказуема, полнота даёт $T\vdash\neg\forall x.\,\varphi(x)$ и затем $T\vdash\exists x.\,\neg\varphi(x)$. Свидетель $c$ даёт $T\vdash\neg\varphi(c)$. По индукции на классе $[c]$ универсальная формула нарушается. Квантор $\exists$ можно выразить через $\neg$ и $\forall$.

### Парадокс Сколема и второй порядок

Пусть у теории множеств есть модель. По нисходящей части она допускает счётную модель, хотя внутри неё истинно предложение о существовании несчётного множества. Внешнее перечисление элементов может существовать без соответствующей функции внутри модели. Именно внутренние функции участвуют в проверке утверждения о несчётности.

Индукция первого порядка задаётся схемой, которая даёт экземпляр аксиомы для каждой формулы $P(x)$ языка.

$$
\bigl(P(0)\land\forall x.\,(P(x)\to P(S(x)))\bigr)\to\forall x.\,P(x).
$$

Во втором порядке при полной семантике квантор по одноместному предикату пробегает все подмножества домена:

$$
\forall P.\,\bigl((P(0)\land\forall x.\,(P(x)\to P(S(x))))\to\forall x.\,P(x)\bigr).
$$

:::meaning
Теория **категорична**, если любые две её модели изоморфны. Изоморфизм — биекция доменов, сохраняющая интерпретации констант, функций и предикатов.
:::

При полной семантике аксиомы Пеано второго порядка категоричны, поскольку каждая модель изоморфна $\mathbb N$. Напротив, любая теория первого порядка с бесконечной моделью имеет модели разных бесконечных мощностей по восходящей теореме Лёвенгейма — Сколема. Между их носителями нет биекции, поэтому такая теория некатегорична.

## Синтаксис и семантика

### Построение формулы и свободные вхождения

Арифметический терм $+(+(x,1),y)$ собирается по правилам арности. После сложения $x$ и $1$ полученный терм становится аргументом сложения с $y$. При бинарном $P$ выражения $P(x)$ и $P(f(x))$ ошибочны из-за отсутствия второго аргумента. При унарном $f$ запись $\forall x.\,f(x)$ тоже ошибочна: квантору нужна формула.

В дереве разбора из первого раздела $x,y$ — термы, затем строится терм $f(y)$, затем атомы $P(x)$ и $Q(x,f(y))$. Над правым атомом строится $\exists y.\,Q(x,f(y))$. Следующие шаги — импликация и внешний $\forall x$.

:::meaning
Переменная свободна в формуле, если хотя бы одно её вхождение свободно. Формулу без свободных переменных называют **замкнутой формулой**, или **предложением**. Замкнутый терм не содержит переменных.
:::

В $\exists x.\,(P(x)\land Q(y))$ свободна только $y$, поэтому формула открытая. В $\forall x\exists y.\,L(x,y)$ оба вхождения связаны, а $P(c)$ замкнута, поскольку $c$ — константа. В $\forall x.\,((\forall x.\,P(x))\lor Q(x))$ вхождение в $P$ связано внутренним квантором, вхождение в $Q$ — внешним.

:::example
При подстановке $x:=y+1$ в $\forall y.\,(x<y)$ механическая замена дала бы $\forall y.\,(y+1<y)$ со связанным вхождением $y$ из вставленного терма. Переименуем связанную переменную в свежее $z$, получив $\forall z.\,(x<z)$. Теперь подстановка даёт $\forall z.\,(y+1<z)$, где $y$ остаётся свободной.
:::

### Теорема о совпадении

Для одной интерпретации $\mathcal I$ две оценки дают одинаковое значение терма, если совпадают на всех его переменных. Для формулы достаточно совпадения на её **свободных** переменных.

1. Для переменной совпадение задано условием, а константа зависит только от интерпретации. В составном терме по индукции совпадают значения всех аргументов, поэтому совпадает и значение функции.
2. Атомы, в том числе равенства, сравнивают те же значения термов. Таблицы истинности связок дают одинаковые результаты на одинаковых значениях подформул.
3. Для $\forall x.\,\varphi$ и $\exists x.\,\varphi$ при каждом $d$ обновляем обе оценки до $\nu[x:=d]$ и $\nu'[x:=d]$. На $x$ они теперь совпадают, а на остальных свободных переменных $\varphi$ совпадали по условию. По индукции проверка $\varphi$ даёт один и тот же результат для каждого $d$. Значит, совпадает и результат квантора.

Поэтому для замкнутого терма пишут $\llbracket t\rrbracket_{\mathcal I}$, для предложения — $\mathcal I\models\varphi$. Например, изменение $\nu(x)$ не влияет на $\forall x.\,(x<5)$.

В арифметике $2$ свидетельствует для $\exists x.\,\mathrm{Even}(x)$, а $1$ опровергает $\forall x.\,\mathrm{Even}(x)$.

Конъюнкция всех её значений показывает, что $\forall x\exists y.\,E(x,y)$ ложно, а дизъюнкция — что в графе есть хотя бы одно ребро. ### Интерпретации, зависимости и перевод на логический язык

| Формула | На $\mathbb Z$ | На $\mathbb N$ |
|---|---|---|
| $\exists x\forall y.\,x\le y$ | Ложна, поскольку наименьшего нет | Истинна со свидетелем $0$ |
| $\forall x\exists y.\,x\le y$ | Истинна при выборе $y=x$ | Истинна при выборе $y=x$ |

Если $M(x,y)$ означает «$y$ — мать $x$», то $\forall x\exists y.\,M(x,y)$ допускает свой выбор $y$ для каждого $x$. В $\exists y\forall x.\,M(x,y)$ один и тот же $y$ должен подойти для всех.

«Лают только собаки» переводится как $\forall x.\,(\mathrm{Bark}(x)\to\mathrm{Dog}(x))$. Молчащая собака с этой формулой совместима и опровергает обратное утверждение $\forall x.\,(\mathrm{Dog}(x)\to\mathrm{Bark}(x))$. По той же причине «только отличники получают стипендию» записывается как $\forall x.\,(\mathrm{Stip}(x)\to\mathrm{Hon}(x))$ и допускает отличника без стипендии.

:::example
В определении $\lim_{x\to a}f(x)=L$ порядок кванторов задаёт порядок выбора:

$$
\forall\varepsilon>0\ \exists\delta>0\ \forall x.\,
\bigl(0<\lvert x-a\rvert<\delta\to\lvert f(x)-L\rvert<\varepsilon\bigr).
$$

После выбора $\varepsilon$ подбирают $\delta$, затем проверяют условие на каждом $x$ из проколотой окрестности. Запись $\forall\varepsilon>0.\,\varphi$ означает $\forall\varepsilon.\,(\varepsilon>0\to\varphi)$.
:::

Единственность выражается так:

$$
\exists!x.\,\varphi(x)\equiv
\exists x.\,\bigl(\varphi(x)\land\forall y.\,(\varphi(y)\to y=x)\bigr),
$$

где $y$ — свежее имя. Первое условие предъявляет носителя свойства, второе отождествляет с ним любого другого кандидата. «У каждого числа ровно один противоположный» записывается как $\forall x.\,\exists!y.\,(x+y=0)$.

### Почему работают законы кванторов

**Отрицание.** Зафиксируем $\mathcal I,\nu$ и пусть $A\subseteq D$ — множество элементов, на которых $\varphi$ истинна. Формула $\neg\forall x.\,\varphi(x)$ истинна тогда и только тогда, когда $A\ne D$. Это означает наличие $d\in D\setminus A$, то есть истинность $\exists x.\,\neg\varphi(x)$. Второй закон получается заменой $\varphi$ на $\neg\varphi$, отрицанием обеих частей и снятием двойного отрицания.

**Распределение.** Если $\varphi(d)\land\psi(d)$ истинна для каждого $d$, то каждый конъюнкт истинен для каждого $d$ по отдельности. Обратно, из истинности обоих универсальных предложений для любого $d$ получаем оба конъюнкта и соединяем их. У $\exists x.\,(\varphi\lor\psi)$ свидетель подтверждает хотя бы один дизъюнкт. Обратно, свидетель любого из двух отдельных существований подходит для исходной дизъюнкции. Одноэлементный домен не даст контрпримера для зеркальных пар: обе проверки там сводятся к одному элементу.

**Перенос.** Если $x$ не свободна в $\psi$, смена $x$ не меняет $\psi$. В $\forall x.\,(\varphi\lor\psi)$ при истинной $\psi$ обе части эквивалентности истинны, при ложной обе сводятся к $\forall x.\,\varphi$. В $\exists x.\,(\varphi\land\psi)$ при истинной $\psi$ обе сводятся к $\exists x.\,\varphi$, при ложной обе ложны. Для $\forall$ с $\land$ и $\exists$ с $\lor$ используется тот же разбор, в том числе непустота домена, когда под квантором остаётся постоянное значение.

При переносе в посылку раскрываем импликацию, выносим независимое $\psi$ и применяем закон отрицания:

$$
\begin{aligned}
\forall x.\,(\varphi\to\psi)
 &\equiv(\forall x.\,\neg\varphi)\lor\psi
 \equiv(\neg\exists x.\,\varphi)\lor\psi,\\
\exists x.\,(\varphi\to\psi)
 &\equiv(\exists x.\,\neg\varphi)\lor\psi
 \equiv(\neg\forall x.\,\varphi)\lor\psi.
\end{aligned}
$$

### Ограниченные кванторы и свежесть имени

:::formula
$$
\begin{aligned}
\forall x\in A.\,P(x)&\equiv\forall x.\,(x\in A\to P(x)),\\
\exists x\in A.\,P(x)&\equiv\exists x.\,(x\in A\land P(x)),\\
\neg(\forall x\in A.\,P(x))&\equiv\exists x\in A.\,\neg P(x).
\end{aligned}
$$
:::

При $A=\{1,2,3\}$ и свойстве «быть чётным» число $1$ одновременно опровергает всеобщность и служит свидетелем для её отрицания. Оно остаётся внутри $A$.

| Формула на $D=\{1,2,3\}$ при $A=\{1,2\}$ и $P(x)$ в смысле $x<3$ | Результат |
|---|---|
| $\forall x.\,(x\in A\to P(x))$ | Истинна, поскольку $1,2$ подходят, а у $3$ ложна посылка |
| $\forall x.\,(x\in A\land P(x))$ | Ложна, поскольку $3$ не входит в $A$ |
| $\exists x.\,(x\in A\land P(x))$ | Истинна, например, со свидетелем $1$ |
| $\exists x.\,(x\in A\to P(x))$ | Истинна, причём даже $3$ служит свидетелем из-за ложной посылки |

:::warning
Из открытой гипотезы $a>0$ можно получить $a+1>1$, но нельзя обобщить до $\forall x.\,(x+1>1)$ через $\forall I$, поскольку параметр $a$ встречается в гипотезе. В $\exists E$ тоже нельзя назначить известное имя свидетелем. При $D=\{0,1\}$, $P^{\mathcal I}=\{0\}$, $Q^{\mathcal I}=\{1\}$ и $a^{\mathcal I}=1$ посылки $\exists x.\,P(x)$ и $Q(a)$ истинны, а $P(a)$ ложно.
:::

## Силлогизмы Аристотеля

### Термины и четыре типа суждений

Силлогистика изложена в аристотелевском «Органоне». В силлогизме две посылки связываются через средний термин $M$. В заключении остаются субъект $S$ и предикат $P$. В рассуждении «Все люди смертны. Сократ — человек. Значит, Сократ смертен» средний термин — «люди», предикат — «смертные», а Сократ — субъект заключения. Как рассуждение о классах это Barbara, если понимать единичный субъект как класс из одного Сократа.

| Тип | Количество и качество | Чтение | Формула |
|---|---|---|---|
| $A$ | Общеутвердительное | Все $S$ суть $P$ | $\forall x.\,(S(x)\to P(x))$ |
| $E$ | Общеотрицательное | Ни одно $S$ не есть $P$ | $\forall x.\,(S(x)\to\neg P(x))$ |
| $I$ | Частноутвердительное | Некоторые $S$ суть $P$ | $\exists x.\,(S(x)\land P(x))$ |
| $O$ | Частноотрицательное | Некоторые $S$ не суть $P$ | $\exists x.\,(S(x)\land\neg P(x))$ |

E -- I {dashed}
```

- Диагонали $A$–$O$ и $E$–$I$ выражают **противоречие**, поэтому ровно одно суждение из каждой пары истинно. Законы отрицания кванторов превращают $\neg A$ в $O$, а $\neg E$ в $I$.
- При непустом $S$ **контрарные** $A$ и $E$ не могут быть одновременно истинны.
- При непустом $S$ **субконтрарные** $I$ и $O$ не могут быть одновременно ложны.
- При наличии элемента в $S$ всеобщее утверждение даёт частное. Такое **подчинение** направлено от $A$ к $I$ и от $E$ к $O$.

При $S=\varnothing$ суждения $A,E$ истинны, поскольку посылка импликации везде ложна. У $I,O$ нет свидетелей, поэтому они ложны. Диагональное противоречие сохраняется, а контрарность, субконтрарность и подчинение требуют **экзистенциального допущения** о непустоте субъекта.

### Фигуры и модусы

Фигура показывает положение среднего термина в посылках, а модус задаёт ещё и их типы вместе с типом заключения. Гласные в именах Barbara, Celarent и Darii кодируют эти три типа. Из $4\cdot4^3=256$ сочетаний традиционно выделяют $19$ правильных модусов или $24$, если учесть модусы с ослаблением заключения при соответствующих допущениях о непустоте.

| Фигура | Большая посылка | Меньшая посылка |
|---|---|---|
| I | $M$—$P$ | $S$—$M$ |
| II | $P$—$M$ | $S$—$M$ |
| III | $M$—$P$ | $M$—$S$ |
| IV | $P$—$M$ | $M$—$S$ |

:::example
**Barbara, $AAA$.** Все $M$ суть $P$, все $S$ суть $M$. Берём произвольный $x$ и допускаем $S(x)$. Меньшая посылка после $\forall E$ даёт $S(x)\to M(x)$, откуда $M(x)$. Большая даёт $M(x)\to P(x)$, откуда $P(x)$. Снимаем допущение и обобщаем до $\forall x.\,(S(x)\to P(x))$.

**Celarent, $EAE$.** Вместо $M(x)\to P(x)$ большая посылка даёт $M(x)\to\neg P(x)$. При $S(x)$ снова получаем $M(x)$, затем $\neg P(x)$. После снятия и обобщения имеем $\forall x.\,(S(x)\to\neg P(x))$.

**Darii, $AII$.** Меньшая посылка $\exists x.\,(S(x)\land M(x))$ даёт во временном подвыводе свежего свидетеля $a$. Из $M(a)$ и правила о всех $M$ получаем $P(a)$. Вместе с $S(a)$ это даёт $\exists x.\,(S(x)\land P(x))$ по $\exists I$. Закрываем подвывод по $\exists E$, так как заключение не содержит $a$.
:::

## Нормальные формы

### Предварённая нормальная форма

:::meaning
Формула в **ПНФ** выглядит как $Q_1x_1\ldots Q_kx_k.\,\psi$. Кванторы образуют префикс, а бескванторная часть $\psi$ называется матрицей.
:::

Сначала раскрывают импликации и эквивалентности, затем вносят отрицания по законам де Моргана и двойственности кванторов. Связанные переменные переименовывают свежими именами, чтобы каждый квантор связывал свои вхождения. После этого кванторы выносят в начало. Эти шаги сохраняют равносильность.

:::example
Для формулы $\neg\forall x.\,(P(x)\to\exists y.\,Q(x,y))$ порядок преобразований такой:

$$
\begin{aligned}
&\neg\forall x.\,(\neg P(x)\lor\exists y.\,Q(x,y))\\
{}\equiv{}&\exists x.\,\neg(\neg P(x)\lor\exists y.\,Q(x,y))\\
{}\equiv{}&\exists x.\,(P(x)\land\neg\exists y.\,Q(x,y))\\
{}\equiv{}&\exists x.\,(P(x)\land\forall y.\,\neg Q(x,y))\\
{}\equiv{}&\exists x\forall y.\,(P(x)\land\neg Q(x,y)).
\end{aligned}
$$

Последний перенос разрешён, потому что $y$ не свободна в $P(x)$.
:::

:::warning
Из $(\forall x.\,P(x))\land(\exists x.\,Q(x))$ нельзя получить $\forall x.\,(P(x)\land Q(x))$. На $D=\{0,1\}$ с $P^{\mathcal I}=D$, $Q^{\mathcal I}=\{0\}$ исходная формула истинна, а «склейка» ложна. После переименования второго $x$ в $z$ правильная ПНФ — $\forall x\exists z.\,(P(x)\land Q(z))$.
:::

### Сколемизация и зависимости свидетелей

:::meaning
При **сколемизации** каждый квантор $\exists$ удаляется. Связанную им переменную заменяют свежей функцией от предшествующих универсальных переменных. При отсутствии таких переменных вводят свежую константу. Оставшийся префикс универсальный.
:::

| Исходная формула | Сколемовская форма | Зависимость |
|---|---|---|
| $\forall x\exists y.\,L(x,y)$ | $\forall x.\,L(x,f(x))$ | Свидетель зависит от $x$ |
| $\exists y\forall x.\,L(x,y)$ | $\forall x.\,L(x,c)$ | Один свидетель на все $x$ |
| $\forall x\exists y\forall z\exists w.\,U(x,y,z,w)$ | $\forall x\forall z.\,U(x,f(x),z,g(x,z))$ | $f$ получает $x$, $g$ — $x,z$ |
| $\exists x\forall y.\,(P(x)\land\neg Q(x,y))$ | $\forall y.\,(P(c)\land\neg Q(c,y))$ | $c$ выбирается до $y$ |

:::warning
Для сколемизации гарантируется **равновыполнимость**. Например, у модели $\exists y.\,L(y)$ есть расширение интерпретацией $c$, в котором $L(c)$ истинно. Произвольное значение $c$ может не попасть в $L^{\mathcal I}$. Любая модель $L(c)$ после забывания $c$ удовлетворяет исходной формуле.
:::

### Резолюция

После сколемизации матрицу представляют как конъюнкцию дизъюнктов. Резолюция строит из двух дизъюнктов новый, устраняя противоположные литералы.

:::example
Проверим $\forall x.\,(P(x)\to Q(x)),\ \exists x.\,P(x)\models\exists x.\,Q(x)$ от противного.

1. Добавляем отрицание цели $\forall x.\,\neg Q(x)$.
2. Сколемизируем $\exists x.\,P(x)$ в $P(c)$. Подставляем $c$ в обе универсальные формулы и раскрываем импликацию.
3. Из $\neg P(c)\lor Q(c)$ и $P(c)$ резолюция даёт $Q(c)$.
4. Из $Q(c)$ и $\neg Q(c)$ получаем пустой дизъюнкт $\square$, то есть противоречие.

Противоречие исключает модель посылок, в которой цель ложна.
:::

## Границы метода

### Таблицы истинности и конечные модели

Для $P(c)\to(Q(c)\to P(c))$ достаточно проверить все $2^2=4$ набора значений атомов $P(c),Q(c)$. Это подстановка в тавтологию $p\to(q\to p)$. Если в бескванторной формуле атомы связаны семантикой равенства, таблица, перебирающая их независимо, может включать нереализуемые наборы.

С кванторами проверка выполняется по домену. Формула $\exists x\forall y.\,x=y$ истинна на одноэлементном домене и ложна на каждом домене с двумя или более элементами. Проверка одной конечной модели отвечает за эту модель, а не за общезначимость.

### Компактность и мощность моделей

Доказательство компактности из предыдущего блока использует полноту, конечность доказательства и корректность. Для полной семантики второго порядка возникает контрпример к компактности. Утверждение «домен конечен» совместимо с любым конечным набором требований «есть не менее $n$ элементов». Со всеми такими требованиями сразу оно несовместимо.

**Конструкция Хенкина для счётного языка.** Добавляем свежие константы для свидетелей и предложения $(\exists x.\,\varphi(x))\to\varphi(c)$. Повторяем добавление для формул расширяющегося языка, чтобы свидетели появились и у предложений с новыми именами. Свежесть имени сохраняет непротиворечивость. Если бы очередная аксиома привела к противоречию, из прежней теории выводилось бы её отрицание. Это дало бы одновременно $\exists x.\,\varphi(x)$ и $\neg\varphi(c)$. Поскольку $c$ свежее, второе можно обобщить до $\forall x.\,\neg\varphi(x)$, что противоречит первому уже в прежней теории. При бесконечном добавлении аксиом любое доказательство противоречия всё равно затронуло бы лишь конечное число шагов.

Затем расширяем теорию до максимального непротиворечивого множества, которое решает каждое предложение. Каноническая модель строится из классов замкнутых термов. Лемма об истинности гарантирует, что она удовлетворяет расширенной теории, а после забывания новых имён — исходной.

:::example
В $\mathrm{Th}(\mathbb N)$ стандартные числительные $0,S(0),S(S(0)),\ldots$ дают классы натуральных чисел. Для $\exists x.\,S(x)=S(S(0))$ подходит $[S(0)]$. Если добавить $c>S^n(0)$ для всех $n$, то после расширения теории до полной теории со свидетелями появляется класс $[c]$, отличный от каждого стандартного класса.

В порядке $\mathbb N+\mathbb N$ рассмотрим первый элемент второй копии $\mathbb N$ и обозначим его в рассуждении буквой $c$. В языке с $0$ и $S$ числительные именуют только элементы первой копии. Формула $\exists x.\,(x\ne0\land\neg\exists y.\,S(y)=x)$ истинна, поскольку $c$ отличен от $0$ и не является непосредственным последователем. В структуре из одних числительных свидетеля нет. Свежая константа $d$ с аксиомой свидетеля позволяет представить такой элемент классом $[d]$.
:::

**Восходящая часть Лёвенгейма — Сколема.** Для бесконечной мощности $\kappa$ добавляем константы $c_\alpha$ при $\alpha<\kappa$ и предложения $c_\alpha\ne c_\beta$ при $\alpha\ne\beta$. Любой конечный набор этих требований выполняется в бесконечной модели $T$. По компактности у всего набора есть модель мощности не меньше $\kappa$. Нисходящая часть для расширенного языка мощности $\kappa$ даёт модель мощности не больше $\kappa$. В ней по-прежнему $\kappa$ различных констант, значит мощность ровно $\kappa$.

### Почему схема индукции допускает нестандартные элементы

Множество стандартных элементов содержит $0$ и замкнуто по $S$. В нестандартной модели оно собственное, поскольку $c$ не принадлежит ему. Если бы оно задавалось формулой первого порядка, применимый экземпляр индукции дал бы, что это весь домен. При полной семантике второго порядка это свойство попадает в область квантора $\forall P$. В сочетании с остальными аксиомами Пеано это даёт категоричность.

### Интерпретатор на конечном графе

Интерпретатор хранит оценку списком пар. Поиск с конца берёт самое свежее присваивание, а ветвь квантора добавляет новое значение к копии оценки. В приведённом коде имя без присваивания трактуется как имя вершины, поэтому для настоящих свободных переменных значения нужно передавать в окружении явно.

```rust
type Env<'a> = Vec<(&'a str, &'a str)>;
const D: [&str; 3] = ["a", "b", "c"];
const E: [(&str, &str); 3] = [("a", "b"), ("b", "c"), ("c", "a")];

enum F<'a> {
    Edge(&'a str, &'a str),
    And(&'a F<'a>, &'a F<'a>),
    Exists(&'a str, &'a F<'a>),
    Forall(&'a str, &'a F<'a>),
}

fn ev<'a>(f: &F<'a>, s: &Env<'a>) -> bool {
    let v = |x: &'a str| s.iter().rev().find(|(k, _)| *k == x).map_or(x, |(_, d)| *d);
    let sub = |x: &'a str, d: &'a str| {
        let mut t = s.clone();
        t.push((x, d));
        t
    };
    match f {
        F::Edge(x, y) => E.contains(&(v(x), v(y))),
        F::And(p, q) => ev(p, s) && ev(q, s),
        F::Exists(x, p) => D.iter().any(|&d| ev(p, &sub(x, d))),
        F::Forall(x, p) => D.iter().all(|&d| ev(p, &sub(x, d))),
    }
}
```

Те же проверки можно вынести в отдельные функции:

```rust
fn exists<'a>(x: &'a str, p: &F<'a>, s: &Env<'a>) -> bool {
    D.iter().any(|&d| {
        let mut t = s.clone();
        t.push((x, d));
        ev(p, &t)
    })
}

fn forall<'a>(x: &'a str, p: &F<'a>, s: &Env<'a>) -> bool {
    D.iter().all(|&d| {
        let mut t = s.clone();
        t.push((x, d));
        ev(p, &t)
    })
}
```
