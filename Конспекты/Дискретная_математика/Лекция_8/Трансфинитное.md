## Мера без числа

### Программа с двумя счётчиками

При доказательстве завершаемости программ классический подход состоит в поиске **меры** (функции завершения, или функции вариантов) — числовой величины, которая строго убывает на каждом шаге вычислений и не может убывать бесконечно. Если такая мера отображает состояние программы в множество неотрицательных чисел, алгоритм гарантированно завершится.

Однако далеко не всякий процесс удаётся описать простым числом. Рассмотрим классический пример программы на Rust с двумя счётчиками:

```rust
const N: u32 = 100;
let (mut a, mut b) = (N, 0);

while a > 0 {
    if b > 0 {
        b -= 1;
    } else {
        a -= 1;
        b = N;
    }
}
```

Попробуем найти меру завершаемости для этого цикла.

:::example
**Попытка использовать сумму $a + b$:**
Естественная идея — взять в качестве меры сумму счётчиков $s = a + b$.

1. Пока $b > 0$, значение $b$ уменьшается на $1$, а $a$ остаётся прежним: сумма $a + b$ уменьшается на $1$.
2. Но когда $b = 0$, выполняется ветка `else`: переменная $a$ уменьшается на $1$, зато $b$ сбрасывается в $N = 100$.
3. Например, при переходе из состояния $(5, 0)$ в состояние $(4, 100)$ сумма $a + b$ подскакивает с $5$ до $104$.

Мера $a + b$ не является монотонно убывающей: локальный всплеск разрушает доказательство.
:::

:::warning
Нельзя утверждать, что программа завершается, если мера «в среднем убывает» или «убывает на большинстве шагов». Для строгого доказательства мера обязана строго уменьшаться **на абсолютно каждом** переходе между состояниями.
:::

Выход состоит в том, чтобы отказаться от попытки свести состояние к одному числу и взглянуть на пару $(a, b)$ как на единый упорядоченный объект.

### Лексикографический порядок на парах

Вместо суммы чисел рассмотрим пары $(a, b) \in \mathbb{N} \times \mathbb{N}$, упорядоченные **лексикографически** (по алфавитному принципу):

:::meaning
**Лексикографический порядок на парах:**
Пара $(a, b)$ строго меньше пары $(a', b')$, обозначается $(a, b) <_{\text{lex}} (a', b')$, если:
$$
(a < a') \quad \lor \quad (a = a' \land b < b')
$$
То есть сначала сравниваются старшие компоненты (первая координата $a$), а младшие компоненты $b$ принимаются во внимание только при равенстве старших.
:::

Если убрать верхнюю границу $N$ и позволить $a$ и $b$ быть любыми натуральными числами, множество пар $\mathbb{N} \times \mathbb{N}$ можно представить в виде бесконечной последовательности бесконечных горизонтальных строк:

- Строка $a = 0$: $(0, 0) < (0, 1) < (0, 2) < (0, 3) < \dots$
- Строка $a = 1$: $(1, 0) < (1, 1) < (1, 2) < (1, 3) < \dots$
- Строка $a = 2$: $(2, 0) < (2, 1) < (2, 2) < (2, 3) < \dots$
- $\dots$

Каждая пара из строки $a = 0$ строго меньше любой пары из строки $a = 1$, независимо от значения второй координаты $b$.

```diagram

```

Теперь проследим, как ведёт себя программа в терминах лексикографического порядка:

1. На шаге `b -= 1` состояние переходит из $(a, b)$ в $(a, b - 1)$. Первая координата сохраняется, а вторая строго уменьшается: $(a, b - 1) <_{\text{lex}} (a, b)$.
2. На шаге сброса `a -= 1; b = N` состояние переходит из $(a, 0)$ в $(a - 1, N)$. Поскольку первая координата уменьшилась ($a - 1 < a$), пара $(a - 1, N)$ строго меньше пары $(a, 0)$, несмотря на то, что $N$ может быть сколь угодно большим!

Программа совершает шаги строго «назад» по этой бесконечной лестнице. Координата $a$ может уменьшиться лишь конечное число раз (так как $a \in \mathbb{N}$ и $a$ не может стать отрицательным). Между двумя последовательными уменьшениями координаты $a$ координата $b$ совершает не более $N$ шагов уменьшения до нуля. Следовательно, бесконечного спуска не существует, и цикл обязан завершиться.

### Длина порядка и ординалы

Сравним структуру упорядоченного множества $\mathbb{N}$ и упорядоченного множества $\mathbb{N} \times \mathbb{N}$:

- Конечный линейный порядок $0 < 1 < 2$ содержит $3$ элемента и имеет длину $3$.
- Натуральный ряд $\mathbb{N} = \{0, 1, 2, \dots\}$ бесконечен. Его «порядковая длина» не выражается никаким натуральным числом. Этой длине сопоставляется первый бесконечный **ординал** (порядковое число), обозначаемый греческой буквой $\omega$ (омега):
  $$
  \text{тип}(\mathbb{N}, <) = \omega
  $$
- Множество пар $\mathbb{N} \times \mathbb{N}$ состоит из бесконечного числа копий натурального ряда, поставленных друг за другом (сначала вся строка $a = 0$, затем вся строка $a = 1$, и так далее). Длина такого порядка обозначается $\omega^2$:
  $$
  \text{тип}(\mathbb{N} \times \mathbb{N}, <_{\text{lex}}) = \omega^2
  $$

:::remember
По мощности множества $\mathbb{N}$ и $\mathbb{N} \times \mathbb{N}$ **равномощны**: $|\mathbb{N} \times \mathbb{N}| = |\mathbb{N}| = \aleph_0$ (пары можно взаимно однозначно пересчитать змейкой по диагоналям).

Однако как упорядоченные множества они принципиально различны: их порядковые типы не совпадают:
$$
\omega < \omega^2
$$
Ординал описывает именно **длину и структуру очереди**, а не только количество элементов в ней.
:::

### Наименьший элемент в каждом непустом подмножестве

Чтобы упорядоченное множество гарантировало завершение программ и позволяло проводить доказательства по индукции, линейного порядка недостаточно.

Рассмотрим множество положительных рациональных чисел $\mathbb{Q}^+$ с обычным отношением $<$ и его подмножество — открытый интервал $(0, 1) \cap \mathbb{Q}$. В этом подмножестве **нет наименьшего элемента**: какое бы число $q \in (0, 1)$ мы ни взяли, число $\frac{q}{2}$ также принадлежит $(0, 1)$ и при этом строго меньше: $\frac{q}{2} < q$. В таком порядке возможен бесконечный спуск:
$$
\frac{1}{2} > \frac{1}{4} > \frac{1}{8} > \frac{1}{16} > \dots
$$

Это наблюдение приводит к фундаментальному понятию полного порядка (well-order).

:::meaning
**Определение 1 (Вполне упорядоченное множество / Well-ordered set):**
Линейно упорядоченное множество $(A, <)$ называется **вполне упорядоченным**, если каждое его непустое подмножество $X \subseteq A$ ($X \ne \varnothing$) содержит наименьший элемент:
$$
\exists\, m \in X \quad \forall\, x \in X \ (m \le x)
$$
Отношение $<$ в этом случае называется **полным порядком** (или вполнеупорядочением).
:::

Любой конечный линейный порядок вполне упорядочен автоматически: в любом конечном непустом наборе элементов всегда можно найти минимум. Для бесконечных множеств это свойство выполняется далеко не всегда.

### Что вполне упорядочено: сравнение числовых множеств

Рассмотрим стандартные числовые множества с их естественным отношением порядка $<$:

| Множество и порядок | Вполне упорядочено? | Причина / Обоснование |
| :--- | :---: | :--- |
| $(\mathbb{N}, <)$ | **Да** | Принцип наименьшего числа (аксиома вполне упорядоченности $\mathbb{N}$). |
| $(\mathbb{Z}, <)$ | **Нет** | Множество отрицательных чисел $\{\dots, -3, -2, -1\}$ не имеет минимума. |
| $(\mathbb{Q}, <)$ | **Нет** | Интервал $(0, 1) \cap \mathbb{Q}$ не имеет наименьшего элемента. |
| $(\mathbb{R}, <)$ | **Нет** | Интервал $(0, 1)$ не имеет наименьшего элемента. |
| $(\mathbb{N} \times \mathbb{N}, <_{\text{lex}})$ | **Да** | Для любого непустого $X$ сначала берётся $\min \{a \mid (a, b) \in X\} = a_0$, а затем $\min \{b \mid (a_0, b) \in X\} = b_0$. Пара $(a_0, b_0)$ — наименьшая в $X$. |

:::remember
Полная упорядоченность — это свойство **отношения порядка**, а не самого множества как совокупности элементов!
:::

Одно и то же множество можно упорядочить разными способами:
1. Если на $\mathbb{N}$ задать обратный порядок $n \prec m \iff n > m$, то порядок перестанет быть вполне упорядоченным: у множества $\mathbb{N}$ не будет наименьшего элемента, так как для любого $n$ число $n + 1$ «меньше» него: $n + 1 \prec n$.
2. И наоборот: множество целых чисел $\mathbb{Z}$ можно вполне упорядочить! Переставим числа по возрастанию абсолютного значения (модуля), отдавая при равенстве предпочтение положительному числу:
   $$
   0 \prec 1 \prec -1 \prec 2 \prec -2 \prec 3 \prec -3 \prec \dots
   $$
   В таком порядке $(\mathbb{Z}, \prec)$ изоморфен $(\mathbb{N}, <)$ и является вполне упорядоченным.

### Теорема об обрыве спуска

Главная практическая ценность вполне упорядоченных множеств для программирования и математической логики выражается в невозможности бесконечного спуска:

:::remember
**Теорема 1 (Обрыв строго убывающих цепей):**
Во вполне упорядоченном множестве $(A, <)$ не существует бесконечной строго убывающей последовательности:
$$
a_0 > a_1 > a_2 > a_3 > \dots
$$
Любая последовательность, в которой каждый следующий элемент строго меньше предыдущего, обязана оборваться за конечное число шагов.
:::

**Доказательство (от противного):**
1. Предположим, что существует бесконечная строго убывающая последовательность элементов $a_0 > a_1 > a_2 > \dots$.
2. Рассмотрим множество всех её членов: $X = \{a_0, a_1, a_2, \dots\} \subseteq A$.
3. Множество $X$ непусто. Поскольку $A$ вполне упорядочено, в $X$ обязан существовать наименьший элемент $a_k \in X$.
4. Однако по определению убывающей последовательности за элементом $a_k$ следует элемент $a_{k+1}$, для которого выполнено $a_{k+1} < a_k$.
5. При этом $a_{k+1} \in X$, что прямо противоречит тому, что $a_k$ является наименьшим элементом множества $X$.
6. Полученное противоречие завершает доказательство. $\blacksquare$

### Индукция по вполне упорядоченному множеству

Обычная математическая индукция работает только на $\mathbb{N}$. На вполне упорядоченных множествах её обобщает трансфинитная индукция:

:::meaning
**Теорема 2 (Принцип трансфинитной индукции на вполне упорядоченном множестве):**
Пусть $(A, <)$ — вполне упорядоченное множество, и $S \subseteq A$ — некоторое подмножество его элементов. Если для каждого элемента $x \in A$ выполнено условие:
$$
(\forall y < x \implies y \in S) \implies x \in S
$$
то $S = A$ (свойство верно для всех элементов множества $A$).
:::

**Доказательство (от противного):**
1. Предположим, что $S \ne A$. Тогда множество «контрпримеров» $A \setminus S$ непусто.
2. Так как $A$ вполне упорядочено, в непустом подмножестве $A \setminus S$ существует наименьший элемент $x_0 = \min(A \setminus S)$.
3. Раз $x_0$ — наименьший элемент среди не вошедших в $S$, то абсолютно все строго меньшие элементы $y < x_0$ не могут принадлежать $A \setminus S$, а значит, обязаны лежать в $S$:
   $$
   \forall y < x_0 \ (y \in S)
   $$
4. Но по условию теоремы, если все предшественники $x_0$ лежат в $S$, то и сам элемент $x_0$ обязан лежать в $S$: $x_0 \in S$.
5. Получаем противоречие: $x_0 \in S$ и $x_0 \in A \setminus S$. Следовательно, $A \setminus S = \varnothing$ и $S = A$. $\blacksquare$

:::note
Обратите внимание на формулировку посылки: здесь нет явного разделения на «базу» и «шаг перехода». 
Для наименьшего элемента множества $A$ множество предшественников пусто ($\{y \mid y < \min A\} = \varnothing$). Утверждение «все элементы пустого множества принадлежат $S$» тривиально истинно, поэтому посылка автоматически требует доказать, что наименьший элемент входит в $S$ — это и есть база!
:::

### Порядковый изоморфизм и порядковый тип

Два упорядоченных множества могут состоять из совершенно разных математических объектов, но иметь абсолютно одинаковую упорядоченную структуру.

:::meaning
**Определение 2 (Порядковый изоморфизм):**
Биекция $f: A \to B$ между линейно упорядоченными множествами $(A, <_A)$ и $(B, <_B)$ называется **порядковым изоморфизмом**, если она сохраняет порядок в обоих направлениях:
$$
a_1 <_A a_2 \iff f(a_1) <_B f(a_2)
$$
В этом случае множества $A$ и $B$ называют *порядково изоморфными* (обозначается $A \cong B$).
:::

Изоморфизм сохраняет все свойства, выражаемые через порядок: наличие наименьшего и наибольшего элементов, непосредственных соседей («следующий за»), супремумы и пределы возрастающих цепочек.

:::example
1. Отображение $f(n) = 2n$ устанавливает порядковый изоморфизм между натуральными числами $\mathbb{N} = \{0, 1, 2, \dots\}$ и чётными числами $2\mathbb{N} = \{0, 2, 4, \dots\}$. Выбрасывание каждого второго элемента не изменило тип порядка.
2. Отображение $0 \mapsto 0, 1 \mapsto 1, 2 \mapsto -1, 3 \mapsto 2, 4 \mapsto -2, \dots$ задаёт порядковый изоморфизм между $(\mathbb{N}, <)$ и целыми числами с упорядочением по модулю.
:::

:::meaning
**Определение 3 (Порядковый тип и ординал):**
Класс эквивалентности линейно упорядоченных множеств относительно отношения порядкового изоморфизма называется **порядковым типом**.
Порядковый тип *вполне упорядоченного множества* называется **ординалом** (или порядковым числом).
:::

Ординал выражает «длину и форму» очереди, абстрагируясь от того, кто именно в ней стоит. Однако возникает проблема: класс всех изоморфных множеств слишком огромен, чтобы быть множеством в строгой аксиоматической теории (это приводит к парадоксам). Чтобы оперировать ординалами как конкретными математическими объектами, Джон фон Нейман предложил гениальную стандартную кодировку — канонического представителя для каждого типа порядка.

### Транзитивные множества

В 1923 году Джон фон Нейман предложил определить каждое порядковое число как конкретное множество, построенное исключительно из пустого множества $\varnothing$ и операций объединения. Фундаментом этой конструкции служит понятие транзитивного множества.

:::meaning
**Определение 4 (Транзитивное множество):**
Множество $A$ называется **транзитивным**, если каждый его элемент одновременно является его подмножеством:
$$
\forall x \ (x \in A \implies x \subseteq A)
$$
Эквивалентная формулировка: отношение принадлежности на элементах транзитивно, то есть:
$$
(z \in y \land y \in x \land x \in A) \implies z \in A
$$
:::

:::example
1. Множество $2 = \{0, 1\} = \{\varnothing, \{\varnothing\}\}$ **транзитивно**:
   - Элемент $\varnothing \in 2$. Является ли он подмножеством? Да, $\varnothing \subseteq 2$ верно для любого множества.
   - Элемент $\{\varnothing\} \in 2$. Все его элементы (только $\varnothing$) принадлежат $2$. Значит, $\{\varnothing\} \subseteq 2$.
2. Множество $\{\varnothing, \{\{\varnothing\}\}\}$ **не транзитивно**:
   - Элемент $\{\{\varnothing\}\}$ содержит элемент $\{\varnothing\}$.
   - Но сам элемент $\{\varnothing\}$ в исходном множестве не лежит!
:::

Транзитивность устанавливает прямой мост между операцией принадлежности $\in$ и отношением включения $\subseteq$.

### Определение ординала фон Неймана

:::meaning
**Определение 5 (Ординал фон Неймана):**
Множество $\alpha$ называется **ординалом фон Неймана**, если:
1. Множество $\alpha$ транзитивно;
2. Множество $\alpha$ вполне упорядочено отношением принадлежности $\in$.
:::

В ординале фон Неймана отношение «меньше» ($\beta < \alpha$) — это в точности отношение принадлежности ($\beta \in \alpha$), которое совпадает со строгим включением ($\beta \subsetneq \alpha$):
$$
\beta < \alpha \iff \beta \in \alpha \iff \beta \subsetneq \alpha
$$

Построим первые ординалы фон Неймана шаг за шагом:
- $0 = \varnothing$ (пустое множество, $0$ элементов);
- $1 = \{0\} = \{\varnothing\}$ ($1$ элемент);
- $2 = \{0, 1\} = \{\varnothing, \{\varnothing\}\}$ ($2$ элемента);
- $3 = \{0, 1, 2\} = \{\varnothing, \{\varnothing\}, \{\varnothing, \{\varnothing\}\}\}$ ($3$ элемента);
- $\dots$
- $n = \{0, 1, 2, \dots, n-1\}$.

:::remember
Каждый ординал фон Неймана в точности равен **множеству всех меньших ординалов**:
$$
\alpha = \{\beta \mid \beta < \alpha\}
$$
Число $5$ в этой системе буквально является множеством чисел от $0$ до $4$.
:::

### Свойства ординалов фон Неймана

Ординалы обладают удивительной внутренней регулярностью.

:::meaning
**Теорема 3 (Элемент ординала есть ординал):**
Если $\alpha$ — ординал и $\beta \in \alpha$, то $\beta$ сам является ординалом.
:::

**Доказательство:**
1. *Вполне упорядоченность:* Так как $\alpha$ транзитивно и $\beta \in \alpha$, то $\beta \subseteq \alpha$. Подмножество вполне упорядоченного множества $(\alpha, \in)$ само вполне упорядочено тем же отношением $\in$.
2. *Транзитивность:* Пусть $\delta \in \gamma \in \beta$. Так как $\beta \subseteq \alpha$, то $\gamma \in \alpha$. Аналогично, раз $\gamma \subseteq \alpha$, то $\delta \in \alpha$.
   Все три элемента $\delta, \gamma, \beta$ лежат в $\alpha$. Отношение $\in$ линейно упорядочивает $\alpha$. Если бы $\delta \notin \beta$, то в силу линейного порядка на $\alpha$ было бы либо $\delta = \beta$, либо $\beta \in \delta$. Но тогда возник бы цикл принадлежности ($\beta \in \delta \in \gamma \in \beta$ или $\beta \in \gamma \in \beta$), что невозможно для строгого порядка. Значит, остаётся единственная возможность: $\delta \in \beta$. Множество $\beta$ транзитивно.
Следовательно, $\beta$ — ординал. $\blacksquare$

:::meaning
**Теорема 4 (Линейная сравнимость ординалов / Трихотомия):**
Для любых двух ординалов $\alpha$ и $\beta$ выполнено ровно одно из трёх соотношений:
$$
\alpha \in \beta \quad (\alpha < \beta), \qquad \alpha = \beta, \qquad \beta \in \alpha \quad (\beta < \alpha)
$$
:::

**Доказательство:**
Рассмотрим пересечение $\gamma = \alpha \cap \beta$. Пересечение двух транзитивных множеств транзитивно, и подмножество ординала вполне упорядочено, поэтому $\gamma$ — тоже ординал.
- Если $\gamma \ne \alpha$, возьмём наименьший элемент $\xi \in \alpha \setminus \gamma$. Все элементы $\delta \in \alpha$, меньшие $\xi$, обязаны лежать в $\gamma$, а любой элемент $\gamma$ меньше $\xi$. Поэтому $\gamma = \xi$, откуда $\gamma \in \alpha$.
- Аналогично, если $\gamma \ne \beta$, то $\gamma \in \beta$.
Если бы одновременно выполнялось $\gamma \in \alpha$ и $\gamma \in \beta$, то по определению пересечения получилось бы $\gamma \in \alpha \cap \beta = \gamma$, то есть $\gamma \in \gamma$, что противоречит строгой иррефлексивности отношения $\in$. Значит, хотя бы в одном случае выполнено равенство: $\gamma = \alpha$ (тогда $\alpha \subseteq \beta$) или $\gamma = \beta$ (тогда $\beta \subseteq \alpha$). Отсюда следует трихотомия. $\blacksquare$

:::note
Следствие: Любое непустое множество ординалов вполне упорядочено отношением принадлежности $\in$.
:::

:::meaning
**Теорема 5 (Следующий ординал):**
Для любого ординала $\alpha$ множество
$$
\alpha + 1 = \alpha \cup \{\alpha\}
$$
является наименьшим ординалом, строго большим $\alpha$.
:::

### Теорема о представлении и жёсткость

Почему кодировка фон Неймана универсальна? Ответ даёт фундаментальная теорема:

:::remember
**Теорема 6 (Теорема о представлении фон Неймана, 1923):**
Каждое вполне упорядоченное множество $(A, <)$ порядково изоморфно **ровно одному** ординалу фон Неймана.
:::

**Идея построения канонического изоморфизма:**
Функция изоморфизма $f: A \to \alpha$ строится рекурсивно: каждый элемент $x \in A$ переходит во множество образов всех строго меньших элементов:
$$
f(x) = \{f(y) \mid y < x\}
$$
- Наименьший элемент множества $A$ переходит в $\{\} = \varnothing = 0$.
- Второй элемент переходит в $\{f(\min A)\} = \{0\} = 1$.
- Третий — в $\{0, 1\} = 2$, и так далее.

:::meaning
**Теорема 7 (Жёсткость ординалов):**
Если $f: \alpha \to \beta$ — порядковый изоморфизм между ординалами, то $\alpha = \beta$ и $f$ является тождественным отображением: $\forall \gamma \in \alpha \ (f(\gamma) = \gamma)$.
:::

Никакой ординал не может быть изоморфен собственному начальному отрезку или другому ординалу. Канонический представитель типа порядка всегда строго единственен!

### Первый бесконечный ординал $\omega$ и предельные ординалы

Конечные ординалы исчерпываются натуральными числами $0, 1, 2, 3, \dots$. Что произойдет, если мы объединим их все вместе?

:::meaning
**Первый бесконечный ординал $\omega$:**
Ординал $\omega$ — это множество всех конечных ординалов (всех натуральных чисел):
$$
\omega = \mathbb{N} = \{0, 1, 2, 3, \dots\} = \sup_{n \in \mathbb{N}} n
$$
Множество $\omega$ транзитивно и вполне упорядочено отношением $\in$. Оно больше любого конечного натурального числа и является **наименьшим бесконечным ординалом**.
:::

Заметим принципиальную разницу:
- Число $5$ получено из $4$ прибавлением единицы: $5 = 4 + 1$. Любое натуральное число $n > 0$ имеет непосредственного предшественника $n - 1$.
- Для ординала $\omega$ предшественника не существует: $\omega \ne \alpha + 1$ ни для какого ординала $\alpha$. Нельзя назвать «последнее натуральное число».

Это приводит к фундаментальной классификации ординалов:

:::meaning
**Определение 6 (Изолированные и предельные ординалы):**
1. Ординал вида $\alpha + 1 = \alpha \cup \{\alpha\}$ называется **изолированным** (или непосредственно следующим за $\alpha$).
2. Ненулевой ординал $\lambda \ne 0$ называется **предельным**, если он не равен $\alpha + 1$ ни для какого $\alpha$. Предельный ординал является точной верхней гранью (супремумом) всех меньших ординалов:
$$
\lambda = \sup_{\beta < \lambda} \beta = \bigcup_{\beta < \lambda} \beta
$$
:::

У предельного ординала нет наибольшего элемента среди меньших: если $\beta < \lambda$, то и $\beta + 1 < \lambda$.

### Структура бесконечной лестницы

За ординалом $\omega$ процесс счета не останавливается! Мы можем продолжать прибавлять единицу:
$$
\omega, \quad \omega + 1, \quad \omega + 2, \quad \omega + 3, \quad \dots
$$
Эта последовательность не имеет последнего элемента. Её супремум образует следующий предельный ординал:
$$
\sup_{n < \omega} (\omega + n) = \omega + \omega = \omega \cdot 2
$$
Далее процесс повторяется:
$$
\omega \cdot 2, \quad \omega \cdot 2 + 1, \quad \dots, \quad \omega \cdot 3, \quad \dots, \quad \omega \cdot n, \quad \dots
$$
Супремум цепочки $\omega \cdot n$ по всем $n < \omega$ даёт ординал:
$$
\sup_{n < \omega} (\omega \cdot n) = \omega^2
$$
Продолжая дальше: $\omega^2, \dots, \omega^3, \dots, \omega^n, \dots$, получаем $\omega^\omega = \sup_{n < \omega} \omega^n$.

### Башня степеней и ординал $\varepsilon_0$

Возведение в степень позволяет строить башни из $\omega$:
$$
\omega, \quad \omega^\omega, \quad \omega^{\omega^\omega}, \quad \omega^{\omega^{\omega^\omega}}, \quad \dots
$$
Каждая башня высоты $n$ строго меньше башни высоты $n + 1$. Супремум этой возрастающей цепочки обозначается символом $\varepsilon_0$ (эпсилон-ноль):
$$
\varepsilon_0 = \sup \{\omega, \omega^\omega, \omega^{\omega^\omega}, \dots\}
$$

:::formula
**Ключевое свойство ординала $\varepsilon_0$:**
$$
\omega^{\varepsilon_0} = \varepsilon_0
$$
$\varepsilon_0$ является наименьшей неподвижной точкой операции $\alpha \mapsto \omega^\alpha$.
:::

Ординал $\varepsilon_0$ является наименьшим ординалом, замкнутым относительно всех школьных арифметических операций: если $\alpha, \beta < \varepsilon_0$, то $\alpha + \beta < \varepsilon_0$, $\alpha \cdot \beta < \varepsilon_0$ и $\alpha^\beta < \varepsilon_0$. Он играет колоссальную роль в логике и теории доказательств (теорема Генцена, последовательности Гудстейна).

### Расхождение порядка и мощности

Возникает естественный вопрос: сколь огромны эти числа по количеству элементов?

| Ординал | Мощность (Кардинал) | Почему счётен? |
| :---: | :---: | :--- |
| $\omega$ | $\aleph_0$ (счётно) | Сам натуральный ряд $\mathbb{N}$. |
| $\omega + 1$ | $\aleph_0$ (счётно) | Натуральный ряд плюс одна точка в конце: $\aleph_0 + 1 = \aleph_0$. |
| $\omega \cdot 2$ | $\aleph_0$ (счётно) | Две копии натурального ряда: $\aleph_0 + \aleph_0 = \aleph_0$. |
| $\omega^2$ | $\aleph_0$ (счётно) | Пары натуральных чисел: $\aleph_0 \cdot \aleph_0 = \aleph_0$. |
| $\omega^\omega$ | $\aleph_0$ (счётно) | Конечные последовательности натуральных чисел. |
| $\varepsilon_0$ | $\aleph_0$ (счётно) | Счётное объединение счётных множеств: $\bigcup_{n < \omega} \text{башня}_n$. |

:::warning
Все эти поражающие воображение ординалы — $\omega, \omega+1, \omega \cdot 2, \omega^2, \omega^\omega, \varepsilon_0$ — **счётны по мощности**! В каждом из них ровно столько же элементов, сколько в обычном множестве натуральных чисел.
Они различаются исключительно тем, **как сложно и глубоко эти элементы упорядочены**.
:::

```quiz
- [x] $\varepsilon_0$ :: $\varepsilon_0$ является наименьшим решением уравнения $\omega^\alpha = \alpha$.
- [ ] $\omega$ :: $\varepsilon_0$ неизмеримо больше $\omega$.
- [ ] $\infty$ :: В ординальной арифметике нет неопределённого символа $\infty$.
explain: По определению $\varepsilon_0$ является супремумом башни степеней и удовлетворяет равенству $\omega^{\varepsilon_0} = \varepsilon_0$.

? Какова мощность множества элементов ординала $\varepsilon_0$?
- [ ] Несчётная мощность $\aleph_1$ :: $\varepsilon_0$ лежит значительно ниже первого несчётного ординала $\omega_1$.
- [ ] Мощность континуума $2^{\aleph_0}$ :: $\varepsilon_0$ счётен.
- [x] Счётная мощность $\aleph_0$ :: $\varepsilon_0$ есть счётное объединение счётных башен степеней $\omega$.
- [ ] Конечная мощность :: $\varepsilon_0 > \omega$, поэтому он бесконечен.
explain: Каждая башня $\omega^{\dots^\omega}$ счётна, а счётное объединение счётных множеств счётно.
```

## Ординальная арифметика

> Математика — это искусство давать одно и то же имя разным вещам.
>
> — Анри Пуанкаре

### Сложение: приставить порядок

Арифметика ординалов определяется через естественные операции склеивания упорядоченных множеств.

:::meaning
**Геометрический смысл сложения:**
Сумма $\alpha + \beta$ — это порядковый тип множества, полученного приставлением копии порядка $\beta$ строго **после** копии порядка $\alpha$.
:::

Формально сложение задаётся трансфинитной рекурсией по правому аргументу:
:::meaning
**Определение 7 (Индуктивное определение сложения ординалов):**
1. $\alpha + 0 = \alpha$
2. $\alpha + (\beta + 1) = (\alpha + \beta) + 1$ (для изолированного шага)
3. $\alpha + \lambda = \sup_{\beta < \lambda} (\alpha + \beta)$ (для предельного $\lambda$)
:::

Сложение ординалов **некоммутативно**! Порядок слагаемых имеет решающее значение.

:::example
**Сравнение $1 + \omega$ и $\omega + 1$:**
1. Сумма $1 + \omega$: сначала ставится одна точка, а следом за ней — бесконечная очередь $\mathbb{N}$:
   $$
   \bullet, \quad 0, 1, 2, 3, \dots
   $$
   Если перенумеровать эту очередь ($\bullet \mapsto 0, 0 \mapsto 1, 1 \mapsto 2, \dots$), мы получим в точности стандартный ряд натуральных чисел! Добавленная спереди точка просто растворилась в бесконечности:
   $$
   1 + \omega = \omega
   $$
2. Сумма $\omega + 1$: сначала ставится бесконечная очередь $\mathbb{N}$, а уже **после неё** приписывается отдельная точка:
   $$
   0, 1, 2, 3, \dots \quad \bullet
   $$
   В этом порядке точка $\bullet$ является **наибольшим элементом** (она больше любого натурального числа). Но в натуральном ряде $\omega$ наибольшего элемента нет! Значит, этот порядок не изоморфен $\omega$:
   $$
   \omega + 1 > \omega
   $$
:::

```diagram
title: Сравнение 1 + w и w + 1
A: note "1 + w: [точка] затем 0, 1, 2, ... -> изоморфно w" @ 250, 50
B: note "w + 1: 0, 1, 2, ... затем [точка в конце] -> строго больше w" @ 250, 120
A -> B : порядки не совпадают!
```

:::remember
**Теорема 8:**
$$
1 + \omega = \omega \ne \omega + 1
$$
- Сложение ординалов не коммутативно.
- **Сокращение слева сохраняется:** $\gamma + \alpha = \gamma + \beta \implies \alpha = \beta$.
- **Сокращение справа ломается:** $1 + \omega = 2 + \omega = \omega$, однако $1 \ne 2$.
:::

### Умножение: копии порядка

:::meaning
**Геометрический смысл умножения:**
Произведение $\alpha \cdot \beta$ — это порядковый тип множества, состоящего из $\beta$ копий порядка $\alpha$, поставленных друг за другом.
:::

Индуктивное определение:
:::meaning
**Определение 8 (Умножение ординалов):**
1. $\alpha \cdot 0 = 0$
2. $\alpha \cdot (\beta + 1) = \alpha \cdot \beta + \alpha$
3. $\alpha \cdot \lambda = \sup_{\beta < \lambda} (\alpha \cdot \beta)$ (для предельного $\lambda$)
:::

Умножение также некоммутативно:
:::example
**Сравнение $2 \cdot \omega$ и $\omega \cdot 2$:**
- $2 \cdot \omega$: это $\omega$ копий двухэлементного множества $\{0, 1\}$, поставленных подряд:
  $$
  (0, 1), (0, 1), (0, 1), \dots \implies \bullet \bullet \bullet \bullet \bullet \bullet \dots
  $$
  Это просто счётная последовательность точек, изоморфная $\omega$:
  $$
  2 \cdot \omega = \omega
  $$
- $\omega \cdot 2$: по определению это $\omega \cdot 1 + \omega = \omega + \omega$. Это две полноценные копии натурального ряда:
  $$
  0, 1, 2, \dots \quad 0', 1', 2', \dots
  $$
  Первая копия образует собственный начальный сегмент, после которого идёт вторая бесконечная цепочка. Очевидно:
  $$
  \omega \cdot 2 > \omega
  $$
:::

### Возведение в степень

:::meaning
**Определение 9 (Степень ординала):**
1. $\alpha^0 = 1$
2. $\alpha^{\beta + 1} = \alpha^\beta \cdot \alpha$
3. $\alpha^\lambda = \sup_{\beta < \lambda} \alpha^\beta$ (для предельного $\lambda$)
:::

:::warning
Не путайте ординальное возведение в степень с кардинальным!
- Для ординалов:
  $$
  2^\omega = \sup_{n < \omega} 2^n = \sup \{1, 2, 4, 8, 16, \dots\} = \omega
  $$
  Каждая конечная степень двойки конечна, а их супремум равен наименьшему бесконечному ординалу $\omega$.
- Для кардиналов (мощностей):
  $$
  2^{\aleph_0} = |\mathcal{P}(\mathbb{N})| = |\mathbb{R}| = \mathfrak{c} > \aleph_0
  $$
  Кардинальная степень обозначает мощность булеана и строго больше исходной мощности по теореме Кантора.
:::

Также для степеней:
$$
\omega \cdot \omega^\omega = \omega^{1 + \omega} = \omega^\omega
$$
(так как $1 + \omega = \omega$), но при умножении справа:
$$
\omega^\omega \cdot \omega = \omega^{\omega + 1} > \omega^\omega
$$

### Нарушение дистрибутивности

В ординальной арифметике сохраняются далеко не все привычные правила школьной алгебры:

:::example
**Правый распределительный закон ломается:**
Попробуем раскрыть скобки в выражении $(1 + 1) \cdot \omega$:
$$
(1 + 1) \cdot \omega = 2 \cdot \omega = \omega
$$
Если бы правая дистрибутивность выполнялась, мы получили бы:
$$
1 \cdot \omega + 1 \cdot \omega = \omega + \omega = \omega \cdot 2
$$
Но $\omega \ne \omega \cdot 2$! Следовательно:
$$
(\alpha + \beta) \cdot \gamma \ne \alpha \cdot \gamma + \beta \cdot \gamma \quad \text{(в общем случае)}
$$
:::

:::remember
**Левая дистрибутивность сохраняется:**
$$
\alpha \cdot (\beta + \gamma) = \alpha \cdot \beta + \alpha \cdot \gamma
$$
:::

### Что осталось от школьных законов

| Закон | В арифметике $\mathbb{N}$ | В арифметике ординалов | Контрпример для ординалов |
| :--- | :---: | :---: | :--- |
| Коммутативность сложения | Да | **Нет** | $1 + \omega = \omega \ne \omega + 1$ |
| Ассоциативность сложения | Да | **Да** | $(\alpha + \beta) + \gamma = \alpha + (\beta + \gamma)$ |
| Сокращение слева | Да | **Да** | $\gamma + \alpha = \gamma + \beta \implies \alpha = \beta$ |
| Сокращение справа | Да | **Нет** | $1 + \omega = 2 + \omega$, но $1 \ne 2$ |
| Коммутативность умножения | Да | **Нет** | $2 \cdot \omega = \omega \ne \omega \cdot 2$ |
| Ассоциативность умножения | Да | **Да** | $(\alpha \cdot \beta) \cdot \gamma = \alpha \cdot (\beta \cdot \gamma)$ |
| Дистрибутивность слева | Да | **Да** | $\alpha \cdot (\beta + \gamma) = \alpha \cdot \beta + \alpha \cdot \gamma$ |
| Дистрибутивность справа | Да | **Нет** | $(1 + 1) \cdot \omega = \omega \ne \omega + \omega$ |

### Мера завершаемости: возврат к двум счётчикам

Теперь мы можем дать строгое математическое доказательство завершаемости программы с двумя счётчиками, рассмотренной в начале:

Состоянию программы $(a, b)$ сопоставим ординальную меру:
$$
\mu(a, b) = \omega \cdot a + b
$$
Все возможные значения меры лежат ниже ординала $\omega^2$. Проверим переходы:
1. Шаг уменьшения внутреннего счётчика $(a, b) \to (a, b - 1)$ при $b > 0$:
   $$
   \mu(a, b - 1) = \omega \cdot a + b - 1 < \omega \cdot a + b = \mu(a, b)
   $$
2. Шаг сброса $(a, 0) \to (a - 1, N)$ при $a > 0$:
   $$
   \mu(a - 1, N) = \omega \cdot (a - 1) + N
   $$
   Сравним с $\mu(a, 0) = \omega \cdot a = \omega \cdot (a - 1) + \omega$. Так как $N < \omega$, то:
   $$
   \omega \cdot (a - 1) + N < \omega \cdot (a - 1) + \omega = \omega \cdot a
   $$

Мера $\mu$ **строго убывает на каждом шаге программы**: сброс счётчика $b$ до любого конечного $N$ никогда не сможет компенсировать уменьшение старшего коэффициента $a$ при $\omega$. Поскольку ординалы вполне упорядочены и бесконечного спуска не существует (Теорема 1), программа гарантированно завершит работу за конечное число шагов!

## Трансфинитная индукция и рекурсия

> Начиная с предметов наиболее простых и легко познаваемых, восходить мало-помалу до познания наиболее сложных.
>
> — Рене Декарт

### Три шага трансфинитной индукции

На числовой прямой $\mathbb{N}$ индукция состоит из двух этапов: базы для $0$ и перехода $n \implies n + 1$. Поскольку среди ординалов появляются предельные числа, не имеющие предшественников, схема индукции расширяется до трёх обязательных шагов.

:::meaning
**Определение 10 (Схема трансфинитной индукции):**
Пусть $P(\alpha)$ — свойство, определённое для всех ординалов $\alpha < \kappa$.
1. **База индукции:** Доказать, что утверждение верно для нуля:
   $$
   P(0)
   $$
2. **Изолированный шаг (переход):** Для любого ординала $\alpha < \kappa$ доказать:
   $$
   P(\alpha) \implies P(\alpha + 1)
   $$
3. **Предельный шаг:** Для каждого предельного ординала $\lambda < \kappa$ доказать:
   $$
   (\forall \beta < \lambda \ P(\beta)) \implies P(\lambda)
   $$
Если все три шага выполнены, то свойство $P(\alpha)$ истинно для всех ординалов $\alpha < \kappa$.
:::

:::warning
**Предельный шаг — отдельная и строгая обязанность!**
Из того, что свойство истинно для всех $n \in \mathbb{N}$, вообще говоря, **не следует**, что оно истинно для $\omega$.

*Классический контрпример:*
Пусть свойство $P(\alpha)$ означает «ординал $\alpha$ является конечным» (или $\alpha \ne \omega$).
- $P(0)$ истинно ($0$ конечно).
- Из того, что $n$ конечно, следует, что $n + 1$ конечно ($P(n) \implies P(n + 1)$ верно).
- Однако $P(\omega)$ ложно! Ординал $\omega$ бесконечен.
Без предельного шага индукция навсегда заперта внутри области конечных чисел.
:::

### Сильная форма индукции

Как мы видели в Теореме 2, три шага можно объединить в одно универсальное правило:

:::meaning
**Теорема 9 (Сильная форма трансфинитной индукции):**
Если для каждого ординала $\alpha$ из предположения, что свойство $P(\beta)$ истинно для всех предшественников $\beta < \alpha$, следует истинность $P(\alpha)$:
$$
\forall \alpha \ ((\forall \beta < \alpha \ P(\beta)) \implies P(\alpha))
$$
то $P(\alpha)$ истинно для всех ординалов $\alpha$.
:::

**Доказательство:**
Если бы свойство выполнялось не для всех ординалов, класс контрпримеров $X = \{\alpha \mid \neg P(\alpha)\}$ был бы непуст. Будучи непустым классом ординалов, $X$ содержит наименьший элемент $\alpha_0$. Тогда для всех $\beta < \alpha_0$ свойство $P(\beta)$ истинно. Но по посылке теоремы отсюда следует $P(\alpha_0)$, что противоречит выбору $\alpha_0 \in X$. $\blacksquare$

:::example
**Доказательство ассоциативности сложения $(\alpha + \beta) + \gamma = \alpha + (\beta + \gamma)$ индукцией по $\gamma$:**
1. *База $\gamma = 0$:* $(\alpha + \beta) + 0 = \alpha + \beta = \alpha + (\beta + 0)$ — верно.
2. *Переход $\gamma \implies \gamma + 1$:* Предположим равенство верным для $\gamma$. Тогда:
   $$
   (\alpha + \beta) + (\gamma + 1) = ((\alpha + \beta) + \gamma) + 1 = (\alpha + (\beta + \gamma)) + 1 = \alpha + ((\beta + \gamma) + 1) = \alpha + (\beta + (\gamma + 1))
   $$
3. *Предельный шаг для $\lambda$:* По определению сложения с предельным ординалом, обе части равенства равны супремумам по всем $\gamma < \lambda$. Так как для каждого $\gamma < \lambda$ равенство выполнено по индукционному предположению, совпадают и их точные верхние грани (сложение непрерывно по правому аргументу).
Равенство доказано для всех ординалов $\gamma$.
:::

### Трансфинитная рекурсия

Если индукция позволяет *доказывать свойства*, то трансфинитная рекурсия позволяет *строить объекты и функции*.

:::meaning
**Теорема 11 (Теорема о трансфинитной рекурсии):**
Пусть $\kappa$ — ординал, и задано правило $F$, сопоставляющее любой частично определённой функции $f|_\alpha$ (функции на ординалах $\beta < \alpha$) значение в точке $\alpha$.
Тогда существует **единственная** функция $f$, определённая на $\kappa$, удовлетворяющая соотношению:
$$
f(\alpha) = F(f|_\alpha) \quad \text{для всех } \alpha < \kappa
$$
:::

Именно на этой теореме базируются корректность определений сложения, умножения, возведения в степень ординалов, а также функция канонического изоморфизма из теоремы о представлении фон Неймана.

### Кардинал как начальный ординал

Ординал отвечает на вопрос «какой по счёту в упорядочении?», а кардинал (мощность) отвечает на вопрос «сколько всего элементов?».

Мы видели, что ординалы $\omega, \omega + 1, \omega \cdot 2, \omega^2, \varepsilon_0$ имеют одинаковое число элементов — все они равномощны множеству $\mathbb{N}$. Среди всех ординалов фиксированной мощности всегда существует **наименьший**.

:::meaning
**Определение 11 (Кардинальное число / Кардинал):**
Ординал $\kappa$ называется **кардиналом** (или начальным ординалом), если он не равномощен ни одному строго меньшему ординалу:
$$
\forall \alpha < \kappa \quad (|\alpha| \ne |\kappa|)
$$
Первый бесконечный кардинал — это ординал $\omega$. В качестве кардинального числа он обозначается первой буквой еврейского алфавита:
$$
\aleph_0 = \omega \quad \text{(алеф-ноль)}
$$
:::

Ординалы $\omega + 1, \omega \cdot 2, \omega^2$ кардиналами не являются, так как каждый из них равномощен строго меньшему ординату $\omega$.

Сравним поведение операций:
| Запись | Как ординалы (структура порядка) | Как кардиналы (размер множества) |
| :---: | :---: | :---: |
| $+ 1$ | $\omega + 1 > \omega$ | $\aleph_0 + 1 = \aleph_0$ |
| $\cdot 2$ | $\omega \cdot 2 > \omega$ | $\aleph_0 \cdot 2 = \aleph_0$ |
| $(\dots)^2$ | $\omega^2 > \omega$ | $\aleph_0^2 = \aleph_0$ |
| $2^{(\dots)}$ | $2^\omega = \omega$ | $2^{\aleph_0} > \aleph_0$ |

### Иерархия алефов

Используя трансфинитную рекурсию и аксиому выбора (которая гарантирует, что любое множество можно вполне упорядочить), Кантор построил полную иерархию бесконечных мощностей:

:::meaning
**Определение 12 (Шкала алефов):**
1. $\aleph_0 = \omega$ — наименьшая бесконечная мощность (счётная);
2. $\aleph_{\alpha + 1}$ — наименьший кардинал, строго больший $\aleph_\alpha$;
3. $\aleph_\lambda = \sup_{\alpha < \lambda} \aleph_\alpha = \bigcup_{\alpha < \lambda} \aleph_\alpha$ (для предельного $\lambda$).
:::

- $\aleph_1$ — **первый несчётный кардинал**. Это мощность множества всех счётных ординалов.
- $\aleph_2$ — следующий за ним кардинал, и так далее.
- $\aleph_\omega = \sup_{n < \omega} \aleph_n$ — первый предельный кардинал после счётного семейства алефов.

### Иерархия бетов

Другой естественный способ движения в бесконечность — это операция перехода к булеану (множеству всех подмножеств $\mathcal{P}(X)$), которая по теореме Кантора всегда строго увеличивает мощность: $|\mathcal{P}(X)| = 2^{|X|} > |X|$. Эта иерархия обозначается второй буквой еврейского алфавита $\beth$ (бет):

:::meaning
**Определение 13 (Шкала бетов):**
1. $\beth_0 = \aleph_0 = |\mathbb{N}|$
2. $\beth_{\alpha + 1} = 2^{\beth_\alpha} = |\mathcal{P}(\beth_\alpha)|$
3. $\beth_\lambda = \sup_{\alpha < \lambda} \beth_\alpha$ (для предельного $\lambda$).
:::

Конкретные значения шкалы бетов:
- $\beth_0 = \aleph_0$ — мощность натуральных чисел $\mathbb{N}$;
- $\beth_1 = 2^{\aleph_0}$ — мощность континуума $|\mathbb{R}| = |\mathcal{P}(\mathbb{N})|$ (мощность числовой прямой);
- $\beth_2 = 2^{2^{\aleph_0}}$ — мощность множества всех подмножеств прямой (всех функций $\mathbb{R} \to \mathbb{R}$).

:::note
Шкала бетов не требует аксиомы выбора: каждый следующий шаг однозначно задан конструкцией булеана.
:::

### Две лестницы и континуум-гипотеза

Мы получили две параллельные лестницы бесконечности:
1. Лестница алефов шагает по **непосредственно следующему кардиналу**: $\aleph_0 \to \aleph_1 \to \aleph_2 \to \dots$
2. Лестница бетов шагает по **булеану**: $\beth_0 \to \beth_1 = 2^{\aleph_0} \to \beth_2 = 2^{\beth_1} \to \dots$

Обе лестницы начинаются в одной точке: $\aleph_0 = \beth_0 = |\mathbb{N}|$.
По теореме Кантора $2^{\aleph_0} > \aleph_0$. Так как $\aleph_1$ — это *наименьший* кардинал, превосходящий $\aleph_0$, неизбежно выполнено неравенство:
$$
2^{\aleph_0} \ge \aleph_1 \quad (\beth_1 \ge \aleph_1)
$$

```diagram

A1: round "Aleph_1" @ 100, 140
A2: round "Aleph_2" @ 100, 220
B1: round "Beth_1 = 2^(Aleph_0)" @ 260, 140
B2: round "Beth_2 = 2^(Beth_1)" @ 260, 220

A0 -> B1 : булеан (2^x)

A1 -> B1 : CH: равны ли они?
```

:::meaning
**Определение 14 (Континуум-гипотеза / Continuum Hypothesis, CH):**
Континуум-гипотеза утверждает, что между счётной мощностью $\aleph_0$ и мощностью континуума $2^{\aleph_0}$ нет промежуточных мощностей, то есть:
$$
2^{\aleph_0} = \aleph_1 \quad (\beth_1 = \aleph_1)
$$
Обобщённая континуум-гипотеза (GCH) утверждает, что обе лестницы полностью совпадают на всех уровнях: $\forall \alpha \ (\beth_\alpha = \aleph_\alpha)$.
:::

### Независимость континуум-гипотезы

Континуум-гипотеза была первой проблемой в знаменитом списке Гильберта (1900 год). Её решение стало триумфом математической логики XX века:

:::remember
**Теорема 12 (Гёдель, 1938; Коэн, 1963):**
Если стандартная система аксиом теории множеств Цермело — Френкеля с аксиомой выбора (ZFC) непротиворечива, то:
1. Континуум-гипотезу **нельзя опровергнуть** в ZFC (Курт Гёдель доказал, что существует непротиворечивая модель $L$ — конструктивный универсум, в котором $\text{CH}$ истинна);
2. Континуум-гипотезу **нельзя доказать** в ZFC (Пол Коэн разработал революционный метод *форсинга* и построил модель, в которой к $\mathbb{N}$ добавляется несчётно много новых подмножеств без изменения кардиналов, делая $2^{\aleph_0} = \aleph_2$ или даже больше).

Континуум-гипотеза **независима** от системы аксиом ZFC.
:::

### Парадокс Бурали-Форти

Можем ли мы собрать абсолютно все существующие ординалы фон Неймана в единое гигантское множество $\Omega$?

Ответ даёт первый исторический парадокс теории множеств, открытый Чезаре Бурали-Форти в 1897 году:

:::remember
**Теорема 13 (Парадокс Бурали-Форти, 1897):**
Не существует множества всех ординалов.
:::

**Доказательство:**
1. Предположим противное: пусть существует множество $\Omega$, элементами которого являются абсолютно все ординалы фон Неймана:
   $$
   \Omega = \{\alpha \mid \alpha \text{ — ординал}\}
   $$
2. *Транзитивность $\Omega$:* Если $\alpha \in \Omega$ (то есть $\alpha$ — ординал) и $\beta \in \alpha$, то по Теореме 3 $\beta$ сам является ординалом, а значит, $\beta \in \Omega$. Следовательно, множество $\Omega$ транзитивно.
3. *Вполне упорядоченность:* Отношение принадлежности $\in$ линейно сравнимо на любых двух ординалах (Теорема 4) и каждое непустое подмножество ординалов имеет наименьший элемент. Следовательно, $(\Omega, \in)$ вполне упорядочено.
4. *Противоречие:* Но множество, которое транзитивно и вполне упорядочено отношением $\in$, по Определению 5 **само является ординалом фон Неймана**!
5. Значит, $\Omega$ обязано входить в множество всех ординалов:
   $$
   \Omega \in \Omega
   $$
6. Однако для любого ординала отношение $\in$ является строгим порядком (иррефлексивным: никакой ординал не может содержать себя $\alpha \notin \alpha$). Принадлежность $\Omega \in \Omega$ прямо противоречит природе строгого порядка.
Полученное противоречие доказывает, что объекта «множество всех ординалов» существовать не может. $\blacksquare$

### Собственные классы

Парадокс Бурали-Форти (как и парадокс Рассела) не разрушил теорию, а показал необходимость различать множества и классы:

:::meaning
**Определение 15 (Собственный класс / Proper Class):**
Совокупность математических объектов, заданная общим свойством, которая является «слишком большой», чтобы быть множеством, называется **собственным классом**.
Совокупность всех ординалов обозначается:
$$
\mathrm{Ord} = \{\alpha \mid \alpha \text{ — ординал}\}
$$
$\mathrm{Ord}$ является собственным классом.
:::

К собственному классу нельзя применить теоретико-множественные операции (нельзя взять его булеан, нельзя включить его в другое множество в качестве элемента, к нему неприменима теорема о представлении). Квантор $\forall \alpha$ («для любого ординала») в математических формулировках понимается как квантор по классу $\mathrm{Ord}$.

### Аксиома подстановки

В наивной теории множеств Цермело не удавалось доказать существование ординалов вроде $\omega \cdot 2$ или $\omega^2$ как множеств. Для преодоления этой проблемы Абрахам Френкель в 1922 году дополнил систему аксиомой подстановки (замещения):

:::meaning
**Определение 16 (Аксиома подстановки / Replacement Axiom):**
Если на множестве $A$ задано функциональное соотношение (свойство, однозначно сопоставляющее каждому элементу $x \in A$ объект $F(x)$), то образ множества $A$ при этом отображении также является множеством:
$$
\{F(x) \mid x \in A\} \quad \text{— множество.}
$$
:::

Именно аксиома подстановки позволяет применить отображение $n \mapsto \omega + n$ к множеству натуральных чисел $\mathbb{N}$ и получить множество $\{\omega, \omega + 1, \omega + 2, \dots\}$, чьё объединение даёт ординал $\omega \cdot 2$. Она необходима для существования ординалов $\omega^2, \omega^\omega$, а также кардиналов $\aleph_\omega$ и $\omega_1$.

### Аксиома регулярности

:::meaning
**Определение 17 (Аксиома регулярности / Foundation Axiom):**
Всякое непустое множество $A$ содержит элемент $x \in A$, не пересекающийся с $A$:
$$
\forall A \ (A \ne \varnothing \implies \exists x \in A \ (x \cap A = \varnothing))
$$
:::

Аксиома регулярности исключает из теории множеств «патологические» конструкции:
- Запрещает множеству принадлежать самому себе: $x \in x$ невозможно (если рассмотреть $A = \{x\}$, то единственный элемент $x$ обязан не пересекаться с $A$, откуда $x \notin x$);
- Запрещает циклы принадлежности вида $x_1 \in x_2 \in \dots \in x_n \in x_1$;
- Запрещает бесконечный нисходящий спуск по принадлежности: $\dots \in x_2 \in x_1 \in x_0$.

## Первый несчётный ординал $\omega_1$

> Мы должны знать. Мы будем знать.
>
> — Давид Гильберт

### Множество счётных ординалов

Мы видели бесконечное число счётных ординалов:
$$
0, 1, 2, \dots, \omega, \omega + 1, \dots, \omega \cdot 2, \dots, \omega^2, \dots, \omega^\omega, \dots, \varepsilon_0, \dots
$$
Счётных ординалов огромное множество. Собраны ли они все в единый объект?

:::meaning
**Определение 18 (Первый несчётный ординал $\omega_1$):**
Первый несчётный ординал $\omega_1$ определяется как совокупность **всех счётных ординалов**:
$$
\omega_1 = \{\alpha \in \mathrm{Ord} \mid |\alpha| \le \aleph_0\}
$$
:::

Проверим свойства $\omega_1$:
1. *Транзитивность:* Если $\alpha \in \omega_1$ (то есть $\alpha$ счётен) и $\beta \in \alpha$, то $\beta$ — ординал и $\beta \subseteq \alpha$. Подмножество счётного множества не более чем счётно, поэтому $\beta$ тоже счётен $\implies \beta \in \omega_1$.
2. *Вполне упорядоченность:* Как подкласс $\mathrm{Ord}$, множество $\omega_1$ вполне упорядочено отношением $\in$.

Следовательно, $\omega_1$ — полноценный ординал фон Неймана!

### Несчётность множества счётных ординалов

Сколько элементов в $\omega_1$?

:::remember
**Теорема 14:**
Множество всех счётных ординалов $\omega_1$ **несчётно**:
$$
|\omega_1| = \aleph_1
$$
$\omega_1$ является **наименьшим несчётным ординалом**.
:::

**Доказательство (от противного):**
1. Предположим, что множество $\omega_1$ счётно.
2. Тогда мы можем рассмотреть точную верхнюю грань (супремум) всех его элементов:
   $$
   \gamma = \sup \omega_1 = \bigcup_{\alpha \in \omega_1} \alpha
   $$
3. Величина $\gamma$ представляет собой счётное объединение счётных множеств. По классической теореме теории множеств, счётное объединение счётных множеств **счётно**.
4. Следовательно, ординал $\gamma$ сам является счётным: $\gamma \in \omega_1$.
5. Но если $\gamma$ счётен, то и следующий за ним ординал $\gamma + 1 = \gamma \cup \{\gamma\}$ также счётен!
6. Значит, $\gamma + 1 \in \omega_1$.
7. Однако $\gamma + 1 > \gamma = \sup \omega_1$, что невозможно, так как супремум множества не может быть строго меньше элемента этого же множества.
8. Противоречие доказывает, что $\omega_1$ не может быть счётным. $\blacksquare$

:::note
**Важное следствие:**
Объединение любой счётной последовательности счётных ординалов $\alpha_0, \alpha_1, \alpha_2, \dots$ всегда строго меньше $\omega_1$:
$$
\sup_{n < \omega} \alpha_n < \omega_1
$$
В $\omega_1$ невозможно добраться до конца ни за какие счётные шаги.
:::

Лестница продолжается и за пределами $\omega_1$:
$$
\omega_1, \quad \omega_1 + 1, \quad \omega_1 + 2, \quad \dots, \quad \omega_1 \cdot 2, \quad \dots, \quad \omega_1^2, \quad \dots, \quad \omega_2, \quad \dots
$$
Каждый кардинал $\aleph_\alpha$ служит начальной точкой для огромного пласта ординалов соответствующей мощности.

```quiz

- [x] Потому что счётное объединение счётных множеств счётно, а значит, результат объединения сам является счётным ординалом, лежащим внутри $\omega_1$ :: $\sup_{n} \alpha_n \in \omega_1$.
- [ ] Потому что $\omega_1$ конечно :: $\omega_1$ несчётно.
- [ ] Потому что последовательности ординалов не имеют точной верхней грани :: Во вполне упорядоченном множестве супремум ограниченного подмножества существует всегда.
explain: Счётное объединение счётных ординалов счётно, следовательно, результат остаётся элементом $\omega_1$.
```

## Завершаемость и ординалы: Гудстейн и Гидра

> Путь в тысячу ли начинается с одного шага.
>
> — Лао-цзы

### Наследственная запись чисел

В 1944 году английский математик Рубен Гудстейн предложил процесс над натуральными числами, демонстрирующий колоссальную мощь ординалов. В основе его конструкции лежит наследственная запись чисел по основанию $b \ge 2$.

В обычной позиционной системе основание $b$ пишется только на нижнем уровне: $26 = 2 \cdot 3^2 + 2 \cdot 3^1 + 2 \cdot 3^0$. В **наследственной записи** показатели степеней также рекурсивно представляются в том же базисе $b$, пока все показатели не станут строго меньше $b$:

:::meaning
**Определение 19 (Наследственная запись по основанию $b$):**
Число $n \ge b$ представляется в виде:
$$
n = c_1 b^{k_1} + c_2 b^{k_2} + \dots + c_m b^{k_m}
$$
где $1 \le c_i < b$, показатели $k_1 > k_2 > \dots > k_m \ge 0$, и каждый показатель $k_i$ сам рекурсивно записан наследственно по основанию $b$.
:::

:::example
- Число $4$ по основанию $2$:
  $$
  4 = 2^2 = 2^{2^1}
  $$
- Число $26$ по основанию $3$:
  $$
  26 = 2 \cdot 3^2 + 2 \cdot 3^1 + 2
  $$
  (показатель $2 < 3$, поэтому рекурсия завершена).
- Число $35$ по основанию $2$:
  $$
  35 = 2^5 + 2^1 + 1 = 2^{2^2 + 1} + 2^1 + 1 = 2^{2^{2^1} + 1} + 2^1 + 1
  $$
:::

### Последовательность Гудстейна

:::meaning
**Определение 20 (Последовательность Гудстейна):**
Для любого стартового натурального числа $n \ge 1$:
1. Полагаем $a_1 = n$, базовое основание $b_1 = 2$.
2. На шаге $i \ge 1$:
   - Если $a_i = 0$, последовательность завершается.
   - Иначе записываем число $a_i$ **наследственно по основанию** $b_i = i + 1$.
   - **Раздувание:** заменяем абсолютно каждое вхождение основания $b_i$ на $b_i + 1$.
   - **Уменьшение:** вычитаем из полученного гигантского числа единицу:
     $$
     a_{i+1} = \text{Замена}(a_i, b_i \mapsto b_i + 1) - 1
     $$
     Основание для следующего шага становится $b_{i+1} = b_i + 1 = i + 2$.
:::

Рассмотрим поведение последовательности для малых чисел:

:::example
**Последовательность Гудстейна для $n = 3$:**
1. Шаг 1 ($b_1 = 2$): $a_1 = 3 = 2^1 + 1$.
   Заменяем основание $2 \to 3$: получаем $3^1 + 1 = 4$.
   Вычитаем $1$: $a_2 = 4 - 1 = 3$.
2. Шаг 2 ($b_2 = 3$): $a_2 = 3 = 3^1$.
   Заменяем основание $3 \to 4$: получаем $4^1 = 4$.
   Вычитаем $1$: $a_3 = 4 - 1 = 3$.
3. Шаг 3 ($b_3 = 4$): $a_3 = 3$ (меньше основания $4$, степень равна нулю).
   Замена основания ничего не меняет: $3 \to 3$.
   Вычитаем $1$: $a_4 = 3 - 1 = 2$.
4. Шаг 4 ($b_4 = 5$): $a_4 = 2 \implies a_5 = 1$.
5. Шаг 5 ($b_5 = 6$): $a_5 = 1 \implies a_6 = 0$ — процесс завершился за $5$ шагов!
Последовательность для $n = 3$: $3, 3, 3, 2, 1, 0$.
:::

Но что происходит для $n = 4$?
- $a_1 = 4 = 2^{2^1}$ (база $2$);
- $a_2 = 3^{3^1} - 1 = 27 - 1 = 26 = 2 \cdot 3^2 + 2 \cdot 3 + 2$ (база $3$);
- $a_3 = 2 \cdot 4^2 + 2 \cdot 4 + 1 = 41$ (база $4$);
- $a_4 = 2 \cdot 5^2 + 2 \cdot 5 = 60$ (база $5$);
- $a_5 = 2 \cdot 6^2 + 1 \cdot 6 + 5 = 83$ (база $6$);
- $a_6 = 2 \cdot 7^2 + 1 \cdot 7 + 4 = 109$ (база $7$);
- $\dots$
Число $a_i$ начинает расти с чудовищной, астрономической скоростью! Кажется абсолютно очевидным, что эта последовательность будет расти до бесконечности и никогда не сможет обратиться в ноль.

### Теорема Гудстейна и ординальная мера

Однако интуиция нас обманывает:

:::remember
**Теорема 15 (Теорема Гудстейна, 1944):**
Для **любого** начального числа $n$ последовательность Гудстейна гарантированно достигнет нуля за конечное число шагов!
:::

**Доказательство с помощью ординальной меры:**
Сопоставим числу $a_i$ ординал $\mu(a_i)$, заменив в его наследственной записи текущее основание $b_i$ на ординал $\omega$:

| Шаг $i$ | Число $a_i$ | Наследственная запись по базе $b_i$ | Ординальная мера $\mu(a_i)$ (база $\mapsto \omega$) |
| :---: | :---: | :--- | :--- |
| 1 | $4$ | $2^{2^1}$ | $\omega^{\omega^1} = \omega^\omega$ |
| 2 | $26$ | $2 \cdot 3^2 + 2 \cdot 3 + 2$ | $2\omega^2 + 2\omega + 2$ |
| 3 | $41$ | $2 \cdot 4^2 + 2 \cdot 4 + 1$ | $2\omega^2 + 2\omega + 1$ |
| 4 | $60$ | $2 \cdot 5^2 + 2 \cdot 5$ | $2\omega^2 + 2\omega$ |
| 5 | $83$ | $2 \cdot 6^2 + 1 \cdot 6 + 5$ | $2\omega^2 + \omega + 5$ |
| 6 | $109$ | $2 \cdot 7^2 + 1 \cdot 7 + 4$ | $2\omega^2 + \omega + 4$ |

Посмотрим, что происходит с мерой $\mu$ на каждом шаге:
1. **Замена основания $b_i \to b_i + 1$:** На месте основания в ординальной мере стояла буква $\omega$. После замены там остаётся та же самая буква $\omega$! Раздувание основания вообще **не меняет** ординал!
2. **Вычитание единицы:** Уменьшение числа на $1$ строго уменьшает ординальную меру:
   $$
   \omega^\omega > 2\omega^2 + 2\omega + 2 > 2\omega^2 + 2\omega + 1 > 2\omega^2 + 2\omega > 2\omega^2 + \omega + 5 > \dots
   $$
Все меры лежат строго ниже $\varepsilon_0$.
Поскольку ординалы вполне упорядочены, бесконечной строго убывающей последовательности ординалов существовать не может (Теорема 1). Значит, последовательность ординалов обязана достичь нуля за конечное число шагов. А так как $\mu(a_i) = 0 \iff a_i = 0$, сама последовательность Гудстейна обязательно оборвётся в ноль! $\blacksquare$

### Граница Пеано и теорема Генцена

Теорема Гудстейна формулируется исключительно в терминах обычных натуральных чисел: в ней нет никаких ординалов или бесконечных множеств. Можно ли доказать её методами обычной школьной арифметики?

В 1982 году Лори Кирби и Джефф Пэрис доказали поразительный результат:
:::remember
**Теорема Кирби — Пэриса (1982):**
Теорема Гудстейна **недоказуема** в формальной арифметике Пеано (PA), если PA непротиворечива.
:::

Индукция до ординала $\varepsilon_0$ принципиально выходит за пределы выразительной силы арифметики Пеано.
Ранее, в 1936 году, Герхард Генцен доказал непротиворечивость самой арифметики Пеано, используя трансфинитную индукцию ровно до этого же ординала $\varepsilon_0$. По второй теореме Гёделя о неполноте никакая теория не может доказать собственную непротиворечивость своими внутренними средствами, поэтому выход за границу $\varepsilon_0$ математически неизбежен.

### Игра в Гидру

Другая наглядная геометрическая иллюстрация трансфинитной завершаемости — математическая битва Геркулеса с Гидрой:

Гидра представляет собой конечное ориентированное дерево с выделенным корнем. Вершины дерева — головы Гидры.
На шаге $n$:
1. Геркулес отрубает одну из голов (лист дерева).
2. Если отрубленная голова росла прямо из корня дерева, она просто исчезает.
3. Если же голова росла из промежуточного узла $u$, то оставшаяся часть поддерева с корнем в $u$ (без срезанной головы) немедленно **клонируется $n$ раз** и прикрепляется к родителю узла $u$!

```tree
Корень
  Шея
    Голова 1 (срез)
    Голова 2
```

После срезания «Головы 1» на шаге $n=2$ узел «Шея» вместе с «Головой 2» клонируется $2$ раза:

```tree
Корень
  Шея_копия1
    Голова 2
  Шея_копия2
    Голова 2
```

Кажется, что Гидра побеждает: число голов на каждом шаге лавинообразно увеличивается.

:::remember
**Теорема 16 (Кирби — Пэрис, 1982):**
Какую бы стратегию срезания голов ни выбрал Геркулес (даже самую глупую и неэффективную), **Гидра неизбежно погибнет** (будет полностью срублена под корень) за конечное число ходов.
При этом утверждение о гибели Гидры также **недоказуемо в арифметике Пеано**.
:::

*Причина:* Мера дерева Гидры — это ординал ниже $\varepsilon_0$. Хотя количество голов возрастает, высота дерева уменьшается, и суммарный ординал строго падает на каждом ударе!

### Меры в верификации программ

Ординальные меры активно используются на практике в современных системах автоматического доказательства теорем и проверки завершаемости кода:
- **AProVE** — автоматический верификатор завершаемости программ на Java, C и функциональных языках; использует ординальные меры для сложных вложенных циклов и взаимно-рекурсивных функций.
- **Isabelle / HOL** и **Dafny** — ассистенты доказательств, поддерживающие лексикографические кортежи и порядки рекурсивного пути (Recursive Path Orders, RPO) над деревьями выражений.

## Большие кардиналы

> Напрасно пытаться посредством большего делать то, что может быть сделано посредством меньшего.
>
> — Уильям Оккам

### Кофинальность и регулярность

Чтобы исследовать саму вершину бесконечности, математики вводят классификацию кардиналов по способу приближения к ним.

:::meaning
**Определение 21 (Кофинальность):**
**Кофинальностью** кардинала $\kappa$, обозначаемой $\operatorname{cf}(\kappa)$, называется наименьшая мощность подмножества $X \subseteq \kappa$, не ограниченного сверху в $\kappa$ (то есть $\sup X = \kappa$).

Кардинал называется **регулярным**, если его кофинальность совпадает с ним самим:
$$
\operatorname{cf}(\kappa) = \kappa
$$
Если же $\operatorname{cf}(\kappa) < \kappa$, кардинал называется **сингулярным**.
:::

:::example
1. $\aleph_0$ **регулярен**: $\operatorname{cf}(\aleph_0) = \aleph_0$. Никакое конечное подмножество натуральных чисел не может быть неограниченным в $\mathbb{N}$.
2. $\aleph_1$ **регулярен**: $\operatorname{cf}(\aleph_1) = \aleph_1$. Супремум любого счётного семейства счётных ординалов счётен (Теорема 14), поэтому до $\aleph_1$ нельзя добраться с помощью счётного числа шагов.
3. $\aleph_\omega$ **сингулярен**: $\operatorname{cf}(\aleph_\omega) = \aleph_0$. Кардинал $\aleph_\omega$ несчётен, но к нему можно подойти через счётную цепочку строго меньших кардиналов:
   $$
   \aleph_\omega = \sup \{\aleph_0, \aleph_1, \aleph_2, \aleph_3, \dots\}
   $$
:::

### Недостижимые кардиналы

Кардиналы бывают пределами в двух разных смыслах:
:::meaning
**Определения 23 и 24 (Слабый и сильный пределы):**
1. Кардинал $\kappa$ называется **предельным**, если для любого $\lambda < \kappa$ следующий кардинал также меньше $\kappa$: $\lambda^+ < \kappa$.
2. Кардинал $\kappa$ называется **сильным предельным** (strong limit), если операция взятия булеана не выводит за его пределы:
   $$
   \forall \lambda < \kappa \implies 2^\lambda < \kappa
   $$
:::

:::meaning
**Определение 22 (Недостижимый кардинал / Inaccessible Cardinal):**
Несчётный кардинал $\kappa > \aleph_0$ называется **недостижимым** (сильно недостижимым), если он:
1. **Регулярен:** $\operatorname{cf}(\kappa) = \kappa$ (до него нельзя дойти объединением меньшего числа меньших множеств);
2. **Является сильным пределом:** $\forall \lambda < \kappa \implies 2^\lambda < \kappa$ (до него нельзя дойти операцией булеана).
:::

Кардинал $\aleph_0$ регулярен и является сильным пределом ($2^n < \aleph_0$ для любого конечного $n$), но он счётен. Недостижимый кардинал — это несчётный аналог $\aleph_0$, абсолютный гигант, недостижимый «снизу» никакими стандартными операциями ZFC.

### Что даёт недостижимый кардинал

Пусть $\kappa$ — недостижимый кардинал. Рассмотрим кумулятивную иерархию фон Неймана — все множества, которые можно построить из пустого множества меньше чем за $\kappa$ шагов:
$$
V_\kappa = \bigcup_{\alpha < \kappa} \mathcal{P}(V_\alpha)
$$

:::remember
**Теорема 17:**
Если $\kappa$ — недостижимый кардинал, то универсум $V_\kappa$ удовлетворяет абсолютно **всем аксиомам ZFC**.
То есть $V_\kappa$ является полноценной **моделью теории множеств ZFC**!
:::

Отсюда следует фундаментальный вывод логики:
- Если существует хотя бы один недостижимый кардинал, то у ZFC существует модель, а значит, **теория ZFC непротиворечива**.
- Но по второй теореме Гёделя теория ZFC не способна доказать собственную непротиворечивость.
- Следовательно, **существование недостижимого кардинала в принципе невозможно доказать внутри ZFC**!

Гипотеза о существовании недостижимого кардинала — это новая, более сильная аксиома, открывающая вход в бесконечную иерархию *больших кардиналов* (слабокомпактные, измеримые и др.).
