## Многочлены степени не выше двух с заданными корнями

:::meaning
В пространстве $\mathcal P_2(\mathbb R)$ каждый многочлен имеет вид $p(x)=ax^2+bx+c$, где $a,b,c\in\mathbb R$. Условие «степень не выше двух» допускает $a=0$.
:::

:::example
**Задача.** Найти все $p\in\mathcal P_2(\mathbb R)$, для которых $p(1)=p(2)=0$.

Подставим $1$ и $2$ в многочлен. Получим уравнения $a+b+c=0$ и $4a+2b+c=0$. Вычтем из второй строки первую, умноженную на $4$.
:::

```matrix
title: Система для коэффициентов многочлена
columns: Коэффициенты | Правая часть
rhs: last
pivots: 1, 2
1 1 1 | 0
4 2 1 | 0
add 2 1 -4
print: last
```

Из второй строки получаем $-2b-3c=0$. Пусть $c=\lambda$, где $\lambda\in\mathbb R$. Тогда $b=-3\lambda/2$, а из первой строки $a=-b-c=\lambda/2$. Итак,

$$
p(x)=\frac{\lambda}{2}x^2-\frac{3\lambda}{2}x+\lambda
=\frac{\lambda}{2}(x-1)(x-2),\qquad \lambda\in\mathbb R.
$$

Подстановка $x=1$ и $x=2$ даёт ноль при любом $\lambda$. При $\lambda=0$ получаем нулевой многочлен.

```quiz
title: Проверка: многочлены с заданными корнями

? Какое уравнение даёт условие $p(2)=0$ для $p(x)=ax^2+bx+c$?
- [ ] $2a+2b+c=0$
- [x] $4a+2b+c=0$
- [ ] $4a+b+c=0$
explain: После подстановки $x=2$ множитель при $a$ равен $2^2=4$, а при $b$ равен $2$.

? Чему равен коэффициент $a$ у многочлена с условиями $p(1)=p(2)=0$ и $c=2$? Введите целое число.
= 1
explain: Из системы получаем $a=c/2=1$.
```

## Совместность СЛАУ и общее решение

:::meaning
В записи $AX=b$ матрица $A$ содержит коэффициенты при неизвестных, $X$ — столбец неизвестных, $b$ — столбец свободных членов. Запись $(A\mid b)$ обозначает расширенную матрицу. Система **совместна**, если имеет хотя бы одно решение.
:::

:::remember
**Критерий Кронекера — Капелли.** Система $AX=b$ совместна тогда и только тогда, когда $\operatorname{rank}A=\operatorname{rank}(A\mid b)$. Строка $(0,\ldots,0\mid d)$ при $d\ne0$ в ступенчатой матрице означает противоречие $0=d$.
:::

:::formula
Общее решение совместной системы имеет вид $X=X_{\mathrm{ч}}+X_{\mathrm{одн}}$. Здесь $X_{\mathrm{ч}}$ — одно фиксированное решение $AX=b$, а $X_{\mathrm{одн}}$ пробегает решения $AX=0$. Если $AX=b$, то $A(X-X_{\mathrm{ч}})=b-b=0$. Обратно, если $AY=0$, то $A(X_{\mathrm{ч}}+Y)=b$.
:::

:::example
**Задача.** Решить СЛАУ с расширенной матрицей ниже.

Обозначим строки через $R_i$. После $R_2\gets R_2-2R_1$ и $R_3\gets R_3-R_1$ получаем строки $(0,0,-1,5,-1\mid-1)$ и $(0,0,-2,10,-2\mid-2)$. Третья строка вдвое больше второй. Преобразование $R_3\gets R_3-2R_2$ обнуляет её, включая правую часть. Обе матрицы имеют ранг $2$, поэтому система совместна.
:::

```matrix
title: Система с тремя параметрами
columns: Коэффициенты | Правая часть
rhs: last
pivots: 1, 3
2 -1 3 -2 4 | 1
4 -2 5 1 7 | 1
2 -1 1 8 2 | -1
add 2 1 -2
add 3 1 -1
add 3 2 -2
scale 2 -1
print: last
```

Ведущие столбцы ступенчатой матрицы соответствуют $x_1,x_3$. Для параметризации можно задать $x_1=\gamma$, $x_4=\beta$, $x_5=\lambda$, поскольку первое уравнение однозначно определит $x_2$ после нахождения $x_3$:

$$
\begin{aligned}
x_3&=5\beta-\lambda+1,\\
x_2&=2\gamma+3x_3-2\beta+4\lambda-1
=2\gamma+13\beta+\lambda+2.
\end{aligned}
$$

Поэтому

$$
X=
\begin{pmatrix}0\\2\\1\\0\\0\end{pmatrix}
+\gamma\begin{pmatrix}1\\2\\0\\0\\0\end{pmatrix}
+\beta\begin{pmatrix}0\\13\\5\\1\\0\end{pmatrix}
+\lambda\begin{pmatrix}0\\1\\-1\\0\\1\end{pmatrix},
\qquad \gamma,\beta,\lambda\in\mathbb R.
$$

Первый столбец — частное решение. Три столбца при параметрах задают однородную часть. Они линейно независимы, поскольку их координаты в позициях $1,4,5$ образуют единичную матрицу.

```quiz

- [ ] Ранг расширенной матрицы больше ранга матрицы коэффициентов
- [x] Каждая нулевая строка коэффициентов имеет нулевую правую часть
- [ ] После исключения появилась строка $0=1$
explain: Оба верных признака означают, что в ступенчатой форме нет противоречивого уравнения.

? Чему равно $x_2$ в частном решении системы ранга $2$ при $\gamma=\beta=\lambda=0$? Введите целое число.
= 2
explain: В формуле $x_2=2\gamma+13\beta+\lambda+2$ остаётся свободный член $2$.
```

## Координаты вектора в заданном базисе

:::meaning
Координаты вектора $v$ в базисе $(b_1,b_2,b_3)$ — коэффициенты его единственного разложения $v=x_1b_1+x_2b_2+x_3b_3$. Если положить $B=(b_1\ b_2\ b_3)$, то это равенство принимает вид $BX=v$.
:::

:::example
**Задача.** Проверить, что $b_1=(1,2,3)^{\mathsf T}$, $b_2=(1,1,2)^{\mathsf T}$, $b_3=(1,1,1)^{\mathsf T}$ образуют базис, и найти в нём координаты $v=(4,7,5)^{\mathsf T}$.

Составим матрицу из этих столбцов и разложим её определитель по первой строке:

$$
\det B=
\begin{vmatrix}
1&1&1\\
2&1&1\\
3&2&1
\end{vmatrix}
=(1-2)-(2-3)+(4-3)=1.
$$

Определитель отличен от нуля, поэтому столбцы образуют базис $\mathbb R^3$. Теперь решим $BX=v$ методом Гаусса.
:::

```matrix
title: Координаты вектора методом Гаусса
columns: Столбцы базиса | Вектор
rhs: last
pivots: 1, 2, 3
1 1 1 | 4
2 1 1 | 7
3 2 1 | 5
add 2 1 -2
add 3 1 -3
add 3 2 -1
scale 2 -1
print: last
```

Последняя строка даёт $-x_3=-6$, откуда $x_3=6$. Далее $x_2=1-x_3=-5$ и $x_1=4-x_2-x_3=3$. Проверка:

$$
3b_1-5b_2+6b_3
=(3-5+6,\ 6-5+6,\ 9-10+6)^{\mathsf T}
=(4,7,5)^{\mathsf T}.
$$

```quiz
title: Проверка: координаты в базисе

? Как расположить $b_1,b_2,b_3$ в матрице системы $BX=v$?
- [x] По столбцам в порядке $b_1,b_2,b_3$
- [ ] По строкам в порядке $b_1,b_2,b_3$
- [ ] По столбцам в порядке $b_3,b_2,b_1$
explain: Произведение $BX$ складывает столбцы с коэффициентами $x_1,x_2,x_3$ в указанном порядке.

? Каков коэффициент при $b_2$ в разложении $v=(4,7,5)^{\mathsf T}$ по разобранному базису? Введите целое число.
= -5
explain: Обратная подстановка даёт $x_3=6$ и $x_2+x_3=1$, поэтому $x_2=-5$.
```

## Линейная оболочка столбцов и система с одним параметром

:::meaning
Линейная оболочка $\operatorname{span}(a_1,\ldots,a_n)$ состоит из всех линейных комбинаций векторов $a_1,\ldots,a_n$. Если это столбцы $A$, то $AX=x_1a_1+\cdots+x_na_n$. Поэтому $AX=b$ совместна тогда и только тогда, когда $b\in\operatorname{span}(a_1,\ldots,a_n)$. Решение указывает, с какими коэффициентами нужно сложить столбцы, чтобы получить $b$.
:::

:::example
**Задача.** Решить СЛАУ с расширенной матрицей ниже.

1. Поменяем местами первые две строки. Обнулим первый столбец под ведущей единицей. В частности, в четвёртой строке второй коэффициент становится $-1-2\cdot2=-5$, а правая часть становится $-6-2\cdot5=-16$.
2. Обнулим второй столбец под ведущим коэффициентом $-1$. Для этого прибавим к третьей строке утроенную вторую, а из четвёртой вычтем вторую, умноженную на $5$. Получим $x_3+4x_5=1$ и $4x_3-3x_5=4$.
3. Из четвёртой строки вычтем третью, умноженную на $4$. Получим $-19x_5=0$, поэтому $x_5=0$, а из третьей строки $x_3=1$.
:::

```matrix
title: Система с одним параметром
columns: Коэффициенты | Правая часть
rhs: last
pivots: 1, 2, 3, 5
2 3 1 0 1 | 6
1 2 1 1 0 | 5
-1 1 3 5 1 | 8
2 -1 1 -8 2 | -6
swap 1 2
add 2 1 -2
add 3 1 1
add 4 1 -2
add 3 2 3
add 4 2 -5
add 4 3 -4
scale 2 -1
print: last
```

:::warning
Свободные переменные определяют по столбцам без ведущего элемента. Здесь пятый столбец ведущий и значение $x_5$ фиксировано. Свободной остаётся только $x_4$.
:::

Положим $x_4=\beta$. Из второй строки $x_2+x_3+2x_4-x_5=4$, откуда $x_2=3-2\beta$. Из первой строки $x_1+2x_2+x_3+x_4=5$, значит $x_1=-2+3\beta$. Оба ранга равны $4$, и общее решение имеет вид

$$
X=(-2,3,1,0,0)^{\mathsf T}
+\beta(3,-2,0,1,0)^{\mathsf T},\qquad \beta\in\mathbb R.
$$

Первый вектор при умножении на $A$ даёт $(6,5,8,-6)^{\mathsf T}$, второй даёт нулевой вектор.

