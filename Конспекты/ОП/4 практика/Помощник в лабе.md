## Функция `countHello` — состояние через указатель

```cpp
int countHello(const char* str, std::size_t sz, int* match_idp = nullptr) {
    static const char* hello = "hello";
    static const std::size_t hello_sz = strlen(hello);

    int match_id = match_idp ? *match_idp : 0;
    int match = 0;

    for (int i = 0; i<sz; ++i) {
        if (str[i] == hello[match_id]){
            match_id++;
            if (match_id == hello_sz){
                match++;
                match_id=0;
            }
        }
        else {
            match_id = (str[i] == hello[0]) ? 1 : 0;
        }
    }

    if (nullptr!=match_idp){
        *match_idp = match_id;
    }

    return match;
}
```

- **Параметры**: `str` — указатель на начало буфера, `sz` — сколько байт в этом буфере реально нужно обработать, `match_[...]
- **`static const char* hello = "hello";`** и **`hello_sz`** — искомое слово и его длина вычисляются один раз (ключевое слово `static` внутр[...]

Модификатор `static` у локальной переменной внутри функции означает, что переменная создаётся один раз за всё вр[...]

## Функция `main`: чтение файла порциями

```cpp
int main(int argc, char** argv) {
    if (argc<2) {
        std::cout << "Argument count error\n";
        return 2;
    }
    FILE* f = fopen(argv[1], "r");

    if (nullptr==f) { 
        std::cout << "File read error\n";
        return 1;
    }
    char buf[BUF_SIZE]{};
    int helloes = 0;
    HelloCountContext ctx;

    std::size_t cnt;
    while ((cnt = fread(buf, sizeof(char), BUF_SIZE, f)) > 0) {
        buf[cnt < BUF_SIZE ? cnt : BUF_SIZE - 1] = '\0';
        std::cout << buf << std::endl;

        ctx.str = buf;
        ctx.sz = cnt;
        helloes += countHelloStruct(&ctx);
    }

    std::cout << helloes << std::endl;
    fclose(f);
    return 0;
}
```
