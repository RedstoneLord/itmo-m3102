# Анти-Магнит для int2026_t

## Условие задачи

К числу типа `int2026_t` на индекс `idx` подносится **Анти-Магнит**. Он действует так:

- все единицы в числе **расползаются на два разных конца** числа — как можно дальше от магнита;
- сам бит с индексом `idx` должен **уйти туда, где единиц меньше**.

Итог — функция `AntiMagnifier(int2026_t& n, const int idx)`: она переписывает число `n` на месте и возвращает его копию.

:::meaning
**Магнит** — позиция `idx` (номер бита, считая от младшего разряда с нуля). **Левая сторона** — разряды старше `idx` (в двоичной записи они стоят слева), **правая сторона** — разряды младше `idx`.
:::

:::remember
Результат работы: слева у старшего края числа стоит сплошной блок единиц, справа у младшего края — тоже сплошной блок единиц, между ними — нули. Общее количество единиц в числе не меняется.
:::

## Устройство числа и подсчёт единиц

Число хранится в массиве байтов `n.bytes` длиной `kByteCount` $= 254$. Байт с индексом $0$ содержит самые младшие разряды, байт с индексом `kByteCount - 1` — самые старшие. Поэтому «левая» сторона числа — это байты с большими индексами, «правая» — с меньшими.

Всего в числе `kBitCount` $= 2026$ значащих бит. Но $254 \cdot 8 = 2032$, то есть в старшем байте используются только $2026 - 253 \cdot 8 = 2$ младших бита. Остальные шесть бит старшего байта — «мусор», в корректном числе они всегда нулевые.

```cpp
constexpr int kByteCount = 254;
constexpr int kBitCount = 2026;
```

:::warning
Старший байт `bytes[kByteCount - 1]` хранит всего **2** значащих бита. Когда мы будем выкладывать единицы от левого края, край числа — это бит номер $2025$, а не бит $2031$.
:::

### Функция CountBits

Для подсчёта единиц в одном байте используется функция `CountBits`:

```cpp
int CountBits(uint8_t byte) {
    if (byte == 0) return 0;
    int s = 0;
    for (int i = 0; i < 8; ++i) {
        s += (byte >> i) & 1;
    }
    return s;
}
```

Как она работает:

1. Если байт нулевой, единиц нет — сразу возвращаем $0$.
2. Иначе перебираем все $8$ разрядов от $0$ до $7$.
3. Выражение `(byte >> i) & 1` сдвигает байт вправо на `i` позиций, так что нужный бит встаёт на место младшего, а `& 1` оставляет только его: получаем $0$ или $1$.
4. Все значения суммируются в `s`.

:::example
`CountBits(0b10110100)`:

1. Биты с $0$-го по $7$-й: $0, 0, 1, 0, 1, 1, 0, 1$.
2. Сумма: $0+0+1+0+1+1+0+1 = 4$.

Ответ: $4$ единицы.
:::

## Подсчёт единиц слева и справа от магнита

### Шаг 1. Индекс → байт и бит

Индекс `idx` — это номер бита во всём числе. Чтобы найти его в массиве байтов:

```cpp
int byte = idx / 8;
int bit = idx % 8;
```

- `byte` — номер байта, в котором лежит бит магнита;
- `bit` — номер бита внутри этого байта (от $0$ до $7$).

:::example
Пусть `idx = 19`.

1. $19 / 8 = 2$ (целочисленное деление) — магнит в байте с индексом $2$.
2. $19 \bmod 8 = 3$ — внутри байта это бит номер $3$.
:::

### Шаг 2. Единицы в целых байтах

```cpp
int nleft = 0;
int nright = 0;
for (int i = kByteCount - 1; i > byte; --i) {
    nleft += CountBits(n.bytes[i]);
}
for (int i = 0; i < byte; ++i) {
    nright += CountBits(n.bytes[i]);
}
```

- Первый цикл идёт от старшего байта вниз до байта магнита (не включая его) и копит единицы **слева** от магнита.
- Второй цикл идёт от нулевого байта вверх до байта магнита (не включая его) и копит единицы **справа**.

### Шаг 3. Единицы в самом байте магнита

Байт с магнитом делится на три части: биты выше магнита (уйдут в `nleft`), сам бит магнита, биты ниже магнита (уйдут в `nright`).

```cpp
if (bit != 7) {
    nleft += CountBits(n.bytes[byte] & (0b11111111 - (((1u << (bit + 1)) - 1) & 0b11111111)));
}
if (bit != 0) {
    nright += CountBits(n.bytes[byte] & ((1u << bit) - 1));
}
```

Разберём маски.

:::meaning
**Маска для нижних бит:** $(1 \ll \text{bit}) - 1$ — это число, у которого единицы стоят в разрядах $0, \ldots, \text{bit}-1$.

**Маска для верхних бит:** $255 - ((1 \ll (\text{bit}+1)) - 1)$ — из «всех единиц» вычитается маска разрядов $0, \ldots, \text{bit}$, остаются единицы в разрядах $\text{bit}+1, \ldots, 7$.
:::

:::example
Пусть `bit = 3`, а байт равен `0b10111010`.

1. Маска нижних бит: $(1 \ll 3) - 1 = 7 = \texttt{0b00000111}$.
2. Маска верхних бит: $255 - ((1 \ll 4) - 1) = 255 - 15 = 240 = \texttt{0b11110000}$.
3. Верхняя часть: `0b10111010 & 0b11110000 = 0b10110000` — три единицы, прибавляем $3$ к `nleft`.
4. Нижняя часть: `0b10111010 & 0b00000111 = 0b00000010` — одна единица, прибавляем $1$ к `nright`.
5. Сам бит магнита (бит $3$) равен $1$ — он пока не учтён ни там, ни там.
:::

:::warning
Условия `bit != 7` и `bit != 0` отражают крайние случаи: при `bit = 7` выше магнита в этом байте разрядов нет, при `bit = 0` ниже магнита разрядов нет. Бит самого магнита в `nleft` и `nright` на этом шаге **не входит**.
:::

## Куда уходит бит магнита

Бит магнита нужно отправить туда, где единиц **меньше**:

```cpp
nleft < nright ? nleft += (n.bytes[byte] >> bit) & 1 : nright += (n.bytes[byte] >> bit) & 1;
```

Выражение `(n.bytes[byte] >> bit) & 1` — это значение бита магнита ($0$ или $1$). Если слева единиц меньше, чем справа, оно прибавляется к `nleft`, иначе — к `nright`.

:::warning
- При **равенстве** `nleft == nright` условие `nleft < nright` ложно, и бит уходит **вправо**.
- Если бит магнита равен $0$, прибавляется ноль — `nleft` и `nright` не меняются.
:::

:::remember
После этого шага `nleft + nright` равно общему числу единиц в исходном числе, поэтому расползание единиц ничего не теряет и не добавляет.
:::

:::example
Пусть `nleft = 3`, `nright = 3`, бит магнита равен $1$.

1. Проверяем `nleft < nright`: $3 < 3$ — ложь.
2. Выполняется ветка `nright += 1`, получаем `nleft = 3`, `nright = 4`.

Если бы было `nleft = 2`, `nright = 3`, то $2 < 3$ — истина, и получилось бы `nleft = 3`, `nright = 3`.
:::

## Расползание единиц по краям

После того как `nleft` и `nright` известны, число очищается и единицы выкладываются заново.

```cpp
for (int i = 0; i < kByteCount; ++i) n.bytes[i] = 0;
```

### Левый край

Единицы выкладываются от самого старшего значащего бита вниз. Старший байт содержит только $2$ значащих бита, поэтому «вместимость» первого заполняемого байта равна $2$, а у остальных — $8$.

```cpp
int c = kByteCount - 1;
int room = kBitCount - 8 * (kByteCount - 1);
while (nleft > 0) {
    int take = nleft < room ? nleft : room;
    n.bytes[c] |= (((1u << take) - 1) << (room - take)) & 0b11111111;
    nleft -= take;
    c--;
    room = 8;
}
```

Как это работает:

1. `c` — номер заполняемого байта, начинаем со старшего. `room` — сколько значащих бит в нём (для старшего $2026 - 253 \cdot 8 = 2$).
2. `take` — сколько единиц положить в этот байт: не больше, чем осталось (`nleft`), и не больше, чем вместимость (`room`).
3. Выражение $((1 \ll \text{take}) - 1) \ll (\text{room} - \text{take})$ строит `take` подряд идущих единиц, прижатых к верхней границе значащих бит байта.
4. Перешли к следующему байту вниз, вместимость стала $8$.

:::example
Пусть `nleft = 11`.

1. Байт $253$: `room = 2`, `take = 2`, в него записывается `0b00000011`. Осталось $9$.
2. Байт $252$: `room = 8`, `take = 8`, записывается `0b11111111`. Осталась $1$.
3. Байт $251$: `take = 1`, записывается $((1 \ll 1) - 1) \ll 7 = \texttt{0b10000000}$. Осталось $0$.

Итого — сплошной блок из $11$ единиц, упирающийся в старший значащий бит числа.
:::

### Правый край

Единицы выкладываются от нулевого бита вверх:

```cpp
int d = 0;
while (nright > 0) {
    if (nright >= 8) {
        n.bytes[d] = 0b11111111;
        d++;
        nright -= 8;
    }
    else {
        n.bytes[d] |= ((1 << nright) - 1) & 0b11111111;
        d++;
        nright = 0;
    }
}
```

- Пока остаётся не меньше $8$ единиц, байт заполняется целиком.
- В последний байт кладётся $\text{nright}$ единиц в младших разрядах: $(1 \ll \text{nright}) - 1$.

:::example
Пусть `nright = 11`.

1. Байт $0$ получает `0b11111111`, остаётся $3$.
2. Байт $1$ получает $(1 \ll 3) - 1 = \texttt{0b00000111}$.
:::

:::warning
Левый и правый блоки не пересекаются: число единиц в обеих частях в сумме равно общему числу единиц, а оно не больше числа бит в числе.
:::

## Полный код функции и пример

Собираем всё вместе:

```cpp
int2026_t AntiMagnifier(int2026_t& n, const int idx) {
    int byte = idx / 8;
    int bit = idx % 8;
    int nleft = 0;
    int nright = 0;
    for (int i = kByteCount - 1; i > byte; --i) {
        nleft += CountBits(n.bytes[i]);
    }
    for (int i = 0; i < byte; ++i) {
        nright += CountBits(n.bytes[i]);
    }

    if (bit != 7) nleft += CountBits(n.bytes[byte] & (0b11111111 - (((1u << (bit + 1)) - 1) & 0b11111111)));
    if (bit != 0) nright += CountBits(n.bytes[byte] & ((1u << bit) - 1));
    nleft < nright ? nleft += (n.bytes[byte] >> bit) & 1 : nright += (n.bytes[byte] >> bit) & 1;

    for (int i = 0; i < kByteCount; ++i) n.bytes[i] = 0;

    int c = kByteCount - 1;
    int room = kBitCount - 8 * (kByteCount - 1);
    while (nleft > 0) {
        int take = nleft < room ? nleft : room;
        n.bytes[c] |= (((1u << take) - 1) << (room - take)) & 0b11111111;
        nleft -= take;
        c--;
        room = 8;
    }

    int d = 0;
    while (nright > 0) {
        if (nright >= 8) {
            n.bytes[d] = 0b11111111;
            d++;
            nright -= 8;
        }
        else {
            n.bytes[d] |= ((1 << nright) - 1) & 0b11111111;
            d++;
            nright = 0;
        }
    }

    return n;
}
```

:::note
Функция принимает число по неконстантной ссылке: число `n` изменяется на месте, а возвращается его копия. Подразумевается, что $0 \le \text{idx} < \text{kBitCount}$.
:::

```array
for (let k = 0; k < n; k++) { a[k] = 0; }
for (let k = 0; k < nl; k++) { a[k] = 1; }
for (let k = 0; k < nr; k++) { a[n - 1 - k] = 1; }
```

:::example
Разберём этот пример по шагам.

1. Слева от магнита ($m = 5$) стоят разряды $1, 0, 1, 0, 1$ — три единицы, `nl = 3`.
2. Справа: $0, 0, 1, 0$ — одна единица, `nr = 1`.
3. Бит магнита равен $1$. Сравниваем: $3 < 1$ — ложь, значит, бит уходит вправо: `nr = 2`.
4. Массив обнуляется.
5. Слева выкладываются $3$ единицы, справа — $2$.

Результат: `1 1 1 0 0 0 0 0 1 1`. Всего единиц $5$ — столько же, сколько было.
:::
