# Перегрузка операторов

[Материалы курса](https://is-itmo-c-26.github.io/lectures/lectures/09-operator-overloading.html)

## 1. Оператор как функция

:::meaning
**Перегрузка оператора** задаёт, какая функция выполняется, когда существующий оператор применён к значениям пользовательского типа. Хотя бы один операнд должен иметь тип класса или перечисления. Например, после определения `operator+` выражение `a + b` может складывать две дроби.
:::

В C++ есть арифметические, битовые, логические операторы, операторы сравнения, присваивания, доступа и работы с памятью. Перегрузка сохраняет грамматику выражения: приоритет, ассоциативность и число операндов изменить нельзя. Нельзя ввести новый знак операции. Среди неперегружаемых операторов — `::`, `.*`, `.` и `?:`.

В C++20 `=`, `[]`, `()` и `->` перегружают как методы. У метода левый операнд — текущий объект, а у свободной функции операнды передаются параметрами. Потоковые `<<` и `>>` для своего типа обычно делают свободными функциями: слева находится поток.

| Выражение | Как выглядит вызов метода | Как выглядит вызов свободной функции |
|---|---|---|
| `-a` | `a.operator-()` | `operator-(a)` |
| `a + b` | `a.operator+(b)` | `operator+(a, b)` |
| `a = b` | `a.operator=(b)` | — |
| `a(b)` | `a.operator()(b)` | — |
| `a[b]` | `a.operator[](b)` | — |
| `a++` | `a.operator++(0)` | `operator++(a, 0)` |

По знаку операции читатель заранее предполагает смысл. Например, сложение обычно вычисляет новое значение, а составное присваивание меняет левый операнд.


## 2. Дроби, сложение и присваивание

Класс `Rational` поддерживает единое представление: дробь сокращена, знаменатель положителен, ноль хранится как $0/1$. Конструктор нормализует переданные числа. При сложении новое значение тоже должно удовлетворять этому инварианту.

### `+=` и `+`

Чтобы сложить $a/b$ и $c/d$, их приводят к общему знаменателю:

$$
\frac{a}{b} + \frac{c}{d} = \frac{ad + cb}{bd}.
$$

В реализации курса вспомогательная функция складывает дроби, проверяет переполнение и возвращает сокращённый результат. `operator+=` присваивает результат текущей дроби и возвращает ссылку на неё. Свободный `operator+` получает левую дробь по значению, применяет к этой копии `+=` и возвращает её по значению. Так формула и проверки находятся в одном месте.

:::example
При сложении $1/2$ и $1/3$ общий знаменатель равен 6, числители после приведения — 3 и 2, результат — $5/6$. После `first + second` исходные дроби остаются $1/2$ и $1/3$. После `first += second` первая дробь становится $5/6$.
:::

### `operator=`

Чтобы присвоить одну уже созданную дробь другой, достаточно скопировать оба целых поля. Подходит и `Rational& operator=(const Rational&) = default;`: сам источник уже нормализован. Возвращённая ссылка нужна для цепочки `third = second = first`. Сначала меняется `second`, затем уже её значение присваивается `third`.

## 3. Ввод, вывод и цепочки

### Вывод

В выражении `stream << fraction` первым аргументом свободной функции служит `std::ostream&`, вторым — `const Rational&`. Функция печатает числитель, косую черту и знаменатель. Она возвращает тот же поток по ссылке, поэтому результат `stream << fraction` можно снова использовать слева от `<<`. Вывод нескольких присвоенных дробей можно собрать одной цепочкой.

### Ввод

Для `stream >> fraction` второй параметр имеет тип `Rational&`, потому что оператор записывает в объект. Последовательность действий важна:

1. Извлечь числитель, разделитель и знаменатель во временные переменные. При неудачном извлечении вернуть поток в его текущем состоянии.
2. Проверить, что разделитель — `/`, а знаменатель отличен от нуля. При нарушении установить `std::ios::failbit`.
3. Создать нормализованную дробь. Если нормализация не помещается в тип и выбрасывает `std::overflow_error`, установить `failbit`.
4. Присвоить готовую дробь и вернуть поток по ссылке.

```cpp
// Фрагмент для Rational с нормализующим конструктором.
std::istream& operator>>(std::istream& input, Rational& target) {
    int num{}, den{};
    char slash{};
    if (input >> num >> slash >> den) {
        if (slash == '/' && den != 0) {
            try {
                Rational parsed{num, den};
                target = parsed;
                return input;
            } catch (const std::overflow_error&) {
                input.setstate(std::ios::failbit);
            }
        } else {
            input.setstate(std::ios::failbit);
        }
    }
    return input;
}
```

:::warning
Объект обновляется после успешного построения нового значения. Например, при вводе дроби с нулевым знаменателем поток отмечает ошибку, а переменная сохраняет прежнее значение.
:::

## 4. Равенство и порядок

У нормализованных дробей равенство означает совпадение обоих полей. Например, $2/4$ хранится как $1/2$, поэтому эти дроби равны. Вручную `!=` можно выразить отрицанием `==`.

### Сравнение произведений

При положительных знаменателях можно умножить обе стороны неравенства на $bd$ без изменения знака:

$$
\frac{a}{b} < \frac{c}{d} \iff ad < cb.
$$

Например, для $-1/3$ и $1/2$ сравниваются $-1 \cdot 2 = -2$ и $1 \cdot 3 = 3$. Первая дробь меньше второй. Остальные сравнения можно записать через `<`: для `a > b` проверить `b < a`, для `a <= b` проверить `!(b < a)`, для `a >= b` проверить `!(a < b)`.

:::warning
К более широкому типу приводят **до** умножения. Если сначала умножить два значения `int`, последующее преобразование уже не защитит от переполнения. Для расчёта в `long long` код курса проверяет, что его диапазон вмещает произведения полей `int`.
:::

### Трёхстороннее сравнение в C++20

`operator<=>` может вернуть `std::strong_ordering` из `<compare>`: результат меньше нуля при меньшем левом операнде, равен нулю при равенстве и больше нуля при большем левом операнде. На его основе работают `<`, `>`, `<=` и `>=`. Для `!=` достаточно подходящего `operator==` с результатом `bool`.

Стандартный `operator<=> = default` сравнивает поля в порядке объявления и при отсутствии объявленного `operator==` неявно объявляет его. Для дробей порядок полей не задаёт числовой порядок: у $1/2$ и $1/3$ числители одинаковы, а сравнение знаменателей ошибочно поставит половину первой. Поэтому для `Rational` трёхстороннее сравнение сравнивает перекрёстные произведения, а равенство объявляется отдельно.

```cpp
#include <compare>
#include <limits>

// Фрагмент для класса Rational с методами numerator() и denominator().
std::strong_ordering operator<=>(const Rational& first, const Rational& second) {
    static_assert(std::numeric_limits<long long>::digits
                  >= 2 * std::numeric_limits<int>::digits);
    const long long left = 1LL * first.numerator() * second.denominator();
    const long long right = 1LL * second.numerator() * first.denominator();
    return left <=> right;
}
```

## 5. Инкремент и преобразование типа

### Префикс и постфикс

При увеличении дроби на единицу знаменатель можно сохранить: $a/b + 1 = (a+b)/b$. Нормализация сохраняется, потому что общие делители $a+b$ и $b$ совпадают с общими делителями $a$ и $b$. Перед сложением проверяют, что новый числитель помещается в `int`.

- Префиксный `operator++()` меняет дробь и возвращает ссылку на неё.
- Постфиксный `operator++(int)` сохраняет копию, вызывает префиксную форму и возвращает прежнее значение по значению. Фиктивный параметр `int` отличает эту перегрузку.

:::example
При начальной дроби $1/2$ после `Rational previous = value++;` переменная `previous` содержит $1/2$, а `value` — $3/2$. Следующая строка `Rational& current = ++value;` увеличивает `value` до $5/2$. `current` ссылается на тот же объект, поэтому адреса совпадают.
:::

### Преобразование в `float`

Объявление `explicit operator float() const` задаёт явное преобразование объекта во `float`. У функции преобразования целевой тип уже указан после `operator`. Перед делением числитель преобразуется во `float`, чтобы получить вещественное деление. Для дроби $1/2$ запись `static_cast<float>(half)` даёт $0.5$, а копирующая инициализация `float value = half;` с таким оператором вызовет ошибку компиляции.

## 6. `friend`, индексация и функциональные объекты

### Доступ через `friend`

Оператор вывода может читать дробь через публичные методы. Если ему нужен прямой доступ к закрытым полям, класс может объявить **эту функцию** другом через `friend`. Она по-прежнему свободная: первый операнд — поток, второй — дробь. Вывод нормализованного объекта, созданного из $2/4$, даст `1/2` в обоих случаях.

### Индексация

В `IntArray`, который хранит элементы в векторе, индекс должен быть меньше размера. Неконстантная перегрузка `int& operator[](std::size_t index)` возвращает изменяемую ссылку. Для константного объекта или ссылки `const IntArray&` выбирается `const int& operator[](std::size_t index) const`. Поэтому запись `values[1] = 42;` меняет ячейку, а чтение `view[1]` через константную ссылку на тот же массив даёт 42 без права записи.

### Функтор

:::meaning
**Функтор**, или функциональный объект, поддерживает вызов через `operator()`. У объекта может быть состояние, которое используется при вызове.
:::

Экземпляр `Multiplier` хранит множитель. Вызов объекта с множителем 2 и аргументом 3 даёт 6. Когда `std::transform` вызывает объект `Multiplier{5}` для каждого элемента последовательности от 1 до 5, результат — 5, 10, 15, 20, 25. Произведения должны помещаться в `int`.

## 7. RAII, разыменование и стрелка

:::meaning
**RAII** (Resource Acquisition Is Initialization) связывает ресурс со временем жизни объекта-владельца. При создании объекта он получает ресурс, а его деструктор освобождает ресурс. Это работает и при выходе из области видимости во время раскрутки стека из-за исключения.
:::

Ресурсом может быть память, файл или блокировка. В примере `FooPtr` принимает адрес объекта `Foo` от одиночного `new` и освобождает его через `delete`. Копирование явно запрещено, чтобы два владельца не удалили один адрес.

| Выражение | Как работает `FooPtr` |
|---|---|
| `*pointer` | `operator*()` возвращает `Foo&` на объект. |
| `pointer->foo()` | `operator->()` возвращает `Foo*`, после чего встроенная стрелка обращается к методу `foo`. |

Обращение требует непустой обёртки. Методы доступа могут быть `const`: владелец не меняет хранимый адрес при доступе. При этом возвращённые `Foo&` и `Foo*` оставляют сам `Foo` изменяемым. Это соответствует поведению `Foo* const`. В примере `pointer->foo()` и `(*pointer).foo()` обращаются к одному объекту и оба дают 2025.
