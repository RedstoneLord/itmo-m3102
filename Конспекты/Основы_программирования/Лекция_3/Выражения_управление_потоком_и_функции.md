# Выражения, управление потоком и функции

[Материалы курса](https://is-itmo-c-26.github.io/lectures/lectures/02-expressions-control-flow-functions.html)

## 1. Выражения, инструкции и блоки

:::meaning
**Выражение** задаёт вычисление. В `a + b` вычисляется сумма, а `i++` даёт прежнее значение `i` и одновременно меняет саму переменную. Изменение переменной — **побочный эффект**. Выражение типа `void`, например вызов функции, возвращающей `void`, значения не даёт.
:::

**Инструкция** описывает действие программы. Если к выражению добавить точку с запятой, получится инструкция-выражение. Например, в строке `c = a + b;` сначала вычисляется сумма, затем результат присваивается `c`. В строке `i++;` результат выражения отбрасывается, но инкремент выполняется. У `if` и `while` другая роль: они управляют тем, когда выполняются вложенные инструкции.

Фигурные скобки объединяют инструкции в **блок**. Блок можно использовать как тело ветви или цикла. Объявленные в нём локальные имена действуют до конца блока.

```quiz

- [x] Переменная `i` увеличивается на единицу.

? Как называется группа инструкций, заключённая в фигурные скобки? Ответьте одним словом.

explain: Блок можно поставить там, где ожидается одна инструкция, например в теле ветви.
```

## 2. Ветвление с `if`

Условие `if` приводится к `bool`. Для целого ноль даёт `false`, любое ненулевое значение — `true`. При истинном условии выполняется первая ветвь, при ложном — `else`, если он есть. В цепочке `else if` условия проверяются сверху вниз до первого истинного.

:::example
В примере с вложенными условиями обе переменные `outer_condition` и `inner_condition` ложны, а `result` изначально равен нулю.

```cpp
if (outer_condition)
    if (inner_condition)
        result = 1;
else
    result = 2;
```

Отступ сбивает с толку: `else` относится к ближайшему незакрытому `if`, то есть к внутреннему. Внешнее условие ложно, поэтому вся его инструкция пропускается и остаётся `result == 0`.

Если заключить внутренний `if` в тело внешней ветви в фигурных скобках и поставить `else` после закрывающей скобки, он станет ветвью **внешнего** `if`. Тогда результат равен двум.
:::

В примере с оценками пороги идут по убыванию: от 90 — `A`, от 75 — `B`, от 60 — `C`, иначе `F`. После выбора ветви остальные пороги уже не проверяются.

```quiz
title: Проверка: условия

? К какому условию относится `else` при вложении двух `if` без фигурных скобок?
- [ ] К тому, с которым он визуально выровнен.
- [ ] Ко внешнему условию.
- [x] К ближайшему `if` без своей ветви `else`.
explain: Отступы не меняют грамматику. Скобки нужны, чтобы явно задать границу ветви.

? Какую оценку даст цепочка проверок от 90, 75 и 60 баллов по убыванию при 75 баллах?

- [ ] `A`
- [ ] `C`
explain: Первая проверка ложна, вторая истинна. До третьей управление уже не доходит.
```

## 3. Циклы

| Цикл | Как проходит итерация |
|---|---|
| `while` | Проверка условия → тело, если условие истинно. |
| `do-while` | Тело → проверка условия. Первая итерация состоится в любом случае. |
| `for` | Инициализация один раз → проверка → тело → шаг → следующая проверка. |
| Диапазонный `for` | Перебирает элементы диапазона по очереди. |

### `while` и `do-while`

При обратном отсчёте от пяти `while (number > 0)` сначала проверяет число, затем печатает его и уменьшает. Ноль уже не печатается. В примере с `do-while` программа сначала просит ввести число и выводит его, а затем решает, повторять ли запрос. Введённый ноль тоже выводится: проверка стоит после тела.

В `do { ... } while (false);` тело запускается один раз и может завершиться раньше через `break`. В примере курса после неудачного открытия файла или выделения памяти управление сразу переходит за цикл, минуя обработку данных.

### `for`, шаг и область видимости

В обычном `for` можно инициализировать счётчик обратного отсчёта или двигать сразу две границы. В примере с `left = 0` и `right = 100` на каждом шаге левая граница растёт, а правая уменьшается. При встрече на 50 тело уже пропускается, поэтому последнее напечатанное значение `left` равно 49.

При переписывании в `while` инициализацию ставят перед циклом, а шаг — в конец тела. Внешние скобки сохраняют область видимости счётчика. Если в теле есть `continue`, простого переноса недостаточно: в `for` после `continue` шаг выполняется, а в `while` управление сразу идёт к проверке условия.

:::example
В цикле `for (int i = 0; i < 3; ++i)` с пропуском печати при `i == 1` выводится `0 2`. Когда управление доходит до `continue`, сначала выполняется `++i`, поэтому следующая проверка получает двойку. Если в версии с `while` пропустить инкремент вместе с концом тела, счётчик навсегда останется равен единице.
:::

Запись `i --> 0` разбирается как `(i--) > 0`. При начальном `i = 10` первое сравнение использует десятку, а тело получает уже девятку. Последняя успешная проверка использует единицу, и тело печатает ноль. В диапазонном `for (int value : values)` явный счётчик не нужен. Переменная `value` получает копии элементов массива по очереди.

### `break` и `continue`

- `break` выходит из ближайшего цикла или `switch`. В обратном отсчёте с выходом при тройке она и последующие числа уже не печатаются.
- `continue` пропускает остаток текущей итерации ближайшего цикла. Если при обратном отсчёте пропустить пятёрку, отсчёт продолжится с четвёрки.

```quiz

- [ ] В `do-while`, когда первая проверка ложна.

```

## 4. Выбор ветви с `switch`

`switch` удобен, когда одно целочисленное значение или перечисление нужно сопоставить с несколькими известными заранее значениями. Каждая метка `case` задаётся константным выражением, метки различны. Если совпадений нет, выполнение начинается с `default`, если такая метка есть.

:::warning
Метка только обозначает точку входа. После неё инструкции идут подряд до `break` или конца `switch`. Поэтому пропущенный `break` может привести к выполнению кода следующей ветви. Это же свойство позволяет поставить подряд `case 1:`, `case 2:` и `case 3:` перед общей обработкой.
:::

```quiz
title: Проверка: switch

? Что происходит, когда `switch` доходит до следующей метки без `break`?
- [ ] Выполнение заканчивается у метки.
- [ ] Значение проверяется снова.
- [x] Выполняются следующие инструкции.
explain: Сопоставление выбирает начальную позицию. Дойдя до следующей метки, программа продолжает идти по инструкциям.

? Сколько тел обработки выполнится для значения `2`, если метки `1`, `2` и `3` ведут к одному телу с `break`? Введите целое число.
= 1
explain: Управление входит через `case 2`, доходит до общего тела и выходит из `switch`.
```

## 5. Функции, вызов и точка входа

При вызове функции аргументы задают значения её параметров. В примере сложения аргументы 5 и 3 становятся значениями двух параметров, а `return` завершает вызов и передаёт сумму 8 вызывающему коду. Возвращаемое выражение должно быть неявно преобразуемо к заявленному типу результата.

Объявление даёт компилятору имя функции, тип результата и типы параметров. Определение содержит тело. Например, объявление `int maximum(int left, int right);` можно поставить до `main`, вызвать `maximum(10, 2)` внутри `main` и определить функцию ниже. Тело выбирает большее из двух значений, поэтому результат — 10. У функции `void` результат отсутствует: функция печати выполняет вывод как побочный эффект.

В обычной программе на C++ стандартные формы точки входа — `int main()` и `int main(int argc, char* argv[])`. Дойти до конца `main` равносильно `return 0;`. Именованные коды `EXIT_SUCCESS` и `EXIT_FAILURE` доступны из `<cstdlib>`.

:::note
`argc` считает строки аргументов. При положительном `argc` элемент `argv[0]` содержит имя запуска программы или пустую строку. Чтобы напечатать аргументы, цикл проходит индексы от нуля до `argc - 1`. Элемент `argv[argc]` — нулевой указатель.
:::

```quiz
title: Проверка: функции и main

? Что содержит определение функции в отличие от объявления без определения?
- [ ] Только имя и тип результата.
- [x] Тело функции.
- [ ] Только список имён аргументов вызова.
explain: Объявления достаточно, чтобы проверить вызов. Определение задаёт вычисления, которые этот вызов выполнит.

? Какие утверждения о `main` верны?
- [x] Достижение конца `main` означает успешное завершение как при `return 0;`.
- [ ] `argc` всегда исключает строку запуска.
- [ ] `argv[argc]` содержит последний обычный аргумент.
- [x] `argv[argc]` равен `nullptr`.
explain: Последний строковый аргумент при положительном `argc` имеет индекс `argc - 1`. Следующий указатель служит признаком конца.
```

## 6. Рекурсия и итерация

:::example
Для факториала рекурсивный вызов уменьшает аргумент, пока не дойдёт до базового случая $0! = 1$. Для аргумента пять сначала откладываются умножения на 5, 4, 3, 2 и 1, а после достижения нуля результаты возвращаются в обратном порядке. Итог — $5! = 120$.

```cpp
unsigned long long FactorialRecursive(unsigned n) {
    return n == 0 ? 1ULL : n * FactorialRecursive(n - 1);
}

unsigned long long FactorialIterative(unsigned n) {
    unsigned long long product = 1;
    for (unsigned factor = n; factor > 1; --factor) {
        product *= factor;
    }
    return product;
}
```

Итеративная версия хранит накапливаемое произведение и не создаёт цепочки вызовов. Оба варианта ограничены диапазоном результата: для беззнакового типа с $N$ битами значения произведение считается по модулю $2^N$.
:::

```quiz
title: Проверка: рекурсия

? Что возвращает базовый случай факториала? Введите целое число.
= 1
explain: По определению нулевой факториал равен единице. В этом случае нового вызова нет.

? Что произойдёт, если произведение перестанет помещаться в `unsigned long long`?
- [ ] Цикл автоматически завершится перед умножением.
- [ ] Тип сам расширится, чтобы сохранить точное значение.
- [x] Арифметика даст остаток по модулю степени двойки.
explain: Это свойство беззнаковой арифметики, поэтому полученное число может отличаться от математического факториала.
```

## 7. Сокрытие имён

Если во вложенной области объявить имя, которое уже есть во внешней, обычный поиск имени будет находить ближайшее объявление. Когда блок заканчивается, доступ к внешнему имени по тому же написанию возвращается.

:::example
В примере курса глобальным `x` и `y` присваивают 21 и 239. Во внутреннем блоке объявляют своё `x = 10`, поэтому в блоке видны 10 и 239. Затем функция печати принимает внешний `y` в параметр с именем `x` и создаёт локальное `y = 3.14`. Внутри функции видны уже 239 и 3.14. После выхода из блока глобальная пара остаётся 21 и 239.
:::

```quiz

- [ ] 21
- [ ] Объявления конфликтуют и программа не компилируется.
explain: Вложенное объявление скрывает внешнее имя в пределах блока.

? Чему равно глобальное `x` после выхода из этого блока, если внутри менялась только локальная переменная? Введите целое число.
= 21
explain: За одинаковыми именами стояли две разные переменные. Локальная переменная исчезает при выходе из блока, а глобальная сохраняет значение.
```
