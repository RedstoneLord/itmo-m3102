# Динамика на отрезках и редакционное расстояние

В данном конспекте рассматриваются два фундаментальных класса задач динамического программирования, традиционно входящих в программу коллоквиума: **динамика на отрезках** (Interval DP) и вычисление **редакционного расстояния** (Edit Distance, алгоритм Вагнера–Фишера).

---

## 1. Динамика на отрезках (Interval DP)

### 1.1. Общая концепция и топологический порядок

:::meaning
**Динамика на отрезках** (англ. *Interval DP*) — метод решения оптимизационных задач, в которых подзадачи естественным образом определяются непрерывными подотрезками входных данных $[l, r]$ ($0 \le l \le r < n$).
:::

Ключевые элементы метода:
1. **Параметризация состояния:** ячейка таблицы $dp[l][r]$ хранит оптимальный ответ для подстроки, подмассива или последовательности элементов от индекса $l$ до индекса $r$ включительно.
2. **Топологический порядок вычислений:** ответ для отрезка длины $len = r - l + 1$ строится на основе ответов для отрезков строго меньшей длины. Поэтому внешний цикл обязан идти **по возрастанию длины отрезка** $len = 1, 2, \dots, n$, а внутренний перебирает левую границу $l$ (при этом правая граница вычисляется как $r = l + len - 1$).
3. **База динамики:** отрезки единичной длины ($len = 1$, то есть $l = r$). Значения $dp[i][i]$ определяются условием конкретной задачи.
4. **Переход:** ответ для отрезка $[l, r]$ находится выбором оптимальной «точки последнего объединения» (разбиения) $k$ между $l$ и $r-1$:
   $$
   dp[l][r] = \min_{l \le k < r} \bigl(dp[l][k] + dp[k + 1][r] + \text{cost}(l, k, r)\bigr).
   $$
5. **Ответ на задачу:** содержится в ячейке $dp[0][n - 1]$ (весь отрезок целиком).
6. **Восстановление оптимального пути:** сохраняется позиция наилучшего разбиения в массиве $split[l][r] = k_{\text{opt}}$, после чего порядок действий рекурсивно раскручивается для половин $[l, k]$ и $[k+1, r]$.

:::note
**Ленивая динамика как альтернатива:** динамику на отрезках можно реализовать и без явного цикла по длине — с помощью рекурсии с мемоизацией (Top-Down). Стек вызовов автоматически разрешит порядок зависимостей подзадач.
:::

### 1.2. Оптимальное перемножение цепочки матриц (Matrix Chain Multiplication)

:::meaning
**Задача.** Дана последовательность из $n$ матриц $A_1, A_2, \dots, A_n$, где матрица $A_i$ имеет размерность $p_{i-1} \times p_i$. Поскольку умножение матриц ассоциативно ($(A B) C = A (B C)$), произведение всех матриц можно вычислить при любой расстановке скобок. Требуется найти такую расстановку скобок, при которой общее число элементарных скалярных умножений **минимально**.
:::

Напомним, что умножение прямоугольной матрицы размера $a \times b$ на матрицу размера $b \times c$ требует ровно $a \cdot b \cdot c$ скалярных умножений.

:::formula
**Рекуррентное соотношение:**
Пусть $dp[l][r]$ — минимальное число скалярных умножений для вычисления произведения $A_{l+1} \dots A_{r+1}$ (в 0-индексации отрезка $[l, r]$):
- **База:**
  $$
  dp[i][i] = 0 \quad (\text{одна матрица умножений не требует}).
  $$
- **Переход ($l < r$):**
  $$
  dp[l][r] = \min_{l \le k < r} \bigl(dp[l][k] + dp[k + 1][r] + p_l \cdot p_{k + 1} \cdot p_{r + 1}\bigr).
  $$
:::

Величина $p_l \cdot p_{k+1} \cdot p_{r+1}$ представляет собой стоимость финального перемножения результирующей матрицы левого блока (размера $p_l \times p_{k+1}$) и результирующей матрицы правого блока (размера $p_{k+1} \times p_{r+1}$).

:::example
**Пошаговый разбор примера коллоквиума:**
Даны 3 матрицы: $A_1(10 \times 30)$, $A_2(30 \times 5)$, $A_3(5 \times 60)$.
Вектор размерностей: $p = [10, 30, 5, 60]$, число матриц $n = 3$.

| Длина $len$ | Отрезок $[l, r]$ | Варианты разбиения $k$ | Формула и расчёт | Результат $dp[l][r]$ |
|:---:|:---:|:---|:---|:---:|
| $1$ | $[0, 0]$ ($A_1$) | База: одна матрица | $0$ | $0$ |
| $1$ | $[1, 1]$ ($A_2$) | База: одна матрица | $0$ | $0$ |
| $1$ | $[2, 2]$ ($A_3$) | База: одна матрица | $0$ | $0$ |
| $2$ | $[0, 1]$ ($A_1 A_2$) | $k = 0$ единственен | $0 + 0 + 10 \cdot 30 \cdot 5 = 1500$ | $1500$ ($k=0$) |
| $2$ | $[1, 2]$ ($A_2 A_3$) | $k = 1$ единственен | $0 + 0 + 30 \cdot 5 \cdot 60 = 9000$ | $9000$ ($k=1$) |
| $3$ | $[0, 2]$ ($A_1 A_2 A_3$) | $k = 0$: $(A_1)(A_2 A_3)$ | $0 + 9000 + 10 \cdot 30 \cdot 60 = 27000$ | — |
| $3$ | $[0, 2]$ ($A_1 A_2 A_3$) | $k = 1$: $(A_1 A_2)(A_3)$ | $1500 + 0 + 10 \cdot 5 \cdot 60 = 4500$ | **$4500$** ($k=1$) |

Сравнение вариантов разбиения:
- Порядок $A_1 (A_2 A_3)$ требует $27\,000$ скалярных операций.
- Оптимальный порядок $(A_1 A_2) A_3$ требует всего **$4\,500$** скалярных операций (в 6 раз быстрее!).
:::

Оптимальная структура скобок визуализируется в виде бинарного дерева синтаксического разбора:

```tree
title: Оптимальная расстановка скобок ((A1 A2) A3) с затратами 4500 операций
(A1 A2 A3) [cost=4500]
  (A1 A2) [cost=1500]
    A1 (10x30)
    A2 (30x5)
  A3 (5x60)
```

#### Реализация на C++ с восстановлением скобок

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <climits>

using namespace std;

// Рекурсивное восстановление скобок по массиву split
string printParentheses(int l, int r, const vector<vector<int>>& split) {
    if (l == r) {
        return "A" + to_string(l + 1);
    }
    int k = split[l][r];
    return "(" + printParentheses(l, k, split) + " * " + printParentheses(k + 1, r, split) + ")";
}

void matrixChainOrder(const vector<int>& p) {
    int n = (int)p.size() - 1; // количество матриц
    vector<vector<long long>> dp(n, vector<long long>(n, 0));
    vector<vector<int>> split(n, vector<int>(n, -1));

    // Внешний цикл по длине отрезка len от 2 до n
    for (int len = 2; len <= n; len++) {
        for (int l = 0; l <= n - len; l++) {
            int r = l + len - 1;
            dp[l][r] = LLONG_MAX;

            for (int k = l; k < r; k++) {
                long long cost = dp[l][k] + dp[k + 1][r] + (long long)p[l] * p[k + 1] * p[r + 1];
                if (cost < dp[l][r]) {
                    dp[l][r] = cost;
                    split[l][r] = k;
                }
            }
        }
    }

    cout << "Минимальное число операций: " << dp[0][n - 1] << endl;
    cout << "Оптимальная расстановка: " << printParentheses(0, n - 1, split) << endl;
}
```

### 1.3. Теоретический анализ и доказательства

:::remember
#### 1. Доказательство оптимальной подструктуры
**Теорема:** Задача об оптимальной расстановке скобок обладает свойством оптимальной подструктуры.

**Доказательство (методом от противного):**
Рассмотрим оптимальное разбиение отрезка $[l, r]$ в некоторой точке $k$: $(A_l \dots A_k)(A_{k+1} \dots A_r)$.
Общая стоимость вычисляется как:
$$
C_{\text{total}} = C_{\text{left}} + C_{\text{right}} + p_l p_{k+1} p_{r+1},
$$
где $C_{\text{left}}$ — стоимость перемножения матриц в блоке $[l, k]$, а $C_{\text{right}}$ — в блоке $[k+1, r]$.

Предположим, что расстановка скобок внутри левого блока $[l, k]$ не оптимальна, и существует иная схема скобок с меньшей стоимостью $C'_{\text{left}} < C_{\text{left}}$.
Заменив расстановку скобок в левом блоке на более эффективную, получим суммарную стоимость:
$$
C'_{\text{total}} = C'_{\text{left}} + C_{\text{right}} + p_l p_{k+1} p_{r+1} < C_{\text{total}},
$$
что противоречит предположению об исходной оптимальности решения для отрезка $[l, r]$. Аналогичное рассуждение справедливо и для правого блока $[k+1, r]$. Значит, подзадачи обязаны быть решены оптимально.
:::

:::remember
#### 2. Доказательство готовности подзадач при обходе по длине
**Утверждение:** Цикл по возрастанию длины отрезка $len = 1, \dots, n$ гарантирует, что к моменту расчёта $dp[l][r]$ все необходимые для него подзадачи уже вычислены.

**Доказательство:**
Для вычисления $dp[l][r]$ требуются значения $dp[l][k]$ и $dp[k+1][r]$ при $l \le k < r$.
Оценим длины этих подотрезков:
- Длина левой части $[l, k]$: $len_{\text{left}} = k - l + 1 \le (r - 1) - l + 1 = r - l < len$.
- Длина правой части $[k+1, r]$: $len_{\text{right}} = r - (k + 1) + 1 = r - k \le r - l < len$.

Обе подзадачи имеют длину, строго меньшую $len$. Следовательно, они были вычислены на предыдущих итерациях внешнего цикла и корректно записаны в таблицу.
:::

:::formula
#### 3. Строгий расчёт числа операций ($\Theta(n^3)$)
Число троек индексов $(l, k, r)$, удовлетворяющих условию $0 \le l \le k < r < n$, взаимно однозначно соответствует выбору $3$ различных индексов из множества границ $\{0, 1, \dots, n\}$.
Следовательно, точное количество итераций внутреннего цикла выражается биномиальным коэффициентом:
$$
\binom{n + 1}{3} = \frac{(n + 1) n (n - 1)}{6} = \frac{n^3 - n}{6} \in \Theta(n^3).
$$
На каждую тройку индексов тратится $O(1)$ элементарных арифметических операций. Таким образом:
- **Время работы:** $\Theta(n^3)$.
- **Память:** $\Theta(n^2)$ для хранения таблицы $dp$ размера $n \times n$.
:::

### 1.4. Другие классические задачи на отрезках

1. **Оптимальная триангуляция выпуклого многоугольника:**
   Даны вершины выпуклого $n$-угольника $v_0, v_1, \dots, v_{n-1}$. Требуется провести непересекающиеся диагонали, разбивающие многоугольник на треугольники, с минимальной суммарной стоимостью (периметром треугольников).
   - *Состояние:* $dp[l][r]$ — минимальная стоимость триангуляции многоугольника с вершинами $v_l, v_{l+1}, \dots, v_r$.
   - *Переход:* фиксируем сторону $(v_l, v_r)$ и перебираем третью вершину $v_k$ ($l < k < r$), образующую треугольник $(v_l, v_k, v_r)$:
     $$dp[l][r] = \min_{l < k < r} \bigl(dp[l][k] + dp[k][r] + \text{weight}(v_l, v_k, v_r)\bigr).$$
2. **Наибольшая подпоследовательность-палиндром (LPS):**
   В строке $S$ найти длину самой длинной подпоследовательности, являющейся палиндромом.
   - *Переход:*
     $$
     dp[l][r] =
     \begin{cases}
     dp[l + 1][r - 1] + 2, & \text{если } S[l] = S[r], \\
     \max(dp[l + 1][r],\, dp[l][r - 1]), & \text{если } S[l] \ne S[r].
     \end{cases}
     $$
3. **Оптимизация Кнута (Knuth's Optimization):**
   В задачах вида $dp[l][r] = \min_{l \le k < r} (dp[l][k] + dp[k+1][r]) + \text{cost}(l, r)$, если функция стоимости удовлетворяет *неравенству четырёхугольника* ($\text{cost}(a, c) + \text{cost}(b, d) \le \text{cost}(a, d) + \text{cost}(b, c)$ для $a \le b \le c \le d$), то оптимальная точка разбиения $opt[l][r]$ монотонна:
   $$
   opt[l][r - 1] \le opt[l][r] \le opt[l + 1][r].
   $$
   Это позволяет сузить границы перебора $k$ и ускорить алгоритм с $\Theta(n^3)$ до **$\Theta(n^2)$**!

## 2. Редакционное расстояние (Edit Distance)

### 2.1. Постановка задачи и элементарные операции

:::meaning
**Редакционное расстояние** (расстояние Левенштейна, англ. *Levenshtein distance*) между двумя строками $S$ (длины $n$) и $T$ (длины $m$) — это **минимальная суммарная стоимость** элементарных операций редактирования, необходимых для преобразования строки $S$ в строку $T$.
:::

В классической формулировке Левенштейна разрешены три операции с единичной стоимостью ($c = 1$):
1. **Удаление (Delete):** удаление одного символа из первой строки $S$.
2. **Вставка (Insert):** вставка одного символа в первую строку $S$.
3. **Замена (Substitute):** замена одного символа строки $S$ на другой символ строки $T$. Если символы совпадают, операция бесплатна ($c = 0$).

---

### 2.2. Алгоритм Вагнера–Фишера

:::meaning
**Инвариант алгоритма:**
Для любых $0 \le i \le n$ и $0 \le j \le m$ значение $dp[i][j]$ строго равно минимальному числу операций редактирования, необходимых для преобразования префикса $S[0..i)$ в префикс $T[0..j)$.
:::

#### База динамики
- Превращение префикса $S[0..i)$ в пустую строку требует $i$ удалений:
  $$dp[i][0] = i \quad (0 \le i \le n).$$
- Превращение пустой строки в префикс $T[0..j)$ требует $j$ вставок:
  $$dp[0][j] = j \quad (0 \le j \le m).$$

#### Формула перехода
Для строк $i = 1, \dots, n$ и столбцов $j = 1, \dots, m$:
$$
dp[i][j] =
\begin{cases}
dp[i - 1][j - 1], & \text{если } S[i - 1] = T[j - 1], \\
1 + \min\bigl(dp[i - 1][j],\; dp[i][j - 1],\; dp[i - 1][j - 1]\bigr), & \text{если } S[i - 1] \ne T[j - 1].
\end{cases}
$$

Смысл трёх аргументов минимума:
- $dp[i - 1][j] + 1$: **удаление** символа $S[i - 1]$ (шаг сверху).
- $dp[i][j - 1] + 1$: **вставка** символа $T[j - 1]$ в $S$ (шаг слева).
- $dp[i - 1][j - 1] + 1$: **замена** символа $S[i - 1] \to T[j - 1]$ (шаг по диагонали).


:::example
**Пошаговый разбор примера коллоквиума: «МАРТ» $\to$ «КАРТА»**
Преобразуем $S = \text{«МАРТ»}$ ($n = 4$) в $T = \text{«КАРТА»}$ ($m = 5$).

Таблица $dp$:

| $S \backslash T$ | $\varepsilon$ | К | А | Р | Т | А |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **$\varepsilon$** | $0$ | $1$ | $2$ | $3$ | $4$ | $5$ |
| **М** | $1$ | $1$ | $2$ | $3$ | $4$ | $5$ |
| **А** | $2$ | $2$ | $1$ | $2$ | $3$ | $4$ |
| **Р** | $3$ | $3$ | $2$ | $1$ | $2$ | $3$ |
| **Т** | $4$ | $4$ | $3$ | $2$ | $1$ | **$2$** |

Редакционное расстояние равно **$dp[4][5] = 2$**.
Оптимальная цепочка преобразований (обратный ход из ячейки $(4, 5)$ в $(0, 0)$):
1. В ячейке $(4, 5)$ переход произошёл слева из $(4, 4)$ с добавлением 1 $\to$ **вставка буквы «А»** в конец.
2. От $(4, 4)$ до $(1, 1)$ диагональный проход: буквы «Т», «Р», «А» совпадают бесплатно ($c = 0$).
3. В ячейке $(1, 1)$ переход по диагонали из $(0, 0)$ с добавлением 1 $\to$ **замена «М» на «К»**.

Итоговое выравнивание:
```
S: М А Р Т -
T: К А Р Т А
   R M M M I  (Replace, Match, Match, Match, Insert) -> 2 операции
```
:::

#### Реализация алгоритма Вагнера–Фишера на C++

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

using namespace std;

int editDistance(const string& S, const string& T) {
    int n = (int)S.size();
    int m = (int)T.size();
    vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));

    for (int i = 0; i <= n; i++) dp[i][0] = i;
    for (int j = 0; j <= m; j++) dp[0][j] = j;

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (S[i - 1] == T[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1]; // бесплатное совпадение
            } else {
                dp[i][j] = 1 + min({
                    dp[i - 1][j],     // удаление из S
                    dp[i][j - 1],     // вставка в S
                    dp[i - 1][j - 1]  // замена символа
                });
            }
        }
    }
    return dp[n][m];
}
```

### 2.3. Оптимизация памяти

#### Хранение двух строк за $\Theta(\min(n, m))$
Чтобы вычислить строку $i$, требуется только предыдущая строка $i - 1$. Достаточно хранить два вектора длины $m + 1$ (`prev` и `curr`). Если гарантировать $m \le n$ (при необходимости поменяв строки местами), расход памяти снижается до $\Theta(\min(n, m))$.

```cpp
int editDistanceMemoryOptimized(string S, string T) {
    if (S.size() < T.size()) swap(S, T); // T — более короткая строка
    int n = (int)S.size(), m = (int)T.size();

    vector<int> prev(m + 1), curr(m + 1);
    for (int j = 0; j <= m; j++) prev[j] = j;

    for (int i = 1; i <= n; i++) {
        curr[0] = i;
        for (int j = 1; j <= m; j++) {
            if (S[i - 1] == T[j - 1]) {
                curr[j] = prev[j - 1];
            } else {
                curr[j] = 1 + min({prev[j], curr[j - 1], prev[j - 1]});
            }
        }
        prev = curr;
    }
    return prev[m];
}
```

#### Алгоритм Хиршберга (Hirschberg's Algorithm)
:::meaning
**Проблема двух строк:** оптимизация до двух строк теряет промежуточные шаги и не позволяет восстановить цепочку операций.

**Решение (Алгоритм Хиршберга):** применяет парадигму «разделяй и властвуй». Делит строку $S$ пополам в точке $mid = n / 2$. Запускает прямое ДП на префиксе $S[0..mid)$ и обратное ДП на суффиксе $S[mid..n)$ для всех префиксов строки $T$. Точка $split$, минимизирующая сумму прямого и обратного расстояний, является вершиной оптимального пути! Затем задача рекурсивно сводится к прямоугольникам $(0..mid, 0..split)$ и $(mid..n, split..m)$.
:::

:::formula
**Сложность алгоритма Хиршберга:**
- **Время:** $\sum_{k} \frac{n m}{2^k} = O(n m)$ (время остаётся квадратичным!).
- **Память:** **$O(n + m)$** строго линейная память с полным восстановлением оптимального выравнивания!
:::

### 2.4. Вариации редакционного расстояния

1. **Расстояние Дамерау–Левенштейна (Damerau–Levenshtein):**
   Разрешает четвёртую операцию — **транспозицию** (обмен местами двух соседних символов за стоимость $1$). Моделирует опечатки вида «вместо» $\to$ «вметсо».
   $$
   \text{при } S[i - 1] = T[j - 2] \text{ и } S[i - 2] = T[j - 1]: \quad dp[i][j] = \min\bigl(dp[i][j],\; dp[i - 2][j - 2] + 1\bigr).
   $$
2. **Алгоритм Укконена (полоса $2k + 1$):**
   Если заранее известно или требуется проверить, что $d(S, T) \le k$ (для малых $k \ll \min(n, m)$), оптимальный путь не может отклоняться от главной диагонали более чем на $k$ клеток. Вычисляются только клетки $|i - j| \le k$.
   Время снижается до **$O(k \cdot \min(n, m))$**.
3. **Связь с наибольшей общей подпоследовательностью (LCS):**
   Если запретить операцию замены (или установить её стоимость $c_{\text{sub}} \ge 2$), допустимыми остаются только вставки и удаления.
   :::formula
   $$
   d_{\text{no-sub}}(S, T) = |S| + |T| - 2 \cdot \text{LCS}(S, T).
   $$
   :::

### 2.5. Теоретические свойства и доказательства

:::remember
#### 1. Расстояние Левенштейна — математическая метрика
**Теорема:** Функция $d(S, T)$ на множестве строк удовлетворяет всем четырём аксиомам метрического пространства:
1. **Неотрицательность:** $d(S, T) \ge 0$, так как стоимость каждой элементарной операции $\ge 0$.
2. **Тождество неразличимых:** $d(S, T) = 0 \iff S = T$. Если $S = T$, операций не требуется ($d = 0$). Если $S \ne T$, требуется хотя бы одна операция модификации длины или символа, поэтому $d > 0$.
3. **Симметрия:** $d(S, T) = d(T, S)$. Каждая операция обратима с сохранением стоимости (вставка $c$ в $S$ обращается удалением $c$ из $T$, замена $a \to b$ обращается заменой $b \to a$).
4. **Неравенство треугольника:** $d(A, B) \le d(A, C) + d(C, B)$.

**Доказательство неравенства треугольника:**
Пусть $\sigma_1$ — оптимальная цепочка из $d(A, C)$ операций, переводящая $A$ в $C$, а $\sigma_2$ — оптимальная цепочка из $d(C, B)$ операций, переводящая $C$ в $B$.
Последовательное применение цепочки $\sigma_1$, а затем цепочки $\sigma_2$ переводит строку $A$ в строку $B$ за $|\sigma_1| + |\sigma_2| = d(A, C) + d(C, B)$ элементарных операций.
Поскольку $d(A, B)$ по определению есть стоимость **кратчайшей** (минимальной) последовательности операций, переводящей $A$ в $B$, выполняется:
$$
d(A, B) \le |\sigma_1| + |\sigma_2| = d(A, C) + d(C, B).
$$
Неравенство треугольника доказано.
:::

:::remember
#### 2. Доказательство связи редакционного расстояния без замен с LCS
**Доказательство:**
При запрете замен символы, которые не были удалены из $S$ и не были вставлены в $T$, обязаны следовать в том же относительном порядке в обеих строках, образуя общую подпоследовательность строк $S$ и $T$.
Пусть её длина равна $L$.
- Число удалений из строки $S$: $|S| - L$.
- Число вставок символов строки $T$: $|T| - L$.
- Общее число операций: $(|S| - L) + (|T| - L) = |S| + |T| - 2L$.

Чтобы минимизировать суммарное число операций, длина общей подпоследовательности $L$ обязана быть максимально возможной: $L = \text{LCS}(S, T)$. Отсюда $d_{\text{no-sub}}(S, T) = |S| + |T| - 2 \cdot \text{LCS}(S, T)$.
:::

## 3. Вопросы экзаменатора и ловушки коллоквиума

### Обязательные вопросы теормина

1. **Что является состоянием и базой в алгоритме Вагнера–Фишера?**
   *Ответ:* Состояние $dp[i][j]$ — редакционное расстояние между префиксами $S[0..i)$ и $T[0..j)$. База: $dp[i][0] = i$ (удаление всех $i$ символов) и $dp[0][j] = j$ (вставка $j$ символов).
2. **Почему в перемножении цепочки матриц внешний цикл идёт по длине отрезка, а не по индексам?**
   *Ответ:* Для вычисления ответа на отрезке $[l, r]$ требуются ответы на строго более коротких подотрезках $[l, k]$ и $[k+1, r]$ ($len < r - l + 1$). Обход по возрастанию длины гарантирует их готовность.
3. **Является ли расстояние Левенштейна метрикой?**
   *Ответ:* Да, оно удовлетворяет всем 4 аксиомам метрического пространства: неотрицательность, тождество неразличимых, симметрия и неравенство треугольника.

### Вопросы с подвохом

1. **Можно ли реализовать динамику на отрезках без цикла по длине?**
   *Ответ:* Да, через рекурсию с мемоизацией (Top-Down / ленивая динамика). Стек вызовов автоматически разрешит порядок вычисления зависимостей.
2. **Как восстановить выравнивание строк при $O(n + m)$ памяти?**
   *Ответ:* Алгоритмом Хиршберга: методом «разделяй и властвуй» находим точку пересечения оптимального пути со средней строкой, рекурсивно решая задачу для двух половин.
3. **Как связаны редакционное расстояние и LCS при запрете операции замены?**
   *Ответ:* Формулой $d(S, T) = |S| + |T| - 2 \cdot \text{LCS}(S, T)$, так как все несохранённые символы обязаны быть либо удалены, либо вставлены.
4. **В чём заключается оптимизация Кнута?**
   *Ответ:* Если матрица стоимости удовлетворяет условию четырёхугольника, то оптимальные точки разбиения монотонны: $opt[l][r-1] \le opt[l][r] \le opt[l+1][r]$, что сокращает время с $O(n^3)$ до $O(n^2)$.
