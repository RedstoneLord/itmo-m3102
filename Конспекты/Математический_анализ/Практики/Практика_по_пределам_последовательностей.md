# Как считать пределы последовательностей: практическое руководство

:::note
Это руководство отвечает на вопрос «как с этим работать руками». Определения и теоремы из лекций здесь не доказываются заново, а применяются. Факты, которые используются без доказательства (они будут доказаны позже, при изучении предела функции), отмечены словами «принимаем как известное».
:::

## Инструментарий: что уже есть из теории

Все вычисления ниже опираются на небольшой набор теорем. Полезно держать их перед глазами.

| Теорема | Что она даёт на практике |
|---|---|
| Определение предела ($\varepsilon$–$N$) | Строгое доказательство того, что $a$ — предел |
| Единственность предела | Если нашли предел, он один |
| Ограниченность сходящейся последовательности | Сходится $\Rightarrow$ ограничена. Неограниченная последовательность сходиться не может |
| Сохранение знака | Если $x_n \to a > 0$, то $x_n > a/2$ при больших $n$ |
| Свойства бесконечно малых (б.м.) | Сумма б.м. — б.м.; ограниченная $\times$ б.м. — б.м. |
| Критерий существования предела | $x_n \to a \iff x_n = a + \alpha_n$, где $\alpha_n$ — б.м. |
| Арифметика пределов | Предел суммы, произведения, частного |
| Теорема о двух милиционерах | «Зажать» последовательность между двумя с одним пределом |
| Теорема Вейерштрасса | Монотонная и ограниченная $\Rightarrow$ сходится |
| Число $e$ | $\left(1+\frac1n\right)^n \to e$ |
| Теорема Больцано — Вейерштрасса | У ограниченной последовательности есть сходящаяся подпоследовательность |
| Критерий Коши | Сходится $\iff$ фундаментальна |

:::remember
Главный принцип вычислений: **сначала понять, что происходит с каждой частью выражения при $n\to\infty$, а затем применить арифметику пределов**. Если арифметика не даёт ответа (получилась неопределённость), выражение нужно преобразовать так, чтобы она исчезла.
:::

## Предел по определению: как искать $N(\varepsilon)$

### Что требуется

:::meaning
$\displaystyle\lim_{n\to\infty}x_n=a$ означает: для любого $\varepsilon>0$ существует номер $N(\varepsilon)$ такой, что для всех $n>N(\varepsilon)$ выполнено $|x_n-a|<\varepsilon$.

Задача «доказать по определению» — это **предъявить правило**, которое по любому $\varepsilon$ выдаёт подходящий $N$.
:::

### Схема решения

:::example
**Алгоритм доказательства по определению.**
1. Выписать модуль разности $|x_n-a|$ и упростить его (привести к общему знаменателю, сократить).
2. Решить (или «огрубить» и решить) неравенство $|x_n-a|<\varepsilon$ относительно $n$.
3. Записать $N(\varepsilon)$ — например, через целую часть $\lfloor\cdot\rfloor$.
4. Сказать: при $n>N(\varepsilon)$ выполнено $|x_n-a|<\varepsilon$, что и требовалось.
:::

:::note
Номер $N(\varepsilon)$ не обязан быть **наименьшим** возможным. Подойдёт любой $N$, начиная с которого неравенство верно: если $N$ подходит, то подходит и любое большее число. Поэтому неравенство можно **огрублять** (заменять левую часть на бо́льшую величину), если решить его так проще.
:::

### Пример 1: точное решение неравенства

:::example
Докажем, что $\displaystyle\lim_{n\to\infty}\frac{2n+1}{n+3}=2$.

1. Упрощаем разность:
$$
\left|\frac{2n+1}{n+3}-2\right|=\left|\frac{2n+1-2n-6}{n+3}\right|=\frac{5}{n+3}.
$$
2. Огрубляем: $\dfrac{5}{n+3}<\dfrac5n$. Достаточно потребовать $\dfrac5n<\varepsilon$, то есть $n>\dfrac5\varepsilon$.
3. Берём $N(\varepsilon)=\left\lfloor\dfrac5\varepsilon\right\rfloor$. При $n>N(\varepsilon)$ имеем $n>\dfrac5\varepsilon$, откуда $\left|\dfrac{2n+1}{n+3}-2\right|<\dfrac5n<\varepsilon$.
:::

Для $\varepsilon=0{,}5$ формула даёт $N=10$, хотя на самом деле неравенство $\frac{5}{n+3}<0{,}5$ верно уже при $n>7$. Это нормально: огрубление даёт «запас». На графике видно, что начиная с $n=8$ все члены лежат в полосе шириной $\varepsilon$ вокруг предела.

### Пример 2: огрубление

:::example
Докажем, что $\displaystyle\lim_{n\to\infty}\frac{3n^2+1}{n^2-1}=3$.

1. Разность:
$$
\left|\frac{3n^2+1}{n^2-1}-3\right|=\left|\frac{3n^2+1-3n^2+3}{n^2-1}\right|=\frac{4}{n^2-1}\qquad(n\ge2).
$$
2. Оценим знаменатель снизу: при $n\ge2$ верно $n^2-1\ge\dfrac{n^2}{2}$ (это равносильно $n^2\ge2$). Поэтому
$$
\frac{4}{n^2-1}\le\frac{8}{n^2}\le\frac8n .
$$
3. Требуем $\dfrac8n<\varepsilon$, то есть $n>\dfrac8\varepsilon$. Берём $N(\varepsilon)=\max\left(2,\left\lfloor\dfrac8\varepsilon\right\rfloor\right)$.

Условие $n\ge 2$ нужно, чтобы знаменатель был положителен и оценка сработала, поэтому в $N$ входит максимум.
:::

:::warning
**Частые ошибки.**
- Проверить несколько значений $n$ и $\varepsilon$ и сказать «сходится». Это не доказательство: нужен $N(\varepsilon)$ для **любого** $\varepsilon$.
- Огрублять «в другую сторону»: заменять $|x_n-a|$ на **меньшую** величину. Оценка должна быть сверху, иначе из $\text{меньшее}<\varepsilon$ ничего не следует.
- Забывать про дополнительные условия вроде $n\ge2$ и не включать их в $N$ через максимум.
:::

### Отрицание: когда $a$ — не предел

:::meaning
Число $a$ **не** является пределом $\{x_n\}$, если
$$
\exists\,\varepsilon_0>0\ \ \forall N\ \ \exists n>N:\ \ |x_n-a|\ge\varepsilon_0 .
$$
То есть вне $\varepsilon_0$-окрестности точки $a$ остаются члены сколь угодно далеко.
:::

## Базовые пределы: «алфавит»

Сложные пределы собираются из простых. Следующие результаты нужно знать наизусть.

:::remember
| Последовательность | Предел |
|---|---|
| $c$ (постоянная) | $c$ |
| $\dfrac1{n^\alpha}$, $\alpha>0$ | $0$ |
| $q^n$, $\lvert q\rvert<1$ | $0$ |
| $q^n$, $q>1$ | $+\infty$ |
| $q^n$, $q\le-1$ | расходится |
| $\sqrt[n]{a}$, $a>0$ | $1$ |
| $\sqrt[n]{n}$ | $1$ |
| $\left(1+\dfrac1n\right)^n$ | $e$ |
| $\dfrac{n^k}{a^n}$, $a>1$ | $0$ |
| $\dfrac{a^n}{n!}$ | $0$ |
| $\dfrac{n!}{n^n}$ | $0$ |
:::

Разберём, откуда берутся самые важные из них.

### Степень $n^{-\alpha}$

Неравенство $\dfrac1{n^\alpha}<\varepsilon$ равносильно $n>\varepsilon^{-1/\alpha}$. Значит, $N(\varepsilon)=\left\lfloor\varepsilon^{-1/\alpha}\right\rfloor$ подходит, и предел равен нулю.

### Геометрическая прогрессия $q^n$

:::example
**Случай $0<|q|<1$.** Запишем $|q|=\dfrac1{1+h}$, где $h>0$. По формуле бинома Ньютона все слагаемые в $(1+h)^n$ неотрицательны, поэтому $(1+h)^n\ge1+nh>nh$. Тогда
$$
0\le|q^n|=\frac1{(1+h)^n}<\frac1{nh}\longrightarrow0 .
$$
По теореме о двух милиционерах $|q^n|\to0$, а значит, и $q^n\to0$.

**Случай $q>1$.** Здесь $q=1+h$ с $h>0$ и $q^n\ge1+nh\to+\infty$.

**Случай $q\le-1$.** Модуль $|q^n|\ge1$ не стремится к нулю: при $q=-1$ последовательность принимает значения $-1,1,-1,1,\dots$, а при $q<-1$ она неограничена. Предела нет.
:::

### Корни $\sqrt[n]{a}$ и $\sqrt[n]{n}$

:::example
**$\sqrt[n]{a}\to1$ при $a>1$.** Запишем $\sqrt[n]{a}=1+h_n$, $h_n>0$. Тогда $a=(1+h_n)^n\ge1+nh_n$, откуда
$$
0<h_n\le\frac{a-1}{n}\to0 .
$$
Значит, $h_n\to0$ и $\sqrt[n]{a}\to1$. Для $0<a<1$ применяем это к $\dfrac1a>1$: $\sqrt[n]{a}=\dfrac1{\sqrt[n]{1/a}}\to1$.

**$\sqrt[n]{n}\to1$.** Запишем $\sqrt[n]{n}=1+h_n$, $h_n>0$. Из бинома при $n\ge2$:
$$
n=(1+h_n)^n\ge\frac{n(n-1)}{2}h_n^2\quad\Longrightarrow\quad h_n^2\le\frac{2}{n-1}\quad\Longrightarrow\quad 0<h_n\le\sqrt{\frac{2}{n-1}}\to0 .
$$
Значит, $\sqrt[n]{n}\to1$.
:::

### «Шкала роста»: $n^k$, $a^n$, $n!$, $n^n$

Эти пределы удобно получать одной леммой.

:::remember
**Лемма об отношении.** Пусть $x_n>0$ и $\dfrac{x_{n+1}}{x_n}\to q$. Если $q<1$, то $x_n\to0$. Если $q>1$, то $x_n\to+\infty$.
:::

:::example
**Доказательство для $q<1$.** Выберем число $r$ с $q<r<1$ (например, $r=\frac{1+q}2$). Начиная с некоторого $N$ выполнено $\dfrac{x_{n+1}}{x_n}<r$. Тогда при $n>N$
$$
0<x_n<x_N\,r^{\,n-N}=\left(x_Nr^{-N}\right)r^n\to0,
$$
так как $r^n\to0$. По теореме о двух милиционерах $x_n\to0$.
:::

:::example
**Применения леммы.**
- $x_n=\dfrac{n^k}{a^n}$, $a>1$: $\dfrac{x_{n+1}}{x_n}=\left(1+\dfrac1n\right)^k\cdot\dfrac1a\to\dfrac1a<1$. Значит, $x_n\to0$.
- $x_n=\dfrac{a^n}{n!}$: $\dfrac{x_{n+1}}{x_n}=\dfrac{a}{n+1}\to0<1$. Значит, $x_n\to0$.
- $x_n=\dfrac{n!}{n^n}$: $\dfrac{x_{n+1}}{x_n}=\dfrac{n^n}{(n+1)^n}=\dfrac1{\left(1+\frac1n\right)^n}\to\dfrac1e<1$. Значит, $x_n\to0$.
:::

:::note
Итог можно запомнить как «лесенку»: при $n\to\infty$ быстрее всех растёт $n^n$, затем $n!$, затем показательные $a^n$, затем степени $n^k$, и медленнее всех логарифм $\ln n$. Подробно это обсуждается в разделе про символы Ландау.
:::

## Арифметика пределов и предельный переход в неравенствах

### Как применять арифметику

Напомним теорему: если $a_n\to a$ и $b_n\to b$, то
$$
a_n\pm b_n\to a\pm b,\qquad a_nb_n\to ab,\qquad \frac{a_n}{b_n}\to\frac ab\ \ (b\ne0).
$$

:::example
Найдём $\displaystyle\lim_{n\to\infty}\frac{\left(2+\frac1n\right)\left(3-\frac1{n^2}\right)}{1+\frac5n}$.

1. Числитель: $2+\frac1n\to2$, $3-\frac1{n^2}\to3$, произведение стремится к $6$.
2. Знаменатель: $1+\frac5n\to1\ne0$.
3. По теореме о частном предел равен $\dfrac61=6$.
:::

:::warning
**Условие «оба предела существуют» обязательно.** Нельзя «разбивать» выражение на части, если хотя бы одна часть не имеет предела. Пример: $x_n=(-1)^n$ и $y_n=-(-1)^n$. Каждая из них расходится, но $x_n+y_n=0\to0$. Поэтому из сходимости суммы не следует сходимость слагаемых.

Правило работы: сначала убедитесь, что каждая часть сходится, и только потом применяйте теорему. Если части расходятся, преобразуйте выражение целиком.
:::

### Функции от последовательности

:::remember
Если $x_n\to a$, то:
- $|x_n|\to|a|$ (так как $\bigl||x_n|-|a|\bigr|\le|x_n-a|$);
- $x_n^k\to a^k$ для натурального $k$ (по теореме о произведении);
- $\sqrt{x_n}\to\sqrt a$ при $x_n\ge0$ и $a\ge0$; аналогично для корней любой степени.
:::

:::example
**Почему $\sqrt{x_n}\to\sqrt a$.** При $a>0$:
$$
\bigl|\sqrt{x_n}-\sqrt a\bigr|=\frac{|x_n-a|}{\sqrt{x_n}+\sqrt a}\le\frac{|x_n-a|}{\sqrt a}\to0 .
$$
При $a=0$ требуется $\sqrt{x_n}<\varepsilon$, то есть $x_n<\varepsilon^2$, а это выполнено при больших $n$, так как $x_n\to0$.
:::

### Предельный переход в неравенстве

:::remember
**Теорема.** Если $x_n\le y_n$ для всех $n$ (или начиная с некоторого номера), $x_n\to a$ и $y_n\to b$, то $a\le b$.
:::

:::example
**Доказательство.** Пусть $a>b$. Последовательность $x_n-y_n\to a-b>0$. По теореме о сохранении знака при больших $n$ имеем $x_n-y_n>0$, что противоречит $x_n\le y_n$.
:::

:::warning
**Строгое неравенство при переходе к пределу превращается в нестрогое.** Из $x_n>0$ не следует $\lim x_n>0$: например, $\frac1n>0$ при всех $n$, но $\frac1n\to0$. Поэтому из $x_n>0$ можно вывести только $\lim x_n\ge0$.
:::

### Подпоследовательности и сдвиг

:::remember
Если $x_n\to a$, то любая подпоследовательность $x_{n_k}\to a$. В частности, $x_{n+1}\to a$ (сдвиг номера не меняет предела).
:::

:::example
**Доказательство.** Пусть $\varepsilon>0$ и $N$ такое, что $|x_n-a|<\varepsilon$ при $n>N$. Так как $n_1<n_2<\dots$ — натуральные числа, то $n_k\ge k$. Значит, при $k>N$ имеем $n_k>N$ и $|x_{n_k}-a|<\varepsilon$.
:::

```quiz
correct: Под корнем $\frac{4n+1}{n}=4+\frac1n\to4$, поэтому предел равен $\sqrt4=2$.
wrong: Под корнем $4+\frac1n\to4$, а корень от последовательности, стремящейся к $4$, стремится к $\sqrt4=2$.
```

## Бесконечно большие последовательности

### Определение

:::meaning
Последовательность $\{x_n\}$ называется **бесконечно большой** ($x_n\to\infty$), если
$$
\forall E>0\ \ \exists N(E):\ \ \forall n>N(E)\quad |x_n|>E .
$$
Если при этом $x_n>E$, пишут $x_n\to+\infty$; если $x_n<-E$ — пишут $x_n\to-\infty$.
:::

:::warning
**Бесконечно большая $\neq$ неограниченная.** Бесконечно большая последовательность неограничена, но обратное неверно. Например, $x_n=n\bigl(1+(-1)^n\bigr)$ принимает значения $0,4,0,8,0,12,\dots$: она неограничена, но на нечётных номерах равна нулю, поэтому условие $|x_n|>E$ при всех больших $n$ не выполнено.
:::

:::note
Выражения $\lim x_n=\infty$ и «последовательность расходится» не противоречат друг другу: по определению предела из лекций предел — конечное число, поэтому бесконечно большая последовательность **расходится**, а запись $\lim x_n=\infty$ лишь уточняет характер расходимости.
:::

### Связь с бесконечно малыми

:::remember
Если $x_n\ne0$, то
$$
x_n\to\infty\iff\frac1{x_n}\to0 .
$$
:::

:::example
**Доказательство.** Условие $|x_n|>E$ равносильно $\left|\dfrac1{x_n}\right|<\dfrac1E$. Положив $\varepsilon=\dfrac1E$, получаем, что «для любого $E$ найдётся $N$» и «для любого $\varepsilon$ найдётся $N$» — одно и то же утверждение.
:::

### Арифметика с бесконечностями

| Что дано | Что получаем |
|---|---|
| $x_n\to+\infty$, $y_n$ ограничена снизу (в частности, сходится) | $x_n+y_n\to+\infty$ |
| $x_n\to+\infty$, $y_n\to+\infty$ | $x_n+y_n\to+\infty$, $x_ny_n\to+\infty$ |
| $x_n\to\infty$, $y_n\to b\ne0$ | $x_ny_n\to\infty$ (знак определяется знаками) |
| $x_n\to\infty$, $c$ — число | $\dfrac{c}{x_n}\to0$ |
| $x_n\to a\ne0$, $y_n\to0$, $y_n\ne0$ | $\dfrac{x_n}{y_n}\to\infty$ |

:::example
**Почему $x_n\to+\infty$ и $y_n\ge-C$ дают $x_n+y_n\to+\infty$.** Для любого $E$ найдём $N$ такое, что $x_n>E+C$ при $n>N$. Тогда $x_n+y_n>E+C-C=E$.
:::

:::example
**Пример.** Найдём $\displaystyle\lim_{n\to\infty}\left(n^2-n\right)$. Прямая подстановка даёт $\infty-\infty$ (неопределённость), поэтому выносим старшую степень:
$$
n^2-n=n^2\left(1-\frac1n\right).
$$
Первый множитель стремится к $+\infty$, второй — к $1$, поэтому произведение стремится к $+\infty$.
:::

:::warning
**Деление на ноль.** Утверждение $\frac{x_n}{y_n}\to\infty$ при $y_n\to0$ верно, только если числитель отделён от нуля ($x_n\to a\ne0$). Если $y_n$ меняет знак, то знак бесконечности определить нельзя. Если и $x_n\to0$, то получается неопределённость $\frac00$.
:::

## Неопределённости и приёмы их раскрытия

### Что такое неопределённость

:::meaning
**Неопределённость** — ситуация, в которой арифметика пределов не определяет результат: при одних и тех же «предельных» данных у разных последовательностей получаются разные пределы. Основные виды:
$$
\frac00,\quad\frac\infty\infty,\quad\infty-\infty,\quad0\cdot\infty,\quad1^\infty,\quad0^0,\quad\infty^0 .
$$
:::

:::example
**Почему $\infty-\infty$ — неопределённость.** Возьмём $x_n=n$, и разные $y_n$:
- $n-n=0\to0$;
- $(n+1)-n=1\to1$;
- $2n-n=n\to+\infty$;
- $n-n^2\to-\infty$.

Все эти пределы получены из «$\infty-\infty$», а результаты различны.
:::

### Рациональные выражения: делим на старшую степень

:::remember
Пусть
$$
x_n=\frac{a_pn^p+a_{p-1}n^{p-1}+\dots+a_0}{b_qn^q+b_{q-1}n^{q-1}+\dots+b_0},\qquad a_p\ne0,\ b_q\ne0 .
$$
Тогда
- если $p<q$, то $x_n\to0$;
- если $p=q$, то $x_n\to\dfrac{a_p}{b_q}$;
- если $p>q$, то $x_n\to\infty$, причём знак равен знаку $\dfrac{a_p}{b_q}$.
:::

**Как это делается.** Числитель и знаменатель делим на $n^q$ (старшую степень знаменателя) или на наибольшую из степеней. После деления каждое слагаемое имеет вид $\text{число}\cdot n^{-k}$ с $k>0$ и стремится к нулю, а остаются только старшие коэффициенты.

:::example
**Пример 1.** $\displaystyle\lim_{n\to\infty}\frac{3n^2-n+1}{2n^2+5}$.

1. Делим числитель и знаменатель на $n^2$:
$$
\frac{3n^2-n+1}{2n^2+5}=\frac{3-\frac1n+\frac1{n^2}}{2+\frac5{n^2}} .
$$
2. Числитель стремится к $3$, знаменатель — к $2\ne0$.
3. Ответ: $\dfrac32$.
:::

:::example
**Пример 2.** $\displaystyle\lim_{n\to\infty}\frac{-2n^3+n}{n^2+4}$.

Делим на $n^2$:
$$
\frac{-2n^3+n}{n^2+4}=\frac{-2n+\frac1n}{1+\frac4{n^2}} .
$$
Числитель стремится к $-\infty$, знаменатель — к $1$, поэтому предел равен $-\infty$.
:::

:::example
**Пример 3 (показательные).** $\displaystyle\lim_{n\to\infty}\frac{2^n+5^n}{2^{n+1}+5^{n-1}}$.

Старший рост у $5^n$, делим на него:
$$
\frac{2^n+5^n}{2\cdot2^n+\frac15\cdot5^n}=\frac{\left(\frac25\right)^n+1}{2\left(\frac25\right)^n+\frac15}\longrightarrow\frac{0+1}{0+\frac15}=5 .
$$
:::

### Корни: домножение на сопряжённое

Для разности двух корней используют формулы
$$
\sqrt A-\sqrt B=\frac{A-B}{\sqrt A+\sqrt B},\qquad
a-b=\frac{a^3-b^3}{a^2+ab+b^2}\ \ (\text{для кубических корней}).
$$
После домножения «опасная» разность превращается в разность подкоренных выражений, а в знаменателе стоит сумма (без вычитания).

:::example
**Пример 1.** $\displaystyle\lim_{n\to\infty}\left(\sqrt{n^2+n}-n\right)$ (тип $\infty-\infty$).

1. Домножаем и делим на сопряжённое:
$$
\sqrt{n^2+n}-n=\frac{(n^2+n)-n^2}{\sqrt{n^2+n}+n}=\frac{n}{\sqrt{n^2+n}+n} .
$$
2. Делим числитель и знаменатель на $n$ (учитывая $n=\sqrt{n^2}$ при $n>0$):
$$
\frac{1}{\sqrt{1+\frac1n}+1}\longrightarrow\frac1{1+1}=\frac12 .
$$
:::

:::example
**Пример 2.** $\displaystyle\lim_{n\to\infty}\left(\sqrt{n^2+3n}-\sqrt{n^2-n}\right)$.

$$
\sqrt{n^2+3n}-\sqrt{n^2-n}=\frac{4n}{\sqrt{n^2+3n}+\sqrt{n^2-n}}=\frac{4}{\sqrt{1+\frac3n}+\sqrt{1-\frac1n}}\longrightarrow\frac{4}{1+1}=2 .
$$
:::

:::example
**Пример 3.** $\displaystyle\lim_{n\to\infty}\left(\sqrt{n+1}-\sqrt n\right)=0$.

$$
\sqrt{n+1}-\sqrt n=\frac{1}{\sqrt{n+1}+\sqrt n}.
$$
Знаменатель стремится к $+\infty$, поэтому дробь стремится к нулю.
:::

:::example
**Пример 4 (кубический корень).** $\displaystyle\lim_{n\to\infty}\left(\sqrt[3]{n+1}-\sqrt[3]{n}\right)=0$.

Положим $a=\sqrt[3]{n+1}$, $b=\sqrt[3]{n}$, тогда $a^3-b^3=1$ и
$$
a-b=\frac{1}{a^2+ab+b^2}\le\frac{1}{3b^2}=\frac{1}{3n^{2/3}}\to0,
$$
а так как $a>b>0$, то $a-b>0$. По теореме о двух милиционерах предел равен нулю.
:::

:::example
**Пример 5 (корень в отношении).** $\displaystyle\lim_{n\to\infty}\frac{\sqrt{4n^2+1}}{n+3}$.

Делим числитель и знаменатель на $n$:
$$
\frac{\sqrt{4+\frac1{n^2}}}{1+\frac3n}\longrightarrow\frac{\sqrt4}{1}=2 .
$$
:::

:::warning
**Типичная ошибка:** писать $\sqrt{n^2+n}\approx n$ и заключать, что $\sqrt{n^2+n}-n\to0$. Разность двух величин, каждая из которых «примерно $n$», может иметь любой предел (в примере выше — $\frac12$). Приближения нельзя вычитать, нужно преобразовывать выражение точно.
:::

### Суммы с растущим числом слагаемых

Когда число слагаемых зависит от $n$, арифметику пределов **нельзя** применять к каждому слагаемому по отдельности.

:::warning
Сумма $\underbrace{\frac1n+\frac1n+\dots+\frac1n}_{n\ \text{слагаемых}}$ равна $1$. Каждое слагаемое стремится к нулю, но слагаемых становится всё больше, и «ноль плюс ноль плюс…» не даёт нуля. Поэтому такие суммы сначала **сворачивают в формулу** или **зажимают** между двумя оценками.
:::

:::remember
Формулы, которые нужны для сворачивания сумм:
$$
1+2+\dots+n=\frac{n(n+1)}2,\qquad 1^2+2^2+\dots+n^2=\frac{n(n+1)(2n+1)}6,
$$
$$
1+q+q^2+\dots+q^{n}=\frac{1-q^{n+1}}{1-q}\ \ (q\ne1),\qquad
\frac1{k(k+1)}=\frac1k-\frac1{k+1}.
$$
:::

:::example
**Пример 1 (арифметическая прогрессия).**
$$
\lim_{n\to\infty}\frac{1+2+\dots+n}{n^2}=\lim_{n\to\infty}\frac{n(n+1)}{2n^2}=\lim_{n\to\infty}\frac12\left(1+\frac1n\right)=\frac12 .
$$
:::

:::example
**Пример 2 (телескопическая сумма).**
$$
\sum_{k=1}^n\frac1{k(k+1)}=\sum_{k=1}^n\left(\frac1k-\frac1{k+1}\right)=1-\frac1{n+1}\longrightarrow1 .
$$
Соседние слагаемые сокращаются, остаются только первое и последнее.
:::

:::example
**Пример 3 (зажатие).** Найдём предел суммы
$$
S_n=\frac{n}{n^2+1}+\frac{n}{n^2+2}+\dots+\frac{n}{n^2+n}.
$$
Каждое из $n$ слагаемых лежит между $\dfrac{n}{n^2+n}$ и $\dfrac{n}{n^2+1}$. Поэтому
$$
\frac{n^2}{n^2+n}\le S_n\le\frac{n^2}{n^2+1}.
$$
Оба края стремятся к $1$ (делим на $n^2$), значит, $S_n\to1$.
:::


## Теорема о двух милиционерах на практике

:::remember
Если $x_n\le y_n\le z_n$ и $x_n\to C$, $z_n\to C$, то $y_n\to C$. Существование предела у $y_n$ **не нужно** предполагать: оно следует из оценки.
:::

Типичная идея — найти простые оценки сверху и снизу, у которых предел один и тот же.

:::example
**Пример 1 (корень из суммы).** $\displaystyle\lim_{n\to\infty}\sqrt[n]{2^n+3^n}$.

Оценим выражение под корнем: $3^n\le2^n+3^n\le2\cdot3^n$. Тогда
$$
3\le\sqrt[n]{2^n+3^n}\le3\sqrt[n]{2}.
$$
Слева стоит постоянная $3$, справа — $3\sqrt[n]{2}\to3$. Значит, предел равен $3$.

**Общее правило:** $\sqrt[n]{a_1^n+\dots+a_k^n}\to\max(a_1,\dots,a_k)$ для положительных $a_i$ и фиксированного $k$.
:::

:::example
**Пример 2 ($\frac{n!}{n^n}\to0$ ещё раз).**
$$
0<\frac{n!}{n^n}=\frac1n\cdot\frac2n\cdot\frac3n\cdots\frac nn\le\frac1n\cdot1\cdot1\cdots1=\frac1n\to0 .
$$
:::

:::example
**Пример 3 (ограниченная на бесконечно малую).** $\displaystyle\lim_{n\to\infty}\frac{\sin n}{n}=0$, так как $\left|\frac{\sin n}{n}\right|\le\frac1n\to0$, то есть $-\frac1n\le\frac{\sin n}n\le\frac1n$.
:::

### Вариант для бесконечностей

:::remember
Если $x_n\le y_n$ и $x_n\to+\infty$, то $y_n\to+\infty$. Аналогично, если $y_n\le z_n$ и $z_n\to-\infty$, то $y_n\to-\infty$.
:::

:::example
$x_n=n+\sin n\ge n-1\to+\infty$, поэтому $x_n\to+\infty$. Достаточно нижней оценки, верхняя не нужна.
:::

## Монотонные и рекуррентные последовательности

### Метод

Если последовательность задана формулой $x_{n+1}=f(x_n)$, то предел находят по такой схеме.

:::example
**Алгоритм.**
1. Доказать **ограниченность** (обычно по индукции).
2. Доказать **монотонность** (обычно сравнением $x_{n+1}$ и $x_n$).
3. По теореме Вейерштрасса предел $a$ существует.
4. Перейти к пределу в равенстве $x_{n+1}=f(x_n)$ (левая часть стремится к $a$ как сдвиг, правая — к $f(a)$) и решить уравнение $a=f(a)$.
5. Из корней выбрать тот, который согласуется с оценками (ограниченностью, монотонностью).
:::

:::warning
Переходить к пределу в равенстве $x_{n+1}=f(x_n)$ можно **только после** того, как доказано, что предел существует. Иначе можно получить «предел» у расходящейся последовательности. Пример: $x_1=0$, $x_{n+1}=1-x_n$ даёт $0,1,0,1,\dots$ (расходится), а уравнение $a=1-a$ формально выдаёт $a=\frac12$.
:::

### Пример 1: $x_{n+1}=\sqrt{2+x_n}$

:::example
Пусть $x_1=\sqrt2$, $x_{n+1}=\sqrt{2+x_n}$.

**Ограниченность сверху числом $2$** (индукция). База: $x_1=\sqrt2<2$. Шаг: если $x_n<2$, то $x_{n+1}=\sqrt{2+x_n}<\sqrt4=2$.

**Монотонность.** Так как $x_n>0$, неравенство $x_{n+1}>x_n$ равносильно $2+x_n>x_n^2$, то есть $(x_n-2)(x_n+1)<0$. Это верно, потому что $0<x_n<2$. Значит, последовательность возрастает.

**Предел.** По теореме Вейерштрасса предел $a$ существует. Переходя к пределу в равенстве, получаем $a=\sqrt{2+a}$, откуда $a^2-a-2=0$, то есть $a=2$ или $a=-1$. Так как $a\ge x_1>0$, то $a=2$.
:::

### Пример 2: $x_{n+1}=\frac{x_n}2+\frac1{x_n}$

:::example
Пусть $x_1=2$, $x_{n+1}=\dfrac{x_n}{2}+\dfrac{1}{x_n}$. Первые члены: $2$, $1{,}5$, $1{,}4167,\dots$

**Ограниченность снизу числом $\sqrt2$.** По неравенству между средним арифметическим и геометрическим
$$
x_{n+1}=\frac{x_n}2+\frac1{x_n}\ge2\sqrt{\frac{x_n}2\cdot\frac1{x_n}}=\sqrt2 .
$$

**Монотонность (убывание).** Разность
$$
x_{n+1}-x_n=\frac1{x_n}-\frac{x_n}2=\frac{2-x_n^2}{2x_n}\le0,
$$
так как $x_n\ge\sqrt2$.

**Предел.** Он существует по теореме Вейерштрасса. Из равенства $a=\frac a2+\frac1a$ получаем $\frac a2=\frac1a$, то есть $a^2=2$. Поскольку $a\ge\sqrt2>0$, то $a=\sqrt2$.
:::

## Символы Ландау и эквивалентные последовательности

### Определения

:::meaning
Пусть $y_n\ne0$ (хотя бы начиная с некоторого номера).

- $x_n=o(y_n)$ («$x_n$ — $o$-малое от $y_n$»), если $x_n=\alpha_ny_n$, где $\alpha_n\to0$. Равносильно: $\dfrac{x_n}{y_n}\to0$. Говорят, что $x_n$ **растёт медленнее** $y_n$ (пишут также $x_n\ll y_n$).
- $x_n=O(y_n)$ («$x_n$ — $O$-большое от $y_n$»), если $x_n=\beta_ny_n$, где $\{\beta_n\}$ ограничена. Равносильно: $|x_n|\le C|y_n|$ для некоторой постоянной $C$.
- $x_n\sim y_n$ («$x_n$ **эквивалентна** $y_n$»), если $x_n=\gamma_ny_n$, где $\gamma_n\to1$. Равносильно: $\dfrac{x_n}{y_n}\to1$.
:::

:::note
Символы $o$ и $O$ — это **обозначения класса** последовательностей, а не конкретная последовательность. Запись $x_n=o(y_n)$ читается слева направо, а записи вроде $o(y_n)=x_n$ не пишут. Равенство $o(n)+o(n)=o(n)$ означает, что сумма любых двух последовательностей, малых по сравнению с $n$, снова мала по сравнению с $n$.
:::

:::example
**Простые примеры.**
- $n=o(n^2)$, так как $\frac n{n^2}=\frac1n\to0$.
- $\sin n=O(1)$, так как $|\sin n|\le1$. Но $\sin n\ne o(1)$: она не стремится к нулю.
- $n+1\sim n$, так как $\frac{n+1}{n}=1+\frac1n\to1$.
- $\sqrt{4n^2+1}\sim2n$, так как $\frac{\sqrt{4n^2+1}}{2n}=\sqrt{1+\frac1{4n^2}}\to1$.
:::

### Свойства

:::remember
1. Из $x_n=o(y_n)$ следует $x_n=O(y_n)$ (бесконечно малая ограничена).
2. $o(y_n)\pm o(y_n)=o(y_n)$; $O(y_n)\pm O(y_n)=O(y_n)$; $c\cdot o(y_n)=o(y_n)$.
3. $z_n\cdot o(y_n)=o(z_ny_n)$ и $z_n\cdot O(y_n)=O(z_ny_n)$.
4. $x_n\sim y_n\iff x_n=y_n+o(y_n)$.
5. Эквивалентность — отношение эквивалентности: $x_n\sim x_n$; из $x_n\sim y_n$ следует $y_n\sim x_n$; из $x_n\sim y_n$ и $y_n\sim z_n$ следует $x_n\sim z_n$.
6. Если $x_n\sim x_n'$ и $y_n\sim y_n'$, то $x_ny_n\sim x_n'y_n'$, $\dfrac{x_n}{y_n}\sim\dfrac{x_n'}{y_n'}$, $x_n^k\sim(x_n')^k$.
7. Если $x_n\sim y_n$ и $y_n\to a$ ($a$ — число или $\infty$), то и $x_n\to a$.
:::

:::example
**Почему верны свойства 4, 6 и 7.**
- *4.* $x_n=\gamma_ny_n=y_n+(\gamma_n-1)y_n$, а $\gamma_n-1\to0$.
- *6.* $x_n=\gamma_nx_n'$, $y_n=\delta_ny_n'$ с $\gamma_n,\delta_n\to1$. Тогда $x_ny_n=(\gamma_n\delta_n)x_n'y_n'$, а $\gamma_n\delta_n\to1$. Для частного аналогично: $\frac{\gamma_n}{\delta_n}\to1$.
- *7.* $x_n=\gamma_ny_n$ — произведение последовательности, стремящейся к $1$, на последовательность, стремящуюся к $a$, поэтому $x_n\to a$ (для $a=\infty$ используем таблицу бесконечно больших).
:::

:::warning
**Эквивалентности нельзя складывать и вычитать, нельзя ставить в показатель.**
- $n+1\sim n$ и $n\sim n$, но $(n+1)-n=1$, а $n-n=0$ — эти разности не эквивалентны.
- $n+1\sim n$, но $e^{n+1}=e\cdot e^n$, то есть $e^{n+1}\not\sim e^n$ (отношение стремится к $e\ne1$).

Для сумм действуют иначе: **сначала выделяют главный член**, а остальное записывают как $o(\text{главный})$. Если главные члены не сокращаются, сумма эквивалентна главному члену.
:::

:::example
**Многочлен эквивалентен своему старшему члену:** $a_pn^p+\dots+a_0\sim a_pn^p$, потому что остальные слагаемые — это $o(n^p)$.

Найдём $\displaystyle\lim_{n\to\infty}\frac{3n^2+n}{5n^3-2}$. Числитель $\sim3n^2$, знаменатель $\sim5n^3$, поэтому по свойству 6 дробь $\sim\dfrac{3n^2}{5n^3}=\dfrac3{5n}\to0$, и по свойству 7 предел равен $0$.
:::

:::example
**Оценка через $O$ и $o$.** Найдём $\displaystyle\lim_{n\to\infty}\frac{n^2+n\sin n}{n^2}$.

Так как $|n\sin n|\le n$, то $n\sin n=O(n)=o(n^2)$. Поэтому числитель равен $n^2+o(n^2)\sim n^2$, а дробь стремится к $1$.
:::

### Шкала роста

:::remember
При $n\to\infty$, для любых $\alpha>0$ и $a>1$:
$$
\ln n\ \ll\ n^\alpha\ \ll\ a^n\ \ll\ n!\ \ll\ n^n .
$$
Каждая последовательность растёт медленнее следующей: предел отношения предыдущей к последующей равен нулю.
:::

:::note
Сравнения $n^\alpha\ll a^n$, $a^n\ll n!$, $n!\ll n^n$ получены выше леммой об отношении. Сравнение $\ln n\ll n^\alpha$ принимаем как известное (оно доказывается при изучении предела функции).
:::

```plot
title: Рост функций: ln x, x, x^2, 2^x
x: 0..6 y: 0..40 grid
y = ln(x) {color: blue, label: "ln x"}
y = x {color: green, label: "x"}
y = x^2 {color: orange, label: "x^2"}
y = 2^x {color: red, label: "2^x"}
```

:::example
**Применения шкалы.**
- $\dfrac{2^n+n^5}{3^n-n^3}$: числитель $\sim2^n$ (так как $n^5\ll2^n$), знаменатель $\sim3^n$. Дробь $\sim\left(\frac23\right)^n\to0$.
- $\dfrac{n!+3^n}{(n+1)!+2^n}$: числитель $\sim n!$, знаменатель $\sim(n+1)!$. Дробь $\sim\dfrac{n!}{(n+1)!}=\dfrac1{n+1}\to0$.
:::

### Таблица эквивалентностей

Для любой последовательности $\alpha_n\to0$, $\alpha_n\ne0$ (принимаем как известное; доказываются при изучении предела функции):

| Эквивалентность | Выражение |
|---|---|
| $\sin\alpha_n\sim\alpha_n$ | синус |
| $\operatorname{tg}\alpha_n\sim\alpha_n$ | тангенс |
| $\arcsin\alpha_n\sim\alpha_n$ | арксинус |
| $\operatorname{arctg}\alpha_n\sim\alpha_n$ | арктангенс |
| $\ln(1+\alpha_n)\sim\alpha_n$ | логарифм |
| $e^{\alpha_n}-1\sim\alpha_n$ | экспонента |
| $a^{\alpha_n}-1\sim\alpha_n\ln a$ | показательная функция |
| $(1+\alpha_n)^k-1\sim k\alpha_n$ | степень |
| $1-\cos\alpha_n\sim\dfrac{\alpha_n^2}2$ | косинус |

:::example
**Пример 1.** $\displaystyle\lim_{n\to\infty}n\sin\frac5n$.

$\sin\frac5n\sim\frac5n$, поэтому $n\sin\frac5n\sim n\cdot\frac5n=5$. Предел равен $5$.
:::

:::example
**Пример 2.** $\displaystyle\lim_{n\to\infty}n^2\left(1-\cos\frac1n\right)$.

$1-\cos\frac1n\sim\frac12\cdot\frac1{n^2}$, поэтому $n^2\left(1-\cos\frac1n\right)\sim\frac12$. Предел равен $\frac12$.
:::

:::example
**Пример 3.** $\displaystyle\lim_{n\to\infty}n\left(\sqrt[n]{a}-1\right)$ при $a>0$.

Запишем $\sqrt[n]{a}=e^{\frac{\ln a}{n}}$, тогда $\sqrt[n]{a}-1=e^{\frac{\ln a}n}-1\sim\dfrac{\ln a}{n}$. Значит, $n\left(\sqrt[n]{a}-1\right)\to\ln a$.
:::

:::example
**Пример 4.** $\displaystyle\lim_{n\to\infty}\frac{\operatorname{tg}\frac1n}{\arcsin\frac2n}$.

$\operatorname{tg}\frac1n\sim\frac1n$ и $\arcsin\frac2n\sim\frac2n$, поэтому дробь $\sim\dfrac{1/n}{2/n}=\dfrac12$.
:::

:::warning
Таблица работает только для множителей и делителей. Выражения вида $\sin\frac1n-\frac1n$ заменой $\sin\frac1n\sim\frac1n$ **нельзя** вычислять: получилась бы разность эквивалентных величин, то есть «$0$». Для таких задач нужны разложения Тейлора (будут позже).
:::

## Второй замечательный предел на практике

### Обобщение

:::remember
Из определения $e$ следует: если $\alpha_n\to0$ и $\alpha_n\ne0$, то
$$
(1+\alpha_n)^{1/\alpha_n}\to e .
$$
Для $\alpha_n=\frac1n$ это в точности определение числа $e$. Общий случай принимаем как известное.
:::

### Рабочая формула

Для неопределённости $1^\infty$ представим выражение в виде $(1+\alpha_n)^{\beta_n}$ и перепишем:
$$
(1+\alpha_n)^{\beta_n}=\Bigl[(1+\alpha_n)^{1/\alpha_n}\Bigr]^{\alpha_n\beta_n}.
$$

:::remember
Если $\alpha_n\to0$, $\alpha_n\ne0$ и $\alpha_n\beta_n\to L$, то
$$
(1+\alpha_n)^{\beta_n}\longrightarrow e^{L}.
$$
:::

:::example
**Рецепт.**
1. Вычесть единицу из основания: $\alpha_n=\text{основание}-1$. Проверить, что $\alpha_n\to0$.
2. Выписать показатель $\beta_n$.
3. Найти $L=\lim\alpha_n\beta_n$ (обычная неопределённость вида $0\cdot\infty$, раскрывается как рациональное выражение).
4. Ответ: $e^{L}$.
:::

### Примеры

:::example
**Пример 1.** $\displaystyle\lim_{n\to\infty}\left(1+\frac kn\right)^n$.

Здесь $\alpha_n=\frac kn$, $\beta_n=n$, $\alpha_n\beta_n=k$. Ответ: $e^k$.
:::

:::example
**Пример 2.** $\displaystyle\lim_{n\to\infty}\left(\frac{n+1}{n+2}\right)^n$.

1. Основание минус единица: $\dfrac{n+1}{n+2}-1=-\dfrac1{n+2}=\alpha_n\to0$.
2. Показатель $\beta_n=n$.
3. $\alpha_n\beta_n=-\dfrac n{n+2}\to-1$.
4. Ответ: $e^{-1}$.
:::

:::example
**Пример 3.** $\displaystyle\lim_{n\to\infty}\left(\frac{n^2+1}{n^2-1}\right)^{n^2}$.

1. $\alpha_n=\dfrac{n^2+1}{n^2-1}-1=\dfrac2{n^2-1}\to0$.
2. $\beta_n=n^2$.
3. $\alpha_n\beta_n=\dfrac{2n^2}{n^2-1}\to2$.
4. Ответ: $e^2$.
:::

:::example
**Пример 4.** $\displaystyle\lim_{n\to\infty}\left(\frac{3n+1}{3n-2}\right)^n$.

$\alpha_n=\dfrac{3}{3n-2}$, $\alpha_n\beta_n=\dfrac{3n}{3n-2}\to1$. Ответ: $e$.
:::

:::warning
**Не всякий предел вида $(1+\alpha_n)^{\beta_n}$ равен $e$.** Всё определяется пределом произведения $\alpha_n\beta_n$. Например, $\left(1+\frac1{n^2}\right)^n$: здесь $\alpha_n\beta_n=\frac1n\to0$, поэтому предел равен $e^0=1$.

Также не путайте с ситуацией, когда основание **не** стремится к единице: если $x_n\to a$ с $a>1$ и показатель стремится к $+\infty$, то $x_n^{y_n}\to+\infty$; если $0<a<1$, то $x_n^{y_n}\to0$. Неопределённости здесь нет.
:::

## Расходимость: как доказать, что предела нет

:::remember
Доказать расходимость можно одним из способов.
1. **Неограниченность.** Сходящаяся последовательность ограничена, поэтому неограниченная — расходится.
2. **Две подпоследовательности с разными пределами.** Если $x_{n_k}\to a$, $x_{m_k}\to b$ и $a\ne b$, то $\{x_n\}$ расходится (иначе обе подпоследовательности имели бы один и тот же предел).
3. **Нарушение условия Коши.** Если
$$
\exists\varepsilon_0>0\ \ \forall N\ \ \exists n,m>N:\ \ |x_n-x_m|\ge\varepsilon_0,
$$
то последовательность не фундаментальна и, по критерию Коши, расходится.
:::

:::example
**Пример 1 ($(-1)^n$).** Подпоследовательность $x_{2k}=1\to1$, подпоследовательность $x_{2k+1}=-1\to-1$. Пределы различны, значит, последовательность расходится.
:::

:::example
**Пример 2 ($(-1)^n\frac{n}{n+1}$).** При чётных $n$ члены равны $\frac n{n+1}\to1$, при нечётных — $-\frac n{n+1}\to-1$. Пределы подпоследовательностей различны, значит, последовательность расходится.
:::

:::example
**Пример 3 (гармоническая сумма).** Пусть $x_n=1+\dfrac12+\dfrac13+\dots+\dfrac1n$. Оценим разность членов с номерами $2n$ и $n$:
$$
x_{2n}-x_n=\frac1{n+1}+\frac1{n+2}+\dots+\frac1{2n}\ge n\cdot\frac1{2n}=\frac12 .
$$
Каждое из $n$ слагаемых не меньше самого маленького, равного $\frac1{2n}$. Таким образом, при $\varepsilon_0=\frac12$ для любого $N$ найдутся $n>N$ и $m=2n>N$ с $|x_m-x_n|\ge\frac12$. Условие Коши нарушено, значит, последовательность расходится.
:::

:::note
Если и чётные, и нечётные члены последовательности стремятся к одному и тому же числу $a$, то и вся последовательность стремится к $a$: для $\varepsilon>0$ берём $N_1$ для чётных и $N_2$ для нечётных номеров, и при $n>\max(N_1,N_2)$ неравенство $|x_n-a|<\varepsilon$ выполнено при любой чётности $n$.
:::

:::warning
Наличие сходящейся подпоследовательности ничего не доказывает про сходимость всей последовательности. У ограниченной последовательности такие подпоследовательности есть всегда (теорема Больцано — Вейерштрасса), и всё же она может расходиться, как $(-1)^n$.
:::

- Многочлены и показательные: делим на старший член.
